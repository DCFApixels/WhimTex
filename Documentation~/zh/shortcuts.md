# 快捷键

## 文档、图层与不透明度

| 快捷键 | 操作 |
| :--- | :--- |
| `Ctrl+S` | 保存 / 另存为。 |
| `Ctrl+Z` · `Ctrl+Y` / `Ctrl+Shift+Z` | 撤销 · 重做。 |
| 在 Layers 中操作后按 `Up` / `Down` | 上一个 / 下一个可见图层。 |
| 点击画布后按方向键 | 沿画布坐标轴将所选图层移动一个画布像素。按住逐渐加快重复，一次 Undo 撤销整个按住操作。选中的参考线优先。 |
| 在缩略图外 `Ctrl`-点击 / `Shift`-点击 | 切换图层 / 选择一个范围。 |
| `Ctrl+Shift`-点击 | 追加一个范围。 |
| `Ctrl+E` / `Ctrl+Alt+E` | 合并选区 / 合并副本。 |
| `0`–`9` 或小键盘 | 设置所选图层的不透明度。 |

`5` 表示 50%；紧接着快速按 `7` 表示 57%。停顿之后再按 `7` 则表示 70%。
`0` 表示 100%，快速按 `00` 表示 0%，`05` 表示 5%。

## 绘制、选区与导航

| 快捷键 | 操作 |
| :--- | :--- |
| `[` / `]` · `X` | 调整画笔/铅笔大小 · 交换颜色。 |
| 按住 `Alt`，用画笔、铅笔或填充点击/拖动 | 在屏幕任意位置拾取可见颜色；松开 `Alt` 返回该工具。 |
| 使用画笔/铅笔时按 `RMB` | 临时擦除。 |
| `U` · 使用形状时 `Shift`-拖动 | 形状工具 · 等比 / 45° 直线角度。 |
| 绘制时 `Shift`-拖动 / `Shift`-点击 | 轴向直线 / 连接端点。 |
| `Ctrl`-点击缩略图/组的箭头 | 选择透明通道。 |
| `Ctrl+C` / `Ctrl+Shift+C` / `Ctrl+V` | 复制所选图层（或所选像素）/ 复制合并像素 / 粘贴，包括在窗口之间。 |
| `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` | 全选 / 取消选择 / 反选区域。 |
| 使用选区工具时按 `Shift` / `Alt` / `Shift+Alt` | 相加 / 相减 / 相交。 |
| 使用套索时按 `Enter` / `Backspace` / `Escape` | 闭合 / 删除顶点 / 取消。 |
| `MMB`-拖动 / 鼠标滚轮 | 在任意工具下平移 / 缩放。 |
| `Shift+MMB`-拖动 | 在任意工具下旋转视图；`Ctrl` 会绕过角度吸附。 |
| 使用缩放时 `Alt`-点击 | 缩小。 |
| 吸附时按 `Ctrl` | 绕过吸附。 |
| 变换中按 `Enter` · 手势过程中按 `Escape` | 退出工具 · 取消手势。 |

在 macOS 上，`Cmd` 也可用于保存、选区和撤销/重做。
请在 WhimTex 窗口处于焦点时使用这些快捷键。
