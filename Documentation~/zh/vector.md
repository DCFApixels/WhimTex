# 矢量路径

一个 Vector 图层包含一个可编辑图形，并拥有独立变换。一个图形可以包含多个轮廓和孔洞。
通过 **+ → Vector** 添加图层，或使用 **Vector Pen**、**Vector Brush** 绘制新图形；每个新图形各占一个图层。
工具栏还提供 **Vector Select** 和 **Vector Nodes**。

## 绘制与编辑

使用 **Vector Pen** 时，单击添加角点，拖动添加曲线控制点。
单击第一个点可闭合路径，**Enter** 完成开放路径，**Escape** 取消创建。
只有闭合轮廓参与填充；开放路径可以描边。

用 **Vector Select** 移动图形，用角部手柄调整大小，用圆形手柄旋转。
这些操作改变图层变换；框描述图形本身，不包含描边或 FX。
按 **Shift** 可等比缩放，或按 15 度步长旋转。
**Vector Nodes** 可移动节点和切线手柄。按 **Shift** 增选节点，
在空白处拖动可框选节点。双击边缘插入节点，**Alt-单击** 删除节点，**Alt-拖动** 解除手柄联动。
顶部的 **Corner** 让两个手柄独立移动，**Aligned** 保持共线，**Mirrored** 还会保持等长。

## 填充与描边

在 **Layers** 中选择图形的图层，然后在 **Properties (Vector)** 中调整外观。
通过图层列表更名、隐藏、排序、复制或删除图形。**Fill → Type** 提供 None、Solid、
Linear、Radial、Square、Diamond 和 Circular。**Fill Rule** 决定重叠轮廓与孔洞的填充方式。
Shape 在启用 **Fill** 时也提供相同的填充控件。

**Linear** 在 **Start** 和 **End** 之间生成直线过渡。**Radial**、**Square** 和
**Diamond** 从 **Center** 向外展开；**Radius / Direction** 确定大小，
也决定 Square/Diamond 的旋转方向。**Circular** 从指向 **Direction** 的射线出发，
绕 Center 逆时针变化一周，在同一射线上形成接缝。首尾颜色不同时，接缝会可见。
坐标相对于图层归一化：`[0,0]` 为左下角，`[1,1]` 为右上角。
两点重合时，整个填充使用渐变的起始颜色。

点击 **Gradient** 调整颜色、透明度及重复方式。切换类型或关闭 Shape 的 Fill
会保留调好的色带和坐标。渐变随图层 Transform 变化；其比例依据 Shape 的当前画布尺寸，
或 Vector 创建时的参考尺寸。因此，改变画布尺寸可能改变 Shape 渐变的比例。

启用 **Stroke**，在 **Type** 中选择 None、Solid、Linear、Radial、Square、Diamond
或 Circular。描边有独立的颜色或渐变、控制点和 Circular 的 **Repetitions**。
其渐变控件与 Fill 相同，修改一方不会改变另一方。选择 None 或关闭 Stroke
会隐藏描边并保留设置。Repetitions 决定绕中心的周期数，色带的 Wrap 决定超出首个周期后的行为。

使用 **Gradient Handles** 在画布上定位渐变。填充和描边同时启用渐变时，
通过工具中的 **Fill** / **Stroke** 选择器确定要编辑哪一个。拖动控制点只调整
所选渐变在图形内的位置，图形的位置和另一渐变保持不变。只有一个可用渐变时，
选择器会自动选中它并禁用切换。Boolean Group 也为结果
提供独立的 Fill 和 Stroke 控件；Combine 使用 **Appearance → Layers** 时，编辑子图层的渐变。

还可设置描边宽度、Inside/Center/Outside 位置、连接和端帽。
**Position** 的 Inside、Center、Outside 图标用细线标记原始轮廓，显示描边相对它的位置。
**Join** 用图标按钮选择 Miter、Round 或 Bevel，**Cap** 用图标按钮选择 Butt、Round 或 Square。
当前选项带有边框，悬停可查看名称和效果说明。
开放路径的描边始终居中。宽度和虚线随图层一起缩放。
对于闭合轮廓，Inside/Outside 先将路径偏移半个描边宽度，再排列虚线和端帽。
圆点与圆形端帽保持完整，不再被填充边界切掉一半；Shape 也使用此规则。
偏移后的路径长度不同，因此虚线位置可能改变。过窄的内缩路径可能分裂或消失；
在狭窄转角处，完整端帽可能越过原始边界。
**Edge Mode → Step** 关闭几何抗锯齿；颜色、Opacity 和 FX 仍可产生半透明效果。

### 虚线

Shape 使用相同的虚线控件。缩放 Shape 时，描边宽度和虚线长度保持文档像素大小；
Vector 则随图层一起缩放它们。

在 **Dashes** 中选择带线条预览的预设，或使用始终显示的 **Pattern (× Width)** 输入框。
`2 1` 表示划线长度为描边宽度的两倍、间隔为一倍；留空表示实线。数值可用空格、逗号或分号分隔。
展开 **Segments** 可单独修改 **Dash** 和 **Gap**，并添加或删除配对。
**Add Pair** 复制最后显示的一对数值；列表为空时使用 `2 1`。
所有控件保持同步；修改预设后，图案可能变为 **Custom**。

输入时预览会实时更新，并考虑宽度、端帽和 **Dash Offset**。
按 **Enter** 或离开输入框，将图案应用到图形；**Escape** 恢复已应用的值。
无效输入保留并高亮，不会替换当前图案。倍数必须为正数且不超过 8192，
最多 256 个数值。奇数列表重复两次，第二次互换划线与间隔角色；重复字段保持联动。
添加或删除配对时，会在同一数量限制内展开成等价的完整周期。

预设保留颜色、宽度、连接、位置和偏移。标有 **Round** 的预设还会选择圆形端帽：
圆点由长度为描边宽度 0.01 倍的短划线形成。修改 **Width** 会同时缩放划线和间隔，Pattern 数值不变。
如果端帽填满间隔，可增大 **Gap**。**Dash Offset** 仍以像素为单位沿轮廓移动图案。长度不会自动对齐到拐角。

## 调整最后一笔

**Vector Brush** 在释放指针后，根据绘制的遮罩拟合可编辑的闭合三次贝塞尔曲线。
在 **Last Stroke — Original Mask** 中降低 **Tolerance (px)**（0.25..64 个图层参考像素）
可更贴近遮罩；提高数值通常会减少锚点、简化曲线。狭窄结构和孔洞可能需要更多锚点。
正的 **Expand (px)**（-256..256）扩大图形，负值缩小图形。每次调整都使用原始遮罩重建，
不会累积拟合误差。数值输入在确认后应用。

每个笔触图形保留自己的遮罩，保存并重新打开 TIFF 或 JSON 后仍可使用。
下一笔创建独立图层，上一笔的遮罩仍可调整。手动编辑该图形会清除它的遮罩。
**Release Mask** 也只删除原始遮罩，保留矢量图形。
遮罩从图层参考尺寸缩小到最长边不超过 1024 像素，因此大图像中的细微结构可能丢失。
过于复杂的笔触可能触及几何或计算限制，编辑器会给出提示。

## 转换 Shape

选中 Shape，在 Properties 或右键菜单中选择 **Convert to Vector**。
Rectangle、Ellipse、Polygon、Star、Line、Arc 和 Sector 按几何轮廓转换，
包括圆角和倒角。图层的位置和 FX 保留。

转换会将 **Clip** 平铺模式改为 **Unbounded**，以保留伸出的线帽和外侧描边；
Vector 的 Clip 模式会将它们裁剪到图层框内。其他平铺模式保持选中。
图层框会适配图形并保持画布位置，因此局部坐标和变换数值可能一起改变。
Repeat/Mirror/Source 的边缘采样也可能不同，因为 Vector 使用已渲染的图层图像。

以下情况会在替换 Shape 前给出不支持提示：启用非零 Feather；
非零宽度描边使用不均匀或投影变换；半透明描边覆盖填充；
较厚圆弧产生偏移尖点或相交端帽。可将 Feather 设为零、调整提示中的设置，
或保留原 Shape。圆弧以三次曲线近似，边缘抗锯齿可能不同。
保存格式和 API 字段见[数据约定](../JSON_FORMAT.md#vector-layers)。

## 组合图形并保留独立编辑

**Boolean Group** 组合其 Shape、Vector 和嵌套 Boolean Group 子图层的几何，
再为结果应用统一的填充和描边。每个子图层仍可独立编辑和移动；变换组会移动整个组合。
选中同一父级中的图形，打开右键菜单，选择 **Boolean Group → Combine**、**Union**、**Subtract**、**Intersect** 或 **Xor**。

要更改现有组的运算，在其 Properties 中使用五个 **Mode** 图标按钮。
图标的填充区域表示两个图形运算后的结果。按钮为所有直接子图层设置同一运算，
不改变嵌套组内部的运算。**Mixed** 表示子图层使用不同运算，此时没有图标被选中。
仍可在各子图层的 **Operation** 字段中单独设置运算。

最下方启用的子图层作为基础。从下往上，为后续子图层选择操作：
**Union** 合并，**Subtract** 减去，**Intersect** 保留交集，**Xor** 保留不重叠部分。
基础图层的操作不影响结果。调整子图层顺序可能改变结果。

在 Boolean Group 上设置最终填充和描边。从图形创建组时，只复制一次底部图形的样式，
之后改变该图形的样式不会改变组样式。子图层的填充和描边保留，但布尔运算使用组样式；子图层 FX 不应用。
描边不会扩大参与布尔运算的区域。将子图层移出组后，它会重新使用自己的外观。

**Combine** 保留独立图形，按从下到上的顺序绘制，不合并重叠区域。每个图形保留完整描边，半透明填充会叠加。
此模式下，**Appearance → Group** 为各图形应用共同填充和描边；**Layers** 使用子图层自己的填充、渐变、描边和边缘处理，包括 Shape 的 Feather。
子图层的 FX、不透明度、混合模式和通道映射仍不生效。Union、Subtract、Intersect 和 Xor 始终使用组样式，切换模式时保留 Appearance 选择。

栅格图层和包含开放轮廓的路径不能作为操作数。请使用闭合图形；不支持的子图层会显示错误，
而不是被静默跳过。多个闭合轮廓和孔洞仍可属于同一个图形。
打开旧的多图形 Vector 图层时，图形会拆分为普通 Group 下的独立子图层，保留原有共享位置和 FX。
