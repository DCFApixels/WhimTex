# 区域选区

选择区域进行绘制、擦除或填充，而不影响图像的其余部分。
使用 **Area Select**（`M`）绘制矩形或椭圆，使用 **Polygonal Lasso** 通过放置点确定轮廓，或使用 **Freehand Lasso** 手绘轮廓。按 `L` 可返回所选套索模式。

在画布上方的边缘模式列表中选择选区边缘：

- **Aliased**（默认）将每个像素完全选中或保持未选中，保留清晰的像素边缘。
- **Antialiased** 部分选中边界上的像素，使边缘更平滑，不添加羽化。

此设置由 Rectangle、Ellipse、两种套索模式和 UV Island Select 共用，切换工具时会保留。更改设置会影响下一次选区；正在绘制的轮廓保留开始时选择的模式。已有选区的边缘保持不变。

## 创建并调整选区

按住或拖动工具栏上的 Area Select 按钮以打开形状列表。在 **Rectangle** 或 **Ellipse** 上松开，然后在画布上拖动。按钮会显示所选形状；按 `M` 可回到该形状。

按住或拖动工具栏上的套索按钮，选择 **Polygonal Lasso** 或 **Freehand Lasso**，然后在所需模式上松开。

使用 **Freehand Lasso** 时，按住鼠标左键沿区域绘制。松开按钮会连接轮廓的终点和起点，并应用选区。`Escape` 取消当前轮廓。

使用 **Polygonal Lasso** 时，沿轮廓点击，并以
`Enter`、添加新点时在同一位置双击，或点击第一个点来结束。双击旧的点或线段不会结束轮廓。
`Backspace` 或右键单击会移除最后一个点；`Escape` 会取消未完成的轮廓。
已放置的点以小方块标记。在完成选区之前，轮廓保持开放，最后一条线段跟随光标。
这是 **Straight** 模式的行为。选择画布上方的 **Smooth**，即可生成经过所有放置点的
自动平滑 Catmull–Rom 曲线。放置至少三个点后，Smooth 按闭合形状计算曲线，但显示开放轮廓：
从最后一点返回第一点的闭合曲线在完成之前保持隐藏。完成时，已显示曲线的形状保持不变。
指向光标的浅蓝色线仅用于定位下一点。移动或插入点会立即更新轮廓；只能在可见曲线上插入点。
编辑轮廓时可以切换 Straight/Smooth。

在 Smooth 中，圆形标记表示平滑点，方形标记表示角点。将光标移到某点上并按 `C`
可切换其类型。**Corner** 复选框修改以蓝色高亮的选中点；放置、插入或拖动点会选中该点。
光标下没有点时，`C` 修改选中点。边界预览和最终选区使用同一轮廓；**Aliased / Antialiased**
仍决定边缘像素的覆盖方式。平滑曲线在点之间可能超出原来的直边多边形。
轮廓离开起点并包含至少三个点后，将光标移到第一个点附近：该点会变为蓝色，线段末端会吸附到它。按下并松开鼠标按钮即可闭合选区；拖动第一个点则会移动它。

完成之前，可以调整已放置的点：

- 拖动点标记以移动该点。
- 点击已有线段以插入一个点。跟随光标的线段不接受插入点。
- `Alt+单击`点标记以删除该点，并重新连接其相邻点。

放置或插入点时，继续按住鼠标按钮并拖动，即可立即调整该点的位置。
添加或拖动新端点时按住 `Shift`，可将其线段约束到相对于画布最近的水平、垂直或 45° 对角方向，即使视图已旋转。`Ctrl+Shift` 会保留方向约束，同时禁用吸附。
拖动已放置的点时，`Shift` 会以拖动开始时的位置为基准，将移动限制在这些方向上。拖动期间按住 `Ctrl` 可禁用参考线吸附，同时保留角度约束。

在最后一个点附近短按鼠标会继续绘制轮廓。按下鼠标按钮之前按住 `Ctrl`，即可在已有点或线段上放置新点，同时禁用吸附和闭合。开始拖动点之后，`Ctrl` 只会禁用吸附。

要绘制**正方形或圆形**，先开始拖动，然后按住 `Shift`。松开 `Shift` 即可恢复自由比例。若在开始前按住 `Shift`，则会改为添加到选区。要添加正方形或圆形，请选择画布上方的 **Add**，并在拖动期间按住 `Shift`。

画布上方的控件可选择 **Add**（添加）、**Subtract**（减去）或 **Intersect**（保留交集）。
未选中模式时，新拖出的区域会替换选区。也可以按住：

- `Shift` 添加区域。
- `Alt` 减去区域。
- `Shift+Alt` 只保留重叠部分。

对于 Lasso，这些修饰键在放置第一个点或开始自由绘制时决定选区操作；调整点或绘制轮廓不会改变该操作。

`Ctrl+A` 选择整个画布。`Ctrl+Shift+I` 选择相反的区域。
`Ctrl+D` 移除选区，让你可以再次在任何位置绘制。
切换工具或图层时选区会保留，但不会随文档保存。

## Quick Selection

选择 **Quick Selection**（`W`），在目标区域内涂抹。工具沿颜色变化寻找边界，并限制不必要的扩展。
在纯色背景上，即使没有 Subtract 笔画，选区也会保持局部范围。要包含其他区域，请继续涂抹。
如果首次结果遗漏细小部分，可用额外的 Add 或 Subtract 笔画进行修正。

- **Add** 添加区域，**Subtract** 减去区域。使用鼠标右键涂抹或按住 `Alt` 可临时减去。
- **Size** 或 `[` / `]` 调整画笔直径，单位为画布像素。
- **Strength** 控制提示强度：100% 固定包含或排除，较低值可被相反提示覆盖。
  0% 清除画笔下的提示。它影响边界判断，不代表选区透明度。
- **Tolerance** 控制允许的颜色差异。选区跨过细微边界时降低此值；要包含更多色调时提高此值。
- **Visible Layers** 使用可见合成图像，**Current Layer** 使用所选图层及其效果。

Add 和 Subtract 笔画会作为前景与背景提示持续保留。先用 Subtract 标记不需要的背景，
再在对象内部继续 Add，两组提示共同决定边界。也可以在首次建立选区之前标记背景。
重叠位置以**最后一笔**的提示为准，其他位置的提示保留。
**Deselect**（`Ctrl+D`）同时清除提示和选区。
只要源图像或选区没有改变，切换工具再返回仍会保留这些提示。

涂抹时，**Preview** 显示近似轮廓，也支持 8192 × 8192 画布。短暂停顿或松开后，
**Refining** 将边界细化到原始像素。继续涂抹会中断旧的细化计算；细小结构可能在细化时出现。
切换工具或复制会等待细化完成。**Stop** 或 `Escape` 取消未完成的计算及等待中的操作，
移除预览，只保留已经应用的选区。修改源图像或创建其他选区也会停止计算。
此工具只改变选区，不修改源像素。
边界沿原始像素网格生成；Rectangle/Lasso 的抗锯齿设置不影响 Quick Selection。
细节很多时，显示轮廓可能整体简化，但仍保持连接；选区蒙版本身的精度不会降低。

## 选择 UV 岛屿


使用模型的 UV 布局来绘制其纹理的各个部分：

1. 打开 **UV** 面板，勾选标题栏中的 **UV**，将 Project 中的网格或模型指定给 **Mesh**。模型会自动使用层级中的第一个网格，包括非激活节点。要选择其他网格，请展开模型并直接指定所需网格。
2. 选择 **UV Channel**（通常是 **UV0**），并可选地选择 **Submesh** 以显示单个材质槽。
3. 选择工具栏分隔线下方的 **UV Island Select**，或在 UV 面板中点击 **Select UV Islands**。启用 UV 只会让工具出现，不会自动选择它。
4. 点击岛屿内部的任意位置。`Shift` 添加岛屿，`Alt` 减去岛屿，`Shift+Alt` 取交集。
5. 切换到画笔、铅笔或填充，在选区内工作。复制和剪切使用同一选区；`Ctrl+D` 会清除它。

只显示 UV 岛边界，不显示内部三角形对角线。小圆点和悬停高亮仅在 UV Island 模式下出现，不会拦截画笔绘制。

**Line Color** 和 **Opacity** 控制轮廓显示。关闭侧面板后仍可看到轮廓并继续绘制；关闭 **UV** 可隐藏轮廓而不清除选区。UV 展开图不会保存或导出到纹理中，也不修改网格。

只显示并可以选择主画布上的 **0–1 UV 平铺**，启用 Tiled 预览时也是如此。如果岛屿重叠，它们共享相同的纹理像素：绘制会改变使用这些坐标的所有模型表面。点击重叠区域时，会一致地选择第一个匹配的岛屿。如果程序化网格发生了变化但没有更新其资源，**Refresh UV** 会重新加载布局。

## 根据现有纹理细节填充

选择要重建的区域，然后在选择工具处于激活状态时点击画布上方的 **Content-Aware Fill**。
它会复用图像中已有的细节：适合填充孔洞、扩展纹理图案和修补 UV 边界，但不适合凭空创造新对象。

选择颜色和纹理相似的取样区域。填充会尝试不同片段来减少重复，
但来源细节不足时，仍可能出现重复形状。独特的光照渐变或没有相似样本的缺失细节可能需要手动修整。

1. 选择 **Source**：**Visible Composition**，或 **Selected Layer**（填充窗口打开时所选的图层）。
2. 将 **Fill Area** 设为 **Entire Selection**，或 **Inner Border**。**Border Width (px)** 会从选区轮廓向内填充一条条带，保持中心和外部的一切不变。
3. 启用 **Transparent Only** 以保留可见像素，只填充空白区域。
4. 选择取样位置：**Nearby** 搭配 **Sampling Distance (px)**、**Whole Image**，或 **Custom Selection**。对于自定义来源，请在主窗口中另外创建一个选区，然后点击 **Use Current Selection as Sampling Area**。你原来的填充区域保持不变。
5. 点击 **Preview**。用 **Show Before** 进行比较，或尝试 **New Variation**。更高的 **Quality** 需要更长时间。
6. 点击 **Apply**，将填充像素作为新绘制图层添加到列表顶部。**Cancel** 停止正在进行的计算，不修改文档；计算结束后按钮变为 **Close**，用于关闭窗口。

Sampling Distance 只改变细节的借用位置；它不会扩大填充区域。请让不需要的对象远离取样区域。来源像素必须可见，并且位于被填充的像素之外；Inner Border 未受影响的中心也可以提供细节。

启用 **Invert Selection** 可以改为填充所捕获选区之外的部分。反转发生在 **Inner Border** 之前，因此它的条带会跟随反转后的区域（包括画布边界）。画布上的选区和自定义取样选区保持不变。选择整个画布后再反转，就没有任何内容可供填充。

这是针对平面纹理的操作：它不会匹配模型 3D 接缝两侧对应的边缘。大面积或结构非常复杂的缺失区域可能需要更小的选区和多次处理。选区和取样区域合并后的边界矩形每次处理限制为 400 万像素。如果来源在窗口打开期间发生变化，请在应用前重新生成预览。

## 在画布上选择图层

选择 **Layer Select**（`V`）并点击图像。透明通道
满足 **Alpha ≥ %** 的最上层图层会被选中；通过透明区域可以选择下方的图层。默认阈值为 **10%**。
可在画布视图中的工具设置或 **User Settings → Layer Select** 中更改；两个控件共享同一项偏好设置。
即使在 0% 时，完全透明的像素也会被忽略。

- `Shift+click` 会在选区中切换某个图层。在空白区域 `Shift+click` 不会改变选区。
- 在同一位置重复点击，可从上到下循环选择命中的图层；到达底部后回到第一个。点击其他位置或切换工具会从顶部重新开始。
- 点击一个组可将其选中，再次点击可选取光标下的子级。重复点击会逐层进入嵌套组；`Ctrl+click` 会直接选取嵌套图层。其父组会在 Layers 中展开。
- 点击空白区域可取消选择。选取不会移动或绘制任何内容。

选取会遵循变换、图层 FX、Mapping、剪贴蒙版以及图层/组的不透明度。隐藏的图层会被跳过。
它使用每个图层自身的透明通道，而不是由其混合模式或预览 Post FX 产生的最终颜色。

## 选择图层的形状

按住 `Ctrl` 并点击图层缩略图或组的箭头。
选区会跟随其可见形状，包括柔和的边缘，而不是它的矩形边界。
你也可以使用隐藏的图层作为形状。

## 复制和粘贴

| 快捷键 | 操作 |
| :--- | :--- |
| `Ctrl+C` | 从活动图层复制选中的区域；如果没有区域选区，则复制选中的图层。 |
| `Ctrl+Shift+C` | 复制选区内的可见合成；没有区域选区时，复制整个画布。 |
| `Ctrl+V` | 插入复制的图层，或将复制的像素粘贴到新的 Drawing 图层上。 |

要转移可编辑的图层，请用 `Ctrl+D` 取消画布选择，在 **Layers** 中选择一行或多行，然后按 `Ctrl+C`。
切换到另一个 WhimTex 窗口并按 `Ctrl+V`。副本会连同名称、
设置、组内容、嵌入的 FX 和 Drawing 像素一起出现在堆栈顶部。每次粘贴都是独立的；复制后源窗口即可关闭。
绘制图层纹理保留原始分辨率，图层变换原样复制，不会按目标画布尺寸重新调整。
请将效果与其目标图层一起复制，以保留这些链接；复制集之外的目标必须重新指定。
图层剪贴板会一直保留到下一次复制、脚本重新加载或关闭 Unity。文本字段仍保留正常的文本复制/粘贴。

有区域选区时，只复制其中的像素。在相同尺寸的画布上，它们保持原有位置；
在不同尺寸的画布上，它们会被居中。没有区域选区时，`Ctrl+Shift+C` 会将整个可见画布作为像素复制。

在 Windows 上，这些像素复制命令还会将 PNG 图像放入系统剪贴板，供其他应用程序粘贴。
图像保留透明通道，并裁剪到所复制区域的边界矩形。
在同一次 Unity 会话中，只要该副本仍在剪贴板上，WhimTex 就会保留 HDR 副本及其原始画布位置，供自己的窗口之间粘贴。
复制其他内容会替换此副本；下一次粘贴会使用新的剪贴板内容。
没有画布选区时，用 `Ctrl+C` 复制的可编辑图层保留在 WhimTex 的图层剪贴板中。
在 macOS 和 Linux 上，像素复制目前在 WhimTex 内部可用。

在 Windows 上，你也可以从其他应用程序复制图像，或用 `Win+Shift+S` 截图，
然后点击画布视图并按 `Ctrl+V`。它会成为新的 Drawing 图层，以其原始像素大小居中，且不会裁剪存储的图像。在空文档中，画布会采用该图像的尺寸。
PNG 透明通道会被保留。系统图像粘贴支持最高 1600 万像素的图像，以及你的 GPU 的纹理尺寸限制。
你也可以复制直接的 HTTP(S) 图像链接并按 `Ctrl+V`：WhimTex 会将 PNG 或 JPEG
下载为独立的 Drawing 图层，保留其原始像素和透明通道。它会被放入画布内，
按比例居中，使用图层变换而不是调整图像大小。同样的大小限制适用；
下载限制为 64 MB。不支持指向网页的链接。关闭窗口或切换文档
会取消下载。本地文件请先拖入 Project，再拖到画布视图。
旧的链接图片 JSON 已不再支持，也不会迁移。请使用对应的旧版 checkout 编辑；
新配方请遵循[当前 JSON 契约](../JSON_FORMAT.md)。
当前 `whimtex.document` 不下载图像，也不存储 Drawing 像素。请按上文直接粘贴图像链接，
或在[文档 JSON](ai-authoring.md)中使用已验证的项目资源引用。

如果绘制似乎被阻止，请尝试按 `Ctrl+D`。
