# 图层与组

用多个独立的图层来构建图像，这样你就能单独移动或调整每个部分。
列表顶部是图像的前面。

## 添加图层

使用 Layers 底部的 **+** 来选择类型：

| 图层 | 用途 |
| :--- | :--- |
| File | Project 中已有的纹理。 |
| Drawing Layer | 绘制、擦除和填充。 |
| Color Fill | 单色的背景或形状。 |
| Gradient | 平滑的颜色过渡。 |
| Noise | 生成的图案。参见 [Noise](noise.md)。 |
| Shape | 可编辑的矩形、椭圆、多边形、星形或直线。 |

你也可以将 Project 中的纹理拖到预览上，把它添加到顶部，
或将它放到行与行之间来选择位置。新指定的图像会保持其原始比例。
将 HDR 纹理指定给 File 图层会把 **Color Range** 和 **Blend Range** 设置为 **HDR**。
之后你可以在 **Color & Blending** 中更改这两项。

引用另一个 WhimTex 文档的 File 图层会在行的左边缘显示细橙线。
双击缩略图或行背景即可打开该文档，不替换当前文档。已打开的文档会获得焦点；
否则 Unity 会尝试在现有 WhimTex 窗口旁添加一个 WhimTex 标签页，若失败则使用单独的窗口。
双击文本或数字字段仍会编辑这些字段。

效果图层也会显示结果缩略图，动画 Shader FX 使用静态图像。

## 绘制形状

选择 **Shape**（`U`），在预览标题栏中选择一个形状，然后拖动即可创建它。
新图层会按图形命名，例如 **Rectangle 1**、**Line 2** 或 **Star 3**，所有形状共用一个编号序列。
你也可以短暂按住 Shape 工具按钮，或从它开始拖动，以在其右侧打开图标列表。
将鼠标移到某个图形上并松开即可选中它。在列表外松开会取消选择。
每次拖动都会添加一个独立的 Shape 图层，在空文档中也是如此。
按住 `Shift` 可获得等比例或 45° 步进角度的直线；`Ctrl` 会绕过参考线吸附。
在松开前按 `Escape` 可取消。

使用 **Transform** 来移动、缩放或旋转已有的图形。在 **Properties (Shape)** 中，
可以更改其类型、填充和描边颜色、矩形圆角、多边形边数或星形角数和内半径。
对于矩形，**Roundness (%)** 在正方形周围有四个字段，每个角一个。
拖动它们的 **TL / TR / BR / BL** 标签即可调整数值，无需输入。
链条图标会链接按比例的变化；带叉的链条让你独立编辑每个角。
链接会保留现有数值。当某个角达到 100% 时，链接的变化停止；编辑值为零的角
会给四个角都加上相同的量。示意图显示的是形状经过 Transform 旋转之前的样子。
描边位于边缘内侧，其宽度以画布像素为单位。
对于直线，使用 Transform 调整其长度和粗细。
你也可以通过 **+ → Shape** 创建一个居中的形状。

Shape 保持可编辑：它能像其他图层一样使用剪贴蒙版、混合和 FX。
例如，在它上面放一个 Gradient 并启用该渐变的剪贴蒙版，即可为图形上色。
只有在你想直接在它上面绘制时，才将它转换为 Drawing。

## 选择与排列

点击某一行即可选中它。按住 `Ctrl` 可选择多个图层，按住 `Shift` 可选择连续范围。
**最后选择的图层是活动图层**：你就在这个图层上绘制，并在 Layer Settings 中编辑它。

拖动某一行的缩略图、空白区域、名称、不透明度字段或眼睛图标，即可移动所选图层。
将拖动的图层保持在列表顶部或底部边缘附近，即可滚动到可见区域之外的图层。
在名称和不透明度字段中，上下拖动可移动图层；左右拖动可选择文本。
当某个字段处于编辑聚焦状态时，拖动只会选择文本；离开该字段后即可再次从它移动图层。
从字段开始拖动会取消其未确认的输入；拖动眼睛图标不会切换可见性。
用 `Enter` 或离开字段来确认名称和不透明度的编辑。
直接在行中编辑名称。**Opacity** 控制图层的显示程度；
**Blend** 控制它与下方图像的混合方式。
在选中的行上更改其中任一项都会更新所有选中的图层。

使用眼睛图标隐藏图层。列标题中的眼睛图标会显示所有图层。

## 编辑图层设置

所选图层的设置分为四个折叠区：

- **Transform:** 位置、尺寸、旋转和平铺。
- **Color & Blending:** Opacity、Blend Mode、颜色范围和 Swizzle。Opacity 和 Blend Mode 也可在 Layers 列表中使用。Standard/HDR 选择器仍保留在标题栏中。
- **Properties (layer type):** 该图层特有的设置，例如其源纹理、效果目标或绘制对称。
- **FX:** 添加和调整着色器效果。

通过 **图层菜单 ⋮ → Properties** 可在独立窗口中打开相同的设置。
不适用于所选图层的部分会变灰。

## 将相关部分放在一个组中

选择图层并点击 **Folder**，或将图层拖入已有的组。
使用组的箭头展开或折叠它。

组默认处于 **Pass Through**，因此其图层可以与组外的图层混合。
选择其他混合模式可将组作为一张图像进行混合。组不透明度会让整个组淡出。
变换和 Shader FX 可用于单个图层，而不是组。

## 复制、合并或删除

右键点击某一行，或打开 **⋮** 对所选内容执行操作。
**Duplicate** 会创建一个可以单独编辑的副本。File 图层仍使用相同的源纹理。

| 底部图标 | 点击 | 放置所选图层 |
| :--- | :--- | :--- |
| **+**（类型菜单） | 选择图层类型。 | 复制。 |
| **Page +**（带加号的纸张） | 添加绘制图层。 | 创建合并后的绘制副本。 |
| **Folder** | 将所选内容成组。 | 成组。 |
| **Trash** | 删除所选内容。 | 删除。 |

当你想在合并后的结果上绘制时，请参见[合并与转换](transform.md#合并图层或将它们转换为-drawing)。

## 修复缺失的图层

类型不可用的图层会保留其名称、位置、可见性和通用设置。
组还会保留其子级。选择该行即可在 Layer Settings 中看到警告。
选择 **Replace with**，然后点击 **Replace Behaviour**。**Transfer saved settings** 会转移旧图层类型的兼容设置。
面板会列出无法转移的内容；保存前请检查结果。包含子图层的组只能恢复为组。

不可用的图层仍可移动、隐藏或删除，恢复前不会显示在画布上。

没有自动转换。请用原来的 WhimTex 版本保留这些文档，
或在更新之前在其中导出它们的图像。
