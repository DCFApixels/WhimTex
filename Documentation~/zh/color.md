# 颜色、HDR 与通道

普通绘制时，关闭 **HDR** 并开启 **R / G / B / A**。更高亮度、通道遮罩和纹理数据的设置见下文。

## 选色与历史

单击颜色字段或双击渐变颜色关键点，打开 WhimTex Color Picker。
先在色相环上选择色相，再用中央方块调整饱和度和明度。
原色与新色位于右上角；更改实时预览。

关闭窗口确认颜色，按 Escape 恢复打开时的颜色。窗口没有确认按钮。

### 输入颜色

使用 **RGB 0–255**、**RGB 0–1** 或 **HSV** 输入数值，用 **A** 调整透明度。
数值模式会在不同选择器和 Unity 会话间保留；切换模式不改变颜色。
通道滑块显示渐变，透明度滑块带棋盘格背景。

**Hexadecimal** 接受以下格式，不区分大小写，可带或不带 `#`：

| 格式 | 示例 | 透明度 |
| :--- | :--- | :--- |
| RGB | `FFAA66` 或 `FA6` | 保持不变 |
| RGBA | `FFAA6680` 或 `FA68` | 可编辑时更新 |

按 Enter 或离开字段应用。字段始终显示六位 RGB，左侧有独立的 **#** 前缀。

### HDR 与查看曝光

**HDR** 允许 RGB 超过 1。限定 Standard 或 HDR 的字段会锁定该开关。
仅切换开关保留原色；在 Standard 下编辑则替换为受限范围内的颜色。

| 控件 | 效果 |
| :--- | :--- |
| Exposure | 按曝光档位修改实际 HDR 强度，只影响 RGB，不影响透明度。 |
| Preview EV | 仅调整显示亮度，范围 −10 至 +10。保存的颜色和数值不变。 |

降低 **Preview EV** 可查看高亮颜色。它影响方块、滑块渐变及颜色/History 色块，
不影响色相环、屏幕滴管、棋盘格或透明度。每个新窗口从 0 开始。
其页脚样式与渐变编辑器一致，但两者的曝光设置独立。

### 用滴管取色

选择器滴管会将色相环替换为放大的像素网格，并框出采样像素。
选择或取消取色后恢复色相环。取色时按 Escape 只取消滴管，窗口保持打开且颜色不变。
如果 Editor 无法显示放大预览，普通取色仍然可用。

在 WhimTex 中按 Alt 取色也会更新该窗口已打开的**主画笔颜色**选择器，包括数值和标记。
图层、渐变和次颜色选择器不受影响。没有对应选择器时，Alt 仍改变主画笔颜色。
白色滴管以左下方尖端作为取色点，不带单独的箭头。History 色样使用相同的光标。

### 复用 History 中的颜色

**History** 随文档保存。确认的颜色放在最前面，不记录滑块的中间值。
确认已有颜色时，即使是手动输入，也会将它移到最前面而不重复添加。
匹配包括透明度和 HDR 强度。文档外的字段没有 History。

| 操作 | 结果 |
| :--- | :--- |
| 单击色块 | 应用颜色，并移到 **+** 后的第一个位置。 |
| 单击 **+** | 添加当前颜色，不关闭选择器。 |
| 在 History 内拖动 | 调整顺序。 |
| 拖出区域，出现红框后松开 | 删除颜色。松开前移回区域或按 Escape 可取消。 |
| 右键 → Remove，或 Delete/Backspace | 删除选中色块。 |

删除色块不会改变使用该颜色的图层。主动进行的 History 操作在随后按 Escape 取消选色后仍然保留；
取消的手动颜色编辑不会记录。

**关闭 HDR** 时，History 隐藏 RGB 超出 0–1 的颜色，但不删除它们。
渐变编辑器按所选颜色关键点的 HDR 模式筛选，透明度不影响筛选。

渐变编辑器的 History 位于 **Presets** 上方，没有 **+**。
选择颜色关键点后单击色块即可应用 RGB 和 HDR 强度；透明度关键点和关键点位置不变。
透明度关键点及中点不能使用调色板。拖动排序和删除与选择器一致。

History 和渐变 Presets 会记住跨会话的展开状态。

## 查看单个通道

页脚的通道按钮可以让你分别查看图像的各个部分：

- **仅 R、G 或 B：** 以黑白方式显示该通道。保持 A 开启可保留透明通道。
- **仅 A：** 以黑白方式显示透明通道。
- **多个颜色通道：** 保留这些通道的颜色，隐藏其他通道。
- **关闭 A：** 查看不含透明通道的颜色。

这些按钮仅改变显示。要在绘制时保护通道，请使用画布视图顶部的 **Write R/G/B/A**，
详见[绘制指南](painting.md#稳定笔触并保护通道)。

### 颜色选择器中的通道视图

颜色选择器中的 **Channels** 会让文档颜色（画笔、图层、渐变关键点和 FX）跟随画布视图的 R/G/B/A 按钮。关闭后恢复普通颜色显示。色相环、方块和滑块渐变会相应变化；色块沿对角线分为左上方的原始颜色与右下方的通道视图。共用的一条透明度条始终表示实际透明度。RGB/HSV/HEX 数值与 History 中保存的颜色不变，隐藏通道仍可编辑。

此开关会在重新打开选择器时保留。参考线、UV 和棋盘格等界面颜色不受影响。滴管放大预览始终显示真实屏幕像素。图层预览的通道按钮独立，不影响颜色选择器。
HDR 颜色字段的两个对角区域均保留强度渐变，共用透明度条仍显示保存的透明度。

## 绘制明亮的 HDR 颜色

开启画布视图底栏中 EV 旁边的 **HDR**，即可选择 RGB 数值超过普通白色（1）的颜色。
这对你想配合泛光使用的发光细节很有用。

HDR 数值是真实的，但当前 WhimTex 编辑器预览（包括颜色选择器和渐变编辑器）以 SDR 显示。仅连接 HDR 显示器不会让这些预览产生额外的实际亮度。降低 **Preview EV** 可查看高亮数值而不修改颜色；颜色字段中的强度渐变只是视觉指示，并非 HDR 显示输出。颜色选择器、渐变编辑器和画布视图的曝光控件相互独立。

在 **Layer Settings → Rendering** 中，从标题栏下拉菜单里选择 **HDR**，
让图层保留这些额外的亮度。普通作品通常选择 **Standard**。

HDR 按钮控制的是取色；它不会转换你已有的图像。
关闭它后，你可以用该颜色绘制，但不带额外强度。
重新开启会恢复该强度，除非你在此期间编辑过这个颜色。
渐变编辑器有针对所选颜色关键点的独立 HDR 开关，不跟随画布视图底栏的共享 HDR 设置。

## 微调图层的颜色范围

大多数工作中你可以让 **Rendering** 保持折叠。展开它可以分别设置两个范围：

| 设置 | 控制内容 |
| :--- | :--- |
| Color Range | 图层本身是否保留额外亮度。 |
| Blend Range | 它的混合是按该额外亮度进行，还是在普通范围内进行。 |

折叠标题中的下拉菜单会同时更改这两项设置。
值为空表示两者不同。

切换到 Standard 不会清除已存储的 HDR 颜色。
只有当你希望永久降低所存储的颜色范围时，才使用 **Convert to 8-bit**。

## 编辑渐变

新渐变默认使用 **Color Mode → Perceptual** 和 **Interpolation → Balanced**。
Pattern 渐变明确使用 Linear 颜色模式。每个渐变独立保留这些设置。

### Color Mode 与 Interpolation

渐变字段采用 Unity 标准字段高度，并与相邻控件对齐。
点击字段编辑颜色和透明度。这两个设置相互独立：

| 设置 | 效果 |
| :--- | :--- |
| Color Mode → Linear | 在线性 RGB 中混合，适合光强混合。 |
| Color Mode → Gamma | 混合经过编码的 RGB 分量。 |
| Color Mode → Perceptual | 在 OKLab 中混合，使感知上的变化更均匀。 |
| Color Mode → Hue | 在 OKLCH 中混合亮度、色度和色相，并选择色相路径。 |
| Interpolation → Blend | 每对关键点之间独立过渡。 |
| Interpolation → Balanced | 根据相邻关键点和中点构建单调过渡曲线。 |
| Interpolation → Smooth | 每段使用固定的缓动曲线。 |
| Interpolation → Adaptive | 根据相邻关键点调整曲线；中点控制形状，不保证该位置恰好为两色的中间值。 |
| Interpolation → Fixed | 形成清晰的颜色和透明度阶梯。 |
| Interpolation → Custom | 直接编辑各通道独立的曲线、关键点和切线。 |

**Smoothness** 只在 Blend 和 Balanced 中显示。**Chroma Correction** 降低相反颜色之间
的色度，零表示关闭。**Hue Path** 只在 Hue 中显示，可选 Shortest、Longest、Increasing
或 Decreasing。Fixed 禁用 Chroma Correction 和 Hue Path，但保留其数值。
透明度使用所选插值及自身的关键点与中点；颜色模式、色相路径和色度校正不影响透明度。

两个颜色关键点之间的 RGB 保持在 0–1 内，除非关键点本身扩大此范围。
HDR 和负分量会扩大三个通道共用的上下限；例如，两个关键点的最小分量为 −0.2、
最大分量为 4 时，允许范围为 −0.2…4。关键点本身保持不变。
超出上下限的中间值会被裁剪，因此过渡可能出现平坦区段或色相变化。

小菱形调整过渡中点。Fixed 忽略中点和 Smoothness。
**Wrap** 控制 0–1 以外的值：Clamp 保持端点颜色，Repeat 重复渐变，Mirror 交替镜像。
Repeat 不会消除首尾颜色不同产生的接缝。

### 编辑 Custom 曲线

选择 **Interpolation → Custom**，再打开 **Edit Curves**。首次切换会近似拟合当前
渐变；以后切换回来会恢复手动曲线，自动模式的设置单独保留。拟合可能略微改变结果，
尤其是尖锐或突变的过渡。

曲线窗口在 Linear/Gamma 下显示 R/G/B，在 Perceptual 下显示 L/a/b，在 Hue 下
显示 L/C/H；透明度始终使用独立通道。单击原始曲线可激活对应通道，双击曲线附近可在曲线上添加关键点。
第二次按下后保持按住即可立即拖动新点；曲线窗口色带也支持此操作。
选择该时间位置最近的可见通道；曲线重合时优先选择当前通道。空白区域和 Wrap 延伸线
不会创建关键点，Output 仍只用于预览结果。可以修改位置、
数值和切线，支持负值及 HDR。切线模式包括 **Auto**、**Smooth**、**Broken**、
**Linear**、**Constant**。Constant 与 Fixed 一样，在两点之间使用右侧关键点的值；
恰好位于关键点时保留该点的值。
最终渲染中的尖锐 Custom 阶梯可能略有柔化。

网格刻度固定在曲线坐标上，平移视图时数值保持不变。两轴主网格线的最大间距均为
0.5。网格线和标签采用十进制 1–2–5 间距，例如 0.5、0.2、0.1、0.05 和 0.02。
越细的线条越透明，放大时平滑变得清晰；重合的刻度只绘制一次。数字标签独立选择
间距，不设上限，保持疏朗且省略小数末尾多余的零。标签使用固定的轻微透明度；
缩放只决定显示或隐藏，不改变标签透明度。
零坐标线略亮。任一坐标轴超出 0–1 的区域背景略暗，角落不会重复加深。
时间 0–1 以外的曲线以半透明线条按 **Wrap** 模式延伸：Clamp 保持端点数值，
Repeat 重复曲线，Mirror 交替镜像。Repeat 接缝不会用斜线连接不同的端点数值。
关键点仍只显示在原始区间内。
启用 **Output** 时，区间外只显示最终曲线；原始曲线仍在 0–1 内用于对比，
避免区间外的半透明线条重叠变亮。

图表与紧贴其下方的渐变色带具有相同的左右边距，两者之间没有空隙。色带随水平可见区间
及 **Wrap** 更新，包括 0–1 之外的区域；纵向导航不改变色带颜色。图表包含刻度标签和滚动条
下方的区域。刻度标签叠加在图表顶部和左侧，
滚动条轨道透明，滑块为半透明，悬停或拖动时会更明显。按住鼠标中键平移时，光标显示为手形。
底部滚动条控制时间，右侧控制
通道数值。拖动滑块中部可平移，拖动任一端可单独缩放该轴，点击轨道可将视图中心
移至该位置。导航范围不会随平移扩大，因此滑块长度和拖动灵敏度保持不变。
Ctrl+滚轮只缩放纵轴。Escape 取消当前拖动，**F** 显示时间 0–1 和可见通道，
遇到负值或 HDR 值时按 0.25 的步长扩展数值范围。这些操作不会修改关键点。
滚轮及滚动条端点缩放不设固定的最小或最大倍率，仅受数值精度限制。
极度缩小时，小于一个像素的 Wrap 重复会显示为淡色数值范围带，不再逐个绘制。

**Output** 位于图表下方，通道按钮在同一行右侧。按钮沿用 Canvas View 页脚的样式和
操作方式：单击切换通道，按住鼠标拖过多个按钮可将第一颗按钮切换后的状态应用于经过的
按钮。通道名称随所选颜色模式变化。界面不再显示 Fit 按钮。

曲线窗口色带将 **t** 相差不超过 0.00001 的关键点合并显示为一个标记，包括透明度通道。
拖动标记会一起移动它代表的点；直接拖动曲线上的点则独立编辑该点。拖动开始时确定成员，
不保存永久关联。双击 0–1 内的色带空白处可为四个通道添加关键点。Wrap 重复区间不显示关键点副本。
仅含透明度关键点的标记以白色覆盖棋盘格：透明度为 1 时呈白色，为 0 时显示棋盘格。
标记主体显示居中的 2×2 棋盘格；同尺寸的正方形格子延伸到三角尖端，按轮廓裁剪而不拉伸。
同时包含颜色关键点的合并标记仍显示颜色。
关键点会吸附到其他点的时间位置以及时间、数值的 0 和 1 边界。在 **Repeat** 下，沿左右
边界拖动关键点时，还可纵向吸附到同一曲线另一端的高度。

普通渐变编辑器及画布操纵器也会合并重合的点。编辑器保留独立的颜色与透明度轨道，
Canvas View 只显示颜色标记。透明度可在渐变编辑器或曲线窗口中编辑；所有窗口的标记都不再显示彩色通道小点。
Custom 标记直接位于渐变直线或圆弧上，圆点和边框与普通渐变操纵器一致。
圆弧闭合时，两端共用一个双色手柄。
双击标记会在曲线窗口中选中对应点。添加颜色标记会在同一位置创建三个独立颜色关键点，
编辑器的透明度轨道只添加透明度点。任一所代表的通道遇到未选中的相邻点时，标记停止移动。

将曲线窗口的色带标记拖到色带上方或下方并松开，即可删除它代表的关键点。
待删除标记会变淡并显示红色边框；松开前拖回色带可取消删除，Escape 取消整个拖动。
删除色带标记会删除它代表的点；在曲线窗口删除点只删除该点。每个通道至少保留一个点。
Custom 忽略 midpoint、Smoothness、Chroma Correction 和 Hue Path。最终颜色仍受
上述可扩展 RGB 范围限制，因此输入曲线与最终颜色可能不同。更改 Custom 的颜色模型
时使用 **Convert Color Mode**，以近似保留外观；转换可能改变关键点及切线，Undo 可以恢复原曲线。

### 编辑关键点

色带左侧的窄颜色字段可同时修改所有颜色关键点。灰色色块上从左下角延伸到右上角、带深灰色阴影的白色对角线表示颜色不同，字段仍可编辑；关键点位置、中点和透明度保持不变。在颜色选择器中按 Escape 可恢复原来的颜色。右侧等宽的环形箭头按钮会反转颜色和透明度两条轨道及其中点。这两个操作均支持 Undo。

在 Custom 之外，双击渐变编辑器的颜色关键点标记可打开颜色选择器。单击选择关键点，拖动则改变其位置。
关闭颜色选择器或按 Escape 取消后，焦点返回渐变编辑器，渐变编辑器不会一起关闭。
需要更高亮度时，可为所选颜色启用 **HDR**。沿垂直方向将关键点拖离轨道即可删除，
每条轨道至少保留一个关键点。右键点击字段可 **Copy / Paste**，粘贴的是独立副本。
SDF 和 Noise 渐变默认使用 **Perceptual**。

启用 `WHIMTEX_DEEP_DEBUG` 后，渐变色带下方会显示 RGBA 曲线图。
**R / G / B / A** 按钮可分别显示或隐藏曲线。曲线使用渐变自身的 Linear/Gamma 色彩空间，
RGB 不乘以透明度；纵轴范围包含负值与 HDR 数值。**Preview EV** 和通道按钮不会修改这些数值或渐变。

### 保存和复用渐变


在 **Presets** 中点击 **New** 色带保存当前渐变，无需命名。点击预设色带即可应用；
右键提供 **Copy** 和 **Delete**。User Settings 中选择预设文件夹，渐变保存在其
**Gradients** 子文件夹中；**↻** 刷新列表。删除的预设可从 **Gradients/.trash** 恢复。 无法读取的预设文件会在加载预设库时跳过。
不导入 Unity 渐变预设库。
新预设出现在列表开头，紧随 **New** 之后。

点击 Presets 中的 **Import…** 可导入 `.grd` 库，生成独立的用户预设。
来源的 Classic/Linear/Perceptual 对应 Gamma/Linear/Perceptual 颜色模式，并使用 Blend 插值。
保留关键点、中点和 Smoothness；警告会说明过渡曲线可能与来源不同。
缺失或无法识别的插值模式使用 **Perceptual**；缺失或无法识别的 Smoothness 使用 **100%**。
foreground/background 关键点会变为黑色/白色。噪声渐变、不支持的颜色模型及超过 64 个关键点的轨道
会跳过并给出警告，不会被静默替换为其他渐变。

**Paste** 也接受 AI 或其他应用提供的渐变 JSON。复制完整的
[渐变 JSON](../AI/README.md#standalone-gradient-json)，然后右键点击渐变字段或编辑器中的渐变色带，选择 **Paste**。

不再接受旧版渐变 JSON。请使用当前渐变格式；
已移除的字段和旧名称不会迁移。

### 在画布上调整渐变形状

选择 **Fill** 旁的 **Gradient**，在 Canvas View 顶部选择类型并编辑渐变，然后拖动。
按住或拖动工具栏按钮可展开子类型列表，在 **Linear**、**Radial**、**Angular**、**Square** 或 **Freeform** 图标上松开即可选择。每种类型都有对应的渐变图标；按钮显示当前类型，并与顶部的 **Type** 同步。单击按钮会启用上次选择的类型。
以小箭头尖端定位，渐变图标位于其右下方。
画布光标会显示所选渐变类型，并在切换时立即更新。

工具顶栏的 **Type** 和图层 Properties 中的 **Gradient Type** 使用相同的一行五个图标。单击切换类型；当前类型高亮显示，悬停可查看名称。

Linear 统一了水平与垂直渐变：拖动端点或旋转图层即可设置任意方向。

Linear 以拖动位置为起点和终点；Radial、Angular 和 Square 以起点为中心。
**Freeform** 创建三个呈三角形排列的点：拖动设置两个顶点，同时预览第三个顶点。拖动时，三个预览点都会显示各自的色带颜色。颜色和透明度取自当前渐变色带的起点、中点和终点，并保留 HDR。松开后立即进入点编辑。
**Shift** 将角度约束为 45° 步长，**Ctrl** 禁用吸附，**Escape** 取消创建。
每次拖动创建一个独立可编辑的 Gradient 图层；单击不创建图层。
所有类型的初始变换在画布像素中都是正方形，因此在矩形画布上切换为 Radial 后也会得到圆形。
对于 **Angular**，创建时的线段只设置中心和方向。松开后恢复为单位正方形，与拖动长度无关：正方形画布上的 Scale 为 1 × 1，矩形画布则按较短边适配。
工具设置不改变现有图层。选择 **Gradient Handles** 可编辑已创建的图层；Freeform 在创建后会自动启用该工具。
所有画布渐变在可拖动的颜色点和控制柄上显示手形光标，在点击可添加颜色关键点的位置显示带加号的箭头。填充和描边渐变也遵循此规则。

选中 Gradient 图层后，会自动启用手形图标的上下文工具 **Gradient Handles**。方形控制柄调整几何形状，彩色点移动颜色关键点。
点击连线可添加关键点；双击彩色点可直接打开 WhimTex Color Picker。透明度关键点仍在渐变编辑器中调整。
拖动小菱形可移动颜色过渡的中点（Fixed 模式除外）。
预览获得焦点时按 Delete 可删除所选颜色关键点，也可将其拖离连线后松开。至少保留一个颜色关键点。
位置、大小和旋转均由图层变换控制，不再提供单独的 Center 和 Radius 设置。径向、菱形和方形渐变均支持移动、缩放和旋转。
**Angular** 的中心用于移动渐变；拖动起始射线可旋转渐变而不打开圆环。
圆弧未闭合时，以更细、更淡的辅助线补全圆环。
完整圆环显示一个双色控制柄，两半分别代表独立的 0% 和 100% 颜色关键点。双击某一半可编辑其颜色。
顺时针拖动会分离终点，逆时针拖动会分离起点；两个端点靠近时重新合并控制柄，但不会合并颜色数据。
圆弧通过 **Repetitions** 设置一个周期的长度；弧外仍使用 **Repeat/PingPong**。
拖动圆弧端点时按住 **Ctrl**，可将 Repetitions 吸附到整数（1、2、3… → 360°、180°、120°…），另一端保持不动。拖动过程中可按下或松开 Ctrl，在整数步进与连续调整之间切换；旋转、中心移动和中间关键点不受影响。
**Start Angle** 独立于图层变换旋转渐变。点击圆弧添加颜色关键点，沿弧拖动中间关键点或中点菱形；Escape 取消拖动。
Repetitions 小于 1 时只显示周期的可见部分，起始控制柄用于旋转，周期长度仍在 Properties 中调整。控制柄没有工具提示。
选择基本工具可隐藏控制柄；没有拖动时按 Escape 可返回上次的基本工具。点击上下文手形按钮可恢复控制柄；选中其他 Gradient 图层时会自动启用它们，但 Gradient 创建工具、Crop 和 Comment 保持当前工具。

同一 **Gradient Handles** 工具也可编辑 **Shape** 和 **Vector** 图层的线性、径向、方形、菱形和圆周填充。选中带渐变填充的形状后，点击上下文手形按钮；仅选择形状不会自动启用控制柄。控制柄只改变填充，不改变形状或图层变换。线性渐变的两端可独立移动；移动其他填充的中心时，方向和半径控制柄会一起移动。颜色关键点和中点菱形的操作与上文相同。

圆周填充沿用双色端点控制柄、打开与闭合手势、淡色补全圆弧和 Ctrl 整数吸附。起始射线旋转填充；Properties 中的 **Center**、**Direction** 和 **Repetitions** 与控制柄同步。第一个周期以外使用调色板的 **Clamp/Repeat/Mirror**。若子形状的外观由 Boolean Group 样式替代，则不显示其填充控制柄；Combine 使用图层外观时仍可编辑。

**Boolean Group** 的公共填充也支持这些控制柄，包括圆周渐变。选中组即可编辑其渐变，不移动组或内部形状。在 **Combine → Appearance: Layers** 模式下，组控制柄隐藏；请选择子图层来编辑它自身的填充。

新建 Color Fill、Gradient 和 Noise 图层默认使用 **Unbounded** 平铺模式。

### Freeform 自由渐变点

选中 **Gradient** 图层，在 Properties 中选择 **Gradient Type → Freeform**。
对于 **Shape** 和 **Vector**，在 **Fill → Type** 或 **Stroke → Type** 中选择 **Freeform**。
填充与描边分别保存各自的点。图形需要手动启用 **Gradient Handles**，
再用工具栏的 **Fill / Stroke** 选择要编辑的点集。
使用 **Gradient Handles** 在画布上自由放置颜色点：

- 点击空白位置添加点；按住鼠标即可立即拖动新点。
- 拖动颜色点调整位置；双击可编辑颜色和透明度。
- 可添加新点的位置显示加号光标；颜色点和影响范围手柄上显示手形光标。
- 拖动所选点的方形控制柄，或调整 **Influence (%)**。数值越大，该颜色相对于其他点占据的区域越大。
  轮廓只是影响范围的参考，不是硬边界。
- **Point** 按编号选择点，**Position**、**Color** 和 **Opacity** 编辑所选点。
- 画布获得焦点时按 **Delete**，或点击 **Delete Point** 删除点。至少保留一个点，最多支持 64 个。
- **Escape** 取消拖动，包括刚添加的点。Undo/Redo 将整个手势作为一次操作。

颜色在线性空间平滑混合，支持 HDR 和透明度。要在结果中保留高于白色的亮度，
请将图层的 **Rendering → Color Range** 设为 **HDR**。
切换 Gradient Type 会保留 Freeform 点和普通渐变色带。
Freeform 可用于 Gradient 图层、Shape/Vector 填充与描边，以及 Boolean Group 样式。
文本和 SVG 导出保持不变。

### 选择过渡形状

Blend 适合独立的缓动过渡，Balanced 会考虑相邻关键点。
Smoothness 0% 去掉平滑贡献，100% 完整应用。Smooth 使用固定缓动曲线，
Adaptive 根据周围关键点调整形状；两者均不使用 Smoothness。
切换插值不会移动关键点。窄过渡仍由现有渲染调色板近似，
选择插值模式并不保证所有结果都没有可见色带。

## 用 Channel Mapping 重新排列通道

在 **Layer Settings → Rendering → Mapping** 中，选择图层或组的每个输出通道写入什么内容。
例如，在 R、G 和 B 三个字段中都选择 R，即可用红色通道生成灰度图像。

每个字段都可以选择原始通道、它们的反相、黑（`0`）、白（`1`），
或颜色通道乘以透明通道（`R * A`、`G * A`、`B * A`）。
`Luminance` 将 RGB 合成为灰度亮度；`Luminance * A` 还会计入透明度。
`1 - Luminance` 反转此 RGB 亮度：黑色变白，白色变黑，不受输入 Alpha 影响。
列表先显示原始 RGBA 和 Luminance，然后是它们的反相、乘以 Alpha 的结果，最后是常量 0 和 1。

右侧箭头按钮提供内置预设：

- **Default：** 恢复 `R G B A`。
- **Default without Alpha：** 保留 RGB，并使图像完全不透明（`R G B 1`）。
- **R**、**G**、**B：** 将亮度写入所选颜色通道，另外两个颜色通道设为 `0`，Alpha 设为 `1`。
- **Luminance to Alpha：** 将 RGB 设为白色，并把亮度写入 Alpha（`1 1 1 Luminance`）。
- **1 - Luminance to Alpha：** 将 RGB 设为白色，并把反转亮度写入 Alpha。
- **Alpha to Grayscale：** 将 Alpha 显示为不透明的灰度图像（`A A A 1`）。

更改某个组的 Mapping 会把它的内容视为一张图像，因此外部混合看起来可能不同。

### 将灰度转换为透明度

1. 选择灰度图层。如果自己绘制遮罩，保持 Canvas View 的所有通道按钮开启，并使用不透明颜色。
2. 在 Mapping 的预设菜单中选择 **Luminance to Alpha**。黑色变透明，白色变不透明，灰色变半透明；RGB 设为白色。
3. 若要保留原图的透明度影响，将 A 字段设为 **Luminance * A**。
4. 在 [Layer Preview](preview.md#图层预览) 中只开启 **A** 来检查结果。这里的通道按钮只控制查看，不限制绘制。

要使用相反的遮罩，在 Mapping 预设菜单中选择 **1 - Luminance to Alpha**：黑色变不透明，白色变透明，RGB 设为白色。此预设不计入图像的原始透明度。

若要用它遮罩另一个图层，选择目标图层并添加 **FX → + Preset → Color → Mask**。
将遮罩纹理来源设为 **Layer**，选择遮罩图层，并将 **Mask Channel** 设为 **Alpha**。
在 **Apply To → Channels** 中只开启 **A**，即可修改透明度而不改变 RGB。
遮罩图层可以隐藏，FX 仍会读取它。详见[纹理来源](shader-fx.md)。

## 打包多个遮罩

选中多个图层，然后在行菜单中选择 **Assign Channels**。
顺序为从上到下，每个图层使用它的红色通道乘以它的透明通道。

- **1–3 个图层：** 分别赋给 R、G 和 B。靠上的选中图层使用 Add 来合并遮罩。
- **4 个图层：** 分别赋给 R、G、B 和 A。此操作只设置 Mapping：在普通混合下，
  RGB 图层没有可见的不透明度，因此它并不是可直接导出的四通道组合。

该命令在图层多于四个时不可用。它会让各个图层保持独立。
