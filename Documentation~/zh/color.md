# 颜色、HDR 与通道

## 选色与历史

关闭 HDR 时，**History** 会隐藏 RGB 分量超出 0–1 范围的颜色。这些颜色仍保留在历史记录中，开启 HDR 后重新显示。渐变编辑器根据所选颜色关键点的 HDR 模式进行筛选；透明度不影响筛选。

WhimTex 颜色字段和渐变关键点会打开 WhimTex Color Picker。使用色相环、中央饱和度/明度方块、RGB/HSV、Hex 和透明度 A 选择颜色。
可直接切换 HDR；限定 Standard 或 HDR 的字段会锁定此开关。Exposure 以曝光档位调整 HDR 强度。
仅切换 HDR 不会改写原有颜色；在 Standard 中编辑会替换为有限范围颜色。
更改实时预览，关闭窗口即可确认，Escape 恢复原色。窗口不再显示确认按钮。
所有颜色选择器都会记住上次选择的 **RGB 0–255**、**RGB 0–1** 或 **HSV** 模式，重启 Unity 后仍然保留。切换模式不会改变颜色。
底部的 **Preview EV** 滑块（−10 至 +10）采用与渐变编辑器相同的样式，只调整显示亮度。降低数值可查看明亮的 HDR 颜色。它影响饱和度/明度方块、滑块渐变及颜色/History 色块，但不影响色相环、屏幕滴管、棋盘格或透明度值。数字和保存的颜色保持不变。每个新窗口从 0 开始；**Exposure** 仍用于修改实际 HDR 颜色。
Hexadecimal 左侧有独立的 **#** 前缀。可粘贴不区分大小写、带或不带 `#` 的 RGB/RGBA 十六进制颜色：`RRGGBB` / `RRGGBBAA`，也支持简写 `RGB` / `RGBA`。按 Enter 或离开字段确认。RGBA 会更新可编辑的透明度，RGB 保留当前透明度。字段始终仅显示六位 RGB，不显示透明度。HDR 曝光只影响 RGB。
Alt 取色会同步更新当前 WhimTex 窗口已打开的主画笔颜色选择器，包括通道、Hex 和选中标记。图层、渐变和次颜色的选择器不受影响。没有对应选择器时，Alt 仍照常更改主画笔颜色。

颜色选择器的滴管会暂时将色相环替换为放大的像素网格，并用边框标记采样像素。选择颜色或取消取色后，色相环恢复。取色期间按 Escape 仅取消滴管，窗口保持打开且当前颜色不变。如果当前 Editor 不支持放大预览，普通滴管取色仍可使用。

通道滑块显示颜色渐变，透明度滑块带棋盘格背景。原始颜色与新颜色位于右上角。
色相环及其选中标记的边缘会根据界面缩放进行抗锯齿处理。
两个选中标记均为白色圆环，外侧带有细而淡的黑色轮廓。
History 是可折叠的紧凑文档颜色网格，新确认的唯一颜色会插入到最前面，不记录拖动滑块的中间值。
开头的灰色 **+** 方块可添加当前颜色而不关闭窗口。即使随后用 Escape 取消选色，主动添加的颜色仍会保留。已有颜色不会重复添加。
悬停在色块上时，显示与 Alt 取色相同的滴管光标，细深色描边可提高其在浅色背景上的可见性。单击色块可复用该颜色，并将其移到 **+** 后的第一个位置；在历史区域内拖动可手动排序。拖出历史区域，出现红色边框后松开即可删除。
松开前移回区域或按 Escape 可取消删除。右键 → Remove 或 Delete/Backspace 也可删除色块。删除色块不影响已使用该颜色的图层。
不属于文档的字段没有文档颜色历史。
手动输入并确认的颜色若与 History 中已有颜色完全一致（包括透明度和 HDR 强度），该颜色会移到最前面，不会产生重复项。手动编辑的中间值及取消编辑不会自动记录颜色或将其前移。主动进行的 History 操作——单击色块、添加、排序或删除——在按 Escape 取消选色后仍会保留。

渐变编辑器也在 **Presets** 上方显示 **History**，但没有 **+** 按钮。选择颜色关键点后，单击色块即可直接应用 RGB 和 HDR 强度，无需打开颜色选择器。透明度关键点和所选关键点的位置保持不变。选择透明度关键点或中点时，调色板不可用；拖动排序和拖出删除与颜色选择器一致。

两个窗口中的 **History** 和渐变编辑器中的 **Presets** 使用相同的深色折叠标题。点击标题即可展开或折叠调色板；各区域会分别记住状态，重启后仍然保留。历史颜色仍随文档保存。

普通绘制时，请关闭 **HDR**，并开启 **R / G / B / A** 四个按钮。
当你需要更高亮度、通道遮罩或纹理数据时，再使用下面的控件。

## 查看单个通道

颜色选择器中的 **Channels** 会让文档颜色（画笔、图层、渐变关键点和 FX）跟随主预览的 R/G/B/A 按钮。关闭后恢复普通颜色显示。色相环、方块和滑块渐变会相应变化；色块沿对角线分为左上方的原始颜色与右下方的通道视图。共用的一条透明度条始终表示实际透明度。RGB/HSV/HEX 数值与 History 中保存的颜色不变，隐藏通道仍可编辑。

此开关会在重新打开选择器时保留。参考线、UV 和棋盘格等界面颜色不受影响。滴管放大预览始终显示真实屏幕像素。迷你预览的通道按钮独立，不影响颜色选择器。
HDR 颜色字段的两个对角区域均保留强度渐变，共用透明度条仍显示保存的透明度。

页脚的通道按钮可以让你分别查看图像的各个部分：

- **仅 R、G 或 B：** 以黑白方式显示该通道。保持 A 开启可保留透明通道。
- **仅 A：** 以黑白方式显示透明通道。
- **多个颜色通道：** 保留这些通道的颜色，隐藏其他通道。
- **关闭 A：** 查看不含透明通道的颜色。

这些按钮同时也会遮罩**新的绘制**。被禁用的 RGB 通道写入零；
如果 A 关闭，画笔、铅笔和填充不会留下任何痕迹。它们不会改变已有的像素。

## 绘制明亮的 HDR 颜色

开启主预览页脚中 EV 旁边的 **HDR**，即可选择 RGB 数值超过普通白色（1）的颜色。
这对你想配合泛光使用的发光细节很有用。

HDR 数值是真实的，但当前 WhimTex 编辑器预览（包括颜色选择器和渐变编辑器）以 SDR 显示。仅连接 HDR 显示器不会让这些预览产生额外的实际亮度。降低 **Preview EV** 可查看高亮数值而不修改颜色；颜色字段中的强度渐变只是视觉指示，并非 HDR 显示输出。颜色选择器、渐变编辑器和主预览的曝光控件相互独立。

在 **Layer Settings → Color & Blending** 中，从标题栏下拉菜单里选择 **HDR**，
让图层保留这些额外的亮度。普通作品通常选择 **Standard**。

HDR 按钮控制的是取色；它不会转换你已有的图像。
关闭它后，你可以用该颜色绘制，但不带额外强度。
重新开启会恢复该强度，除非你在此期间编辑过这个颜色。
渐变编辑器有针对所选颜色关键点的独立 HDR 开关，不跟随主预览页脚的共享 HDR 设置。

## 微调图层的颜色范围

大多数工作中你可以让 **Color & Blending** 保持折叠。展开它可以分别设置两个范围：

| 设置 | 控制内容 |
| :--- | :--- |
| Color Range | 图层本身是否保留额外亮度。 |
| Blend Range | 它的混合是按该额外亮度进行，还是在普通范围内进行。 |

折叠标题中的下拉菜单会同时更改这两项设置。
值为空表示两者不同。

切换到 Standard 不会清除已存储的 HDR 颜色。
只有当你希望永久降低所存储的颜色范围时，才使用 **Convert to 8-bit**。

## 编辑渐变

新渐变（包括笔尖和画笔着色渐变）默认使用 **Perceptual**，但明确指定其他模式的控件除外，例如 Pattern 渐变使用 Linear。已有渐变保留其选定的插值模式。

选中 Gradient 图层后，会自动启用手形图标的上下文工具 **Gradient Handles**。方形控制柄调整几何形状，彩色点移动颜色关键点。
点击连线可添加关键点；双击彩色点可直接打开 WhimTex Color Picker。透明度关键点仍在渐变编辑器中调整。
拖动小菱形可移动颜色过渡的中点（Fixed 模式除外）。
预览获得焦点时按 Delete 可删除所选颜色关键点，也可将其拖离连线后松开。至少保留一个颜色关键点。
位置、大小和旋转均由图层变换控制，不再提供单独的 Center 和 Radius 设置。径向、菱形和方形渐变均支持移动、缩放和旋转。
Circular 暂不提供画布控制柄。选择基本工具可隐藏控制柄；没有拖动时按 Escape 可返回上次的基本工具。点击上下文手形按钮可恢复控制柄；选中其他 Gradient 图层时会自动启用它们。

新建 Color Fill、Gradient 和 Noise 图层默认使用 **Unbounded** 平铺模式。

点击渐变字段可编辑颜色和透明度。**Classic** 提供常见的颜色混合，**Linear** 混合光强，
**Perceptual** 让颜色过渡在视觉上更均匀，**Fixed** 则创建清晰的色带。
**Smoothness** 可平滑关键点附近的过渡；小菱形用于移动相邻关键点之间的中点。
Fixed 不使用这两个设置。
新旧渐变始终使用内置的 **Rounded** 算法，不再提供 Transition 设置。无需迁移或重新保存，但旧作品的外观可能改变。
**Rounded** 优先平滑渐变与恒定颜色区域之间的衔接。速度补偿延伸至相邻中点，以减弱渐变内部的可见条带。建议使用 **Perceptual** 和 **100% Smoothness**。平滑会覆盖 0–1 范围内恒定区域边界的两侧：关键点位置不变，但该处实际颜色或透明度可能偏离存储值。位于 0、1 以及普通内部位置的关键点仍保留其值，中点位置也不变。仍会有少量近似恒定颜色区域，不能保证消除所有可见环状边缘。
Smoothness 为 0% 时，在所选工作色彩空间中进行线性插值；Fixed 使用硬色带。较窄的渐隐区间或靠近端点的中点仍可能形成可见的环状边缘。
**Wrap** 控制 0–1 范围外的采样方式：**Clamp** 固定为最近的端点颜色，**Repeat** 重复渐变，**Mirror** 则镜像重复区间。

在渐变编辑器中双击颜色关键点标记可打开颜色选择器。单击选择关键点，拖动则改变其位置。
关闭颜色选择器或按 Escape 取消后，焦点返回渐变编辑器，渐变编辑器不会一起关闭。
需要更高亮度时，可为所选颜色启用 **HDR**。沿垂直方向将关键点拖离轨道即可删除，
每条轨道至少保留一个关键点。右键点击字段可 **Copy / Paste**，粘贴的是独立副本。
SDF 和 Noise 渐变默认使用 **Perceptual**。

在 **Presets** 中点击 **New** 色带保存当前渐变，无需命名。点击预设色带即可应用；
右键提供 **Copy** 和 **Delete**。User Settings 中选择预设文件夹，渐变保存在其
**Gradients** 子文件夹中；**↻** 刷新列表。删除的预设可从 **Gradients/.trash** 恢复。
不导入 Unity 渐变预设库。
新预设出现在列表开头，紧随 **New** 之后。

**Paste** 也接受 AI 或其他应用提供的渐变 JSON。复制完整的
[渐变 JSON](../AI/README.md#standalone-gradient-json)，然后右键点击渐变字段或编辑器中的渐变色带，选择 **Paste**。

## 用 Swizzle 重新排列通道

**Swizzle** 决定图层或组的每个输出通道写入什么内容。
例如，在 R、G 和 B 三个字段中都选择 R，即可用红色通道生成灰度图像。

每个字段都可以选择原始通道、它们的反相、黑（`0`）、白（`1`），
或颜色通道乘以透明通道（`R * A`、`G * A`、`B * A`）。
更改某个组的 Swizzle 会把它的内容视为一张图像，因此外部混合看起来可能不同。

## 打包多个遮罩

选中多个图层，然后在行菜单中选择 **Assign Channels**。
顺序为从上到下，每个图层使用它的红色通道乘以它的透明通道。

- **1–3 个图层：** 分别赋给 R、G 和 B。靠上的选中图层使用 Add 来合并遮罩。
- **4 个图层：** 分别赋给 R、G、B 和 A。此操作只设置 Swizzle：在普通混合下，
  RGB 图层没有可见的不透明度，因此它并不是可直接导出的四通道组合。

该命令在图层多于四个时不可用。它会让各个图层保持独立。
