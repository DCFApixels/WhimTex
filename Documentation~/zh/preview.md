# 画布视图与导航

**Canvas View**（画布视图）是包含工具设置和底栏的整个面板。**Canvas**（画布）是其中的图像工作区，用于绘画、检查细节、接缝和各个通道。
更改视图不会改变文档尺寸。
拖动右侧分隔条可调整 Canvas View 的宽度。调整窗口尺寸时，标题栏、画布区域和底栏始终紧贴分隔条。临时缩窄窗口不会覆盖所选面板尺寸，窗口再次扩大时会恢复。按 Escape 可取消分隔条拖动。

画布上方的两行包含文档和工具设置。面板变窄时，滑块轨道会隐藏，但数值输入框仍可用：可以输入数值，也可以拖动数值字段的标签来调整。如果空间仍不足，控件会换行。

画布视图底部集中放置质量、模型纹理实时更新、平铺、参考线和通道查看设置。
这里还有用于颜色输入的 **HDR** 模式和当前工具的提示。

常驻图标栏位于画布滚动条右侧，在 Canvas View 顶栏和底栏之间，紧邻可拖动的面板分隔条；宽度和样式与主工具栏一致。**Brushes**、**Comments**、**Post FX** 和 **UV** 四个图标始终可用。
**UV** 图标是由六个正方形组成的十字形立方体展开图，较长的一端朝右。
面板紧贴图标栏左侧展开，覆盖滚动条和画布，不会将它们推开。
当前打开面板的图标会高亮；再次点击可关闭，点击其他图标可切换面板。悬停可查看名称。
仅画笔设置会在选择其他工具时禁用；**Select Brush** 位于 Brushes 标题栏右侧。**Post FX** 和 **UV** 标题前的复选框可启用或关闭对应模式，即使关闭模式也可编辑设置。Comments 无需切换工具。
关闭设置面板不会关闭 Post FX 或 UV 功能。

## Profiler

历史记录的后台写入显示为 **worker** 事件，并有独立耗时。它可与界面工作同时执行，因此不能加到主线程总时间中。**input.canvas_ready** 表示从画笔输入到更新画布就绪的延迟；可用时，**input.gpu_observed** 还包含等待 GPU 完成的时间。这不代表显示器实际显示图像的时刻。多个输入事件可能合并为一次画布更新。

在 **Capture settings** 中将 **Document ID** 留空可记录所有文档；如需只记录一个文档，请原样粘贴返回的
`profilerDocumentId` 字符串。

要排查画布更新缓慢的问题，打开 **Window → Analysis → WhimTex Profiler**，点击
**Record**（会替换上一次已停止的记录）。在 WhimTex 中重复该操作，然后点击 **Stop**；
结果会自动更新。在 **Layer** 中按图层名称或 ID 筛选，或在 **Phase** 中按阶段筛选；确认字段后选择事件查看详情。
在 **Groups** 中可多选 **UI & Input**、**Tools & Editing**、**Rendering**、**Resources & Memory**、
**Load & Save** 和 **Diagnostics**。取消勾选可隐藏分组，**All** 选中全部，**None** 清空选择；
要只显示一组，先点击 **None**，再勾选该组。数量是在应用其他筛选条件后、分组筛选前统计的；部分分组可能尚无记录。
选择会在 Refresh 和脚本重新加载后保留，同时作用于 Summary 和 Events；灰显的父级仅提供上下文。
筛选不会改变记录的计时或完整 JSON 导出。颜色区分通用分组，缓存命中、未命中及错误单独标色。
SDF、文本、形状和 FX 均属于 Rendering。缩进表示嵌套，时长条便于查找耗时阶段。
拖动分隔线可调整汇总、事件列表和详情区域的高度。
点击阶段旁的箭头可折叠或展开子事件，也可以对选中的阶段使用左右方向键。
**Expand all** 展开所有分支；**Collapse all** 折叠所有页面的分支，只保留根事件。
搜索会保留匹配事件的父级路径，折叠不会改变汇总计时。
新记录的 **Events** 按开始顺序排列，较早的阶段在上方。阶段运行时保留原来的行位置，
结束后填入时长。**Summary** 默认按总耗时从大到小排列。
点击 **Count**、**Total ms**、**Self ms**、**Max ms**、**Prep ms**、**GPU ms**、**Allocations** 或 **Self allocations** 可排序，再次点击可切换箭头方向。
**Allocations** 是主线程托管分配次数（包含子阶段），**Self allocations** 不包含子阶段；两者都是次数，不是字节。
`*` 表示部分调用的合计，悬停可查看已测量/可测量调用数。排序仅使用已测量的合计，不估算缺失部分；不可用值显示为 `—`，而非零。
窗口较窄时，Summary 的表头和数据行会一起水平滚动。
排序设置会在 Refresh 和脚本重新加载后保留。不可用值在两个排序方向下均置底，时长条始终比较总耗时。
Summary 排序不会改变 Events 的顺序。
重新编译脚本后，记录会自动恢复并重新显示。正在进行的记录会在重新加载前停止；
未完成的阶段标为 **Interrupted**，不会生成虚假的时长。
特别大的记录可能超过重新加载备份的大小限制；如需保留，请在重新编译前导出。
**Export Temp JSON** 可保存分析报告；开始新记录或关闭 Unity 前请先导出。
**Clear** 会丢弃已停止的记录。达到事件数量或时间限制时，记录会自动停止。状态和变化后的结果会自动更新；**Refresh** 仍可立即刷新。
自动更新会保留所选行、筛选、排序、折叠分支和滚动位置。
记录较大时，表格会分小步更新，并降低更新频率。准备新结果期间保留上一次完整结果，记录仍继续。
**Refresh** 会立即请求最新结果；记录较大时可能需要更长时间。
记录还涵盖笔刷印章批次和像素回读、选区修改和蒙版上传、变换、画布框修改、填充、Undo/Redo 恢复、界面刷新、加载、保存及导出。
选择 **render.trigger** 可查看画布请求的原因；**Occurrences** 表示合并到本次更新中的同类请求次数。
**cache.miss**、**cache.bypass**、**cache.release** 和 **cache.invalidate** 说明缓存决策，**Cache entry** 标识相关缓存条目。
**Latest change** 显示该文档最近一次记录的修改，以及已知的来源和图层。这只是上下文，不证明每次后续缓存未命中都由该修改引起。
原因行不表示耗时操作。笔刷的主计时包含等待和命令提交；部分绘制与混合批次也记录单独的 GPU 区间。

展开 **fx.block** 可按名称查看各个效果。**Prep ms** 显示 CPU 准备时间，**GPU ms** 显示整个 FX 块或单个效果的 GPU 时间区间；详情还单独显示 CPU 提交命令的时间。
如果需要测量首次操作的 GPU 时间，点击 Record 后请等待 **GPU ready**（启用 Graphics Jobs 时为 **GPU unconfirmed**）。GPU 结果会延迟数帧返回：**…** 表示等待中，**—** 表示不可用，**\*** 表示汇总不完整。
结果会自动更新，包括 Stop 之后；待所有查询完成后即可导出。CPU 计时包含等待；CPU/GPU 及父子阶段的区间会重叠，不能相加。详见[性能分析参考](../AgentAPI.md#profiler-captures)。
原生 GPU 时间戳为零或存在歧义时显示 **—**，不表示操作免费。GPU 区间可能包含空闲时间；小幅差异需要在相同条件下重复比较。
启用 Graphics Jobs 时仍尝试采集 GPU 计时，但返回的数字使用淡黄色背景：Unity 不支持此模式下的 GPU 性能分析，结果未经确认。
悬停可查看说明，不在每个数字旁重复文字。顶部显示实际 Graphics Jobs On/Off；配置与运行模式不同时提示重启。
记录和基线保留采集时的模式。要在受支持模式下比较，请关闭 Graphics Jobs、重启 Unity 并重新记录。分析器不会自行修改项目设置。
同步读取像素可能截断尚未完成的 GPU 时间戳。受影响的行显示 **—**，详情标为 `invalidated_by_readback`；CPU 计时及已完成的 GPU 结果保留。

要比较两次操作，停止第一次记录后点击 **Set baseline**，然后录制并停止第二次记录。
在比较的 **Metric** 中选择 **Allocations** 或 **Self allocations**，查看主线程托管分配次数（包含或排除子阶段）。
Baseline、Current、**Δ alloc** 和 **Δ %** 显示前后数值、差值和百分比，按差值绝对值从大到小排序。这些是次数，不是字节。
不完整的合计标为 `*`，提示中显示已测量/可测量调用数；只有两行均测量完整时才显示差值，否则为 `—`。
基线为零时百分比也不可用；比较时还应考虑调用次数的变化。
Δ 和 Δ % 中，耗时或分配次数减少显示为绿色，增加显示为红色；零值和不可用值保持中性色。
调用次数的差值也保持中性色。正负号仍然保留，四舍五入后显示为零的值不会着色。
在汇总区域启用 **Compare baseline**。基线独立保存：**Record** 和 **Clear** 不会删除基线，脚本重新加载会恢复两份记录。
**Clear baseline** 单独删除基线。比较显示前后数值和差值；除了总耗时，还要检查调用次数和平均耗时。
重复操作更多次会增加总耗时，并不一定表示单次操作变慢。缺失的 GPU 计时及新增/消失阶段显示 **—**，不冒充耗时降为零。
筛选同时作用于两份记录，但单次操作筛选不用于比较。评估修改时应保持相同文档、输入、质量和缓存条件。
关闭 Unity 前请导出需要保留的报告。

展开 **Diagnostics & benchmarks** 查看内存数据。独立的 **Managed allocated · all Editor threads**
一行显示记录期间所有 Editor 线程分配的托管内存总字节数，包括无关的 Editor 工作和测量代码自身的分配。
文档选择和显示筛选都不会限制这个总量；它表示这段时间内的分配量，不是当前堆大小。
事件详情显示主线程的分配**次数**，包括测量代码自身的分配：inclusive 包含嵌套阶段，self 扣除子阶段。
各阶段不提供托管分配字节数，嵌套阶段的 inclusive 次数存在重叠。
无法测量或达到记录器上限的结果显示 **—**，而不是零；达到上限时会显示提示。
面板还显示整份记录中跟踪到的纹理与原生缓存数据量，以及 Unity 全局内存采样，不受显示筛选影响。
纹理数据量不是实际显存占用，归还的 RT 仍可能留在 Unity 池中。
**Explain cause** 沿缓存依赖追踪已观察到的属性变化；缺失证据不代表没有原因，达到跟踪上限时会显示提示。
GPU 计时还覆盖常见合成、图层与变换、缓存复制、Drawing 操作和输出编码；不可用结果仍显示 **—**。

重复测量时，填写 **Document ID**，选择 Cold/Warm/Both、重复次数、预热次数和最大尺寸，再点击 **Run**。
测量使用独立文档快照，不替换当前记录或基线。中位数、p95 和范围会自动更新；**Cancel** 在操作之间停止并保留部分结果。
计时包含同步 GPU 回读，是实际经过时间而非纯 GPU 时间。Cold 使用新建的文档副本缓存，不重启 Unity、JIT 或驱动。
纹理与 Drawing 在启动时冻结；字体、网格和机器负载仍共享。完整限制见 **Method & limitations**。
当前 Unity 会话只保留最近一次基准测试，不建立归档。

## 评论

在 **WhimTex Settings → Comments → Nickname** 中设置昵称。WhimTex 优先使用个人 Unity
组织名称，在可用时保留原始大小写；无法获取组织名称时使用邮箱中 `@` 前的部分，并为所有项目保存结果。
你也可以输入自己的昵称；点击 **↺** 可按此顺序重新获取。账户信息不可用时，新消息署名为 **User**，下次打开
WhimTex 或发布消息时会重试。更改名称只影响新消息和新回复，不会修改已有消息的署名。

选择 **Crop** 正下方的 **Comment**（**N**），然后点击画布上的位置。输入内容后点击 **Post**，
或按 **Ctrl+Enter**（macOS 上为 **Cmd+Enter**）。Enter 换行；**Esc** 或关闭按钮
会关闭卡片并保留草稿。**Cancel** 才会放弃草稿。切换工具或讨论、重新加载脚本后，同一编辑器窗口会保留
文字、附件和消息编辑。**Resume Draft** 可重新打开尚未提交的新评论；在 **Post** 或 **Save** 前，草稿文字和附件只保存在本地窗口中，代理无法读取。
选中 Comment 时会显示编号标记，空画布上也可以添加评论。
文档没有评论时，右侧面板工具栏中的 Comments 图标为空心轮廓；提交评论后，图标变为实心，文字线条镂空。
已完成的评论也会计入，未提交的草稿不会计入。左侧 Comment 工具图标始终为实心，不显示状态红点。

新评论使用 **WhimTex Settings → Comments → Color**。未指定颜色时，WhimTex 根据昵称计算色相，
保持原先蓝色的饱和度和明度。设置旁的 **↺** 恢复自动颜色。修改用户颜色会更新已打开文档中
属于你的自动颜色评论；其他文档在下次打开时更新。

卡片标题栏中的色块可在提交前后为该讨论单独指定颜色；右键点击色块并选择 **Reset to Author Color** 可恢复讨论创建者的颜色。
其他作者的回复不会改变讨论颜色。所有旧评论都保留原来的颜色，视为手动指定。
浅色标记使用深色编号，以便阅读。
每条消息的作者姓名左侧都有一条 5 px 色条，使用该作者自己的颜色，不受讨论标记颜色影响，回复也一样。

点击标记可以阅读讨论或回复。消息右侧的 **⋮** 菜单提供 **Copy Text**、**Edit**，回复还提供 **Delete Reply**。
右键点击作者行的任意位置也可打开同一菜单。
编辑后显示 **edited**，悬停日期可查看编辑时间。卡片标题栏中紧靠关闭按钮左侧的垃圾桶按钮在旁边弹出的 **Cancel / Delete** 确认窗口中确认后删除整个讨论。
确认窗口默认聚焦 **Cancel**；按 **Esc** 或关闭窗口也会取消删除。
**Cancel** 保留讨论和当前草稿；**Undo** 恢复已删除的讨论及其全部消息。
不同本地日期发布的消息之间会显示低对比度的日期和细线。编辑消息不会改变其日期分组。

展开 **Filters & Sort** 可按参与作者（含回复作者）、创建或活动时间筛选，并按编号、创建时间、
最后活动或首条消息作者排序；**Descending** 切换为降序。**Custom dates** 使用本地日期
`yyyy-MM-dd`，包含起止两天，留空表示不限制该边界。最后活动指最新回复或消息编辑。
筛选同时影响列表和画布标记。屏幕上重叠的关闭标记会合并为带数量的标记；点击可选择讨论，
放大后不同锚点会重新分开。打开的卡片保留各自的标记。

在列表行的右键菜单或卡片的 ↗ 按钮中选择 **Copy Link**。将链接粘贴到 Comments 搜索框，
即可查找当前文档中的讨论。消息文字、作者和编号按子串匹配，不区分大小写；讨论自身的链接
必须完整匹配且区分大小写，仅忽略首尾空白字符。其他筛选仍然生效。
将链接粘贴到画布可直接打开讨论。含链接的消息下方会显示
**Open linked comment** 按钮。跳转会打开指定讨论并清除隐藏它的筛选。已保存文档的链接在资源
重命名后仍有效；分享新讨论前请保存文档。未保存文档使用仅在当前窗口会话有效的临时链接。
链接在 WhimTex 内打开，不会从外部应用启动 Unity。

拖动标记只移动位置，不会打开卡片；单击标记可打开讨论。
按住卡片编号旁的状态图标，移到纵向菜单的选项上再松开即可选择；也可先单击打开菜单，再单击选项。
可选状态为半填充圆形 **In Progress**（进行中）、
红色圆形 **Awaiting Review**（等待审核）或勾号 **Resolved**（已解决）。列表与状态筛选使用相同图标，
悬停可查看完整名称，三种状态可以自由切换。等待审核的讨论在列表编号旁和画布标记右上角显示红点；
只要文档中存在此类讨论，右侧面板工具栏中填充的 Comments 图标也会显示红点，即使讨论被筛选隐藏。
状态随文档保存在 TIFF 中。打开、阅读或回复不会自动改变状态；提交审核或确认完成时需要明确切换。

可以同时打开多个讨论，每个讨论都有独立卡片和连接到自身标记的线。
连接线与卡片相接处有一段较粗的短边框，会沿卡片边缘跟随连接点移动，在圆角处也保持厚度，并略微覆盖卡片内侧边缘。
外缘形成两侧内凹的短箭头，底部会在圆角处调整，标记靠近卡片时箭头随之缩短。箭头与细线在连接处宽度一致，没有横向描边。细线显示在所有卡片后方；箭头和接触处的粗边框仅位于所属卡片上方，会被层级更高的卡片遮挡。
再次点击已打开的讨论会将其卡片置于前方。关闭一张卡片不会关闭其他卡片；草稿与附件各自独立。
评论列表和已打开的卡片在任何工具下都可用。列表或卡片打开时，以及选择 Comment 时，画布标记会显示；创建和移动标记仍需使用 Comment。脚本重载会在同一窗口中保留打开状态和已修改的草稿。筛选会暂时隐藏不匹配的卡片及标记，清除筛选后恢复。
列表标题栏中 **Comments** 右侧的 **Close All** 关闭当前文档的所有卡片，包括被筛选隐藏的卡片。
讨论、草稿和附件都会保留。点击标记或列表条目可重新打开讨论；未发布的新评论可通过 **Resume Draft** 继续。
新卡片没有文字、附件或手动设置时，点击卡片外会将其丢弃；点击另一画布位置会在那里新建卡片。

## 图层预览

向上拖动 **Layer Settings** 底部的 **Layer Preview** 分隔条可查看所选图层，向下拖动可隐藏图像。独立的 **Properties** 窗口使用相同的图层预览，默认展开。整个区域位于可滚动设置下方，高度最多为 256 px（包含分隔条）；空间不足时会缩小。切换图层或图像分辨率不会改变所选高度。小图像等比例放大，大图像等比例缩小，不会裁剪。

图层预览显示图层与其他图层混合前的结果。组的预览在透明背景上显示组自身的彩色内容。

紧凑的中性灰色 **R / G / B / A** 按钮可独立切换通道，与画布视图底栏一致。单个 RGB 通道以灰度显示，**A** 控制透明度。仅开启 **A** 可查看灰度透明度，关闭全部四个通道则显示黑色。透明区域显示棋盘格。此选择仅属于图层预览，不影响画布视图、绘制、图层或保存的输出。

在画布视图或图层预览中，按住鼠标左键拖过 **R / G / B / A**，可同时切换多个通道。

## 上下文工具

工具栏分隔线下方的工具会根据当前上下文出现。只有选中 Gradient 图层才会自动启用手形图标的 **Gradient Handles**，但创建渐变或使用 Crop、Comment 时例外。编辑 Shape、Vector 和 Boolean Group 的渐变时，请手动点击手形按钮。手动启用的控制柄会在同一文档内切换到具有可编辑填充或描边渐变的图层时保持启用，包括 Gradient 图层。选择没有可编辑渐变的图层或其他工具，会结束此行为。自动启用的控制柄在切换到非 Gradient 图层时，会返回上次使用的基本工具。手动切回基本工具后，该选择会保持到活动图层改变。多选时，上下文由最后选中的活动图层决定。

启用 **UV** 会添加 **UV Island Select**，但不会自动切换工具。FX 参数的 **Edit on Canvas** 会在工具栏最下方添加一个临时手形工具。按钮提示和画布视图底栏标明正在编辑的参数；编辑其他参数会替换此临时工具。

再次点击当前上下文工具或按 `Escape`，会返回上次使用的基本工具。退出临时 FX 工具时，会返回进入前的工具，包括仍可用的上下文工具。拖动时，`Escape` 只取消当前拖动；再次按下才退出工具。操作 Inspector、打开 Color Picker 或切换应用不会退出工具。

## 网格 UV 叠加

打开 **UV** 面板，勾选标题栏中的 **UV** 并指定 **Mesh**，即可在图像上看到其 UV 岛轮廓。UV 面板可让你选择通道、子网格、线条颜色和不透明度。轮廓会跟随缩放、平移和视图旋转，且绝不会出现在导出中。要绘制模型的特定部分，请使用 [UV 岛选择](selection.md#选择-uv-岛屿)。

**Mesh** 字段也接受包含网格的模型或 GameObject；有多个网格时，WhimTex 使用找到的第一个。

利用 UV 轮廓将细节放到正确的面上。启用 [Live Update](saving.md) 后，你在绘制时可以在 Scene View 中看到模型上的画笔编辑。

## 图像过滤

**Canvas → Filter** 控制 WhimTex 内的图像采样：**Point** 保持像素锐利，
**Bilinear** 平滑像素过渡，**Trilinear** 在有 mip 层级时混合这些层级。
此设置不会生成 mipmap。Pencil 会临时使用 Point 和完整预览质量。

对于材质或精灵使用的已保存 TIFF，请在其 Unity Inspector 中设置 **Filter Mode** 和 mipmap。
PNG/JPEG/EXR 文件不会为其他应用程序保存采样模式。

## 移动视图

- 顶部和左侧标尺以像素为单位显示距离。刻度随缩放调整，标记显示指针位置。零点对应画布左上角；旋转视图后，距离沿视图轴测量。
- 右侧和底部的细滚动条用于平移视图。单击两端的箭头可小步移动，按住可持续移动。拖动滑块、单击轨道翻页，或在滚动条上滚动鼠标滚轮。即使整个画布都在视图中，也可以继续向边缘之外滚动：离开得越远，滑块越短；返回时滑块会重新变长。
- 按住鼠标滚轮并拖拽以平移。
- 按住 `Shift` 并按住鼠标滚轮拖拽，可使用任意工具旋转视图。旋转会轻微吸附到 90° 步进，以及使参考线在屏幕上水平或垂直的角度。最接近的角度胜出；按住 `Ctrl` 可跳过吸附。隐藏的参考线以及关闭了 **Snap to Guides** 的参考线不会添加磁性角度。
- 使用任意工具滚动可围绕指针缩放。
- 使用 **Zoom**（`Z`）时，单击可放大，`Alt`-单击可缩小，或拖出一个矩形框选要检查的区域。
- **Fit** 会正立显示整个画布；**100%** 适合检查像素细节。
- 在 **Zoom %** 中输入精确的百分比，然后按 Enter 或离开该字段。视图中心及其旋转保持不变。
- 在 **Zoom → Angle °** 中输入精确角度并按 Enter（或离开字段）即可在不吸附的情况下应用。**0°** 会重置旋转，而不改变缩放或平移。

视图旋转不会旋转图层，也不影响保存和导出。

**Tiled** 是画布视图底栏中位于 Guides 旁的切换按钮。开启后可查看重复图像并跨边缘操作：
绘制、擦除、填充和选区会延伸到画布的另一侧。保存的图像尺寸和图层变换不变。
参见[无缝绘制](symmetry.md)。

## 裁剪、扩展或缩放画布

选择 **Crop**（`C`）。按住工具栏按钮，或将其拖动 3 个 UI 像素，即可选择 **Scale** 或 **Resize**，然后在所需图标上松开。也可以在工具设置中选择模式。按钮的图标和提示显示当前模式；切换工具后通过 `C` 或 `Q` 返回时，会保留这一选择。

**Resize** 改变画布边界，同时保持图像的像素大小。拖动角点或边缘控制点可调整裁剪框大小，拖动框内可移动裁剪框，在框外拖动可绘制新框。裁剪框可以超出当前画布。**X**、**Y**、**W** 和 **H** 可精确定位及设定尺寸：X 和 Y 从当前画布左上角起算，负值可向左或向上扩展。

**Scale** 将整个图像缩放到新的画布尺寸，包括所有图层、区域选区和参考线。拖动裁剪框的角点或边缘控制点可预览结果，也可以输入 **W** 和 **H**。裁剪框的位置仅作为预览锚点；应用后的图像尺寸由框的宽度和高度决定。X 和 Y 会隐藏，在框内或框外拖动不会移动它或创建新框。图层及其源像素仍可编辑。

拖动角点时按住 `Shift` 可保持裁剪框比例；按住 `Ctrl` 可绕过吸附。点击 **Apply** 或按 `Enter` 可应用当前模式。应用之前，裁剪框只预览结果。**Reset** 或 `Escape` 将其恢复为当前画布尺寸；拖动过程中按 `Escape` 会先取消这次拖动。切换模式会重置预览，平移和缩放视图不会移动它。

Crop 中的 **Flip Canvas Horizontal**、**Flip Canvas Vertical**、**Rotate Canvas Left 90°** 和 **Rotate Canvas Right 90°** 图标会立即翻转或旋转整个文档，包括未选中的图层。旋转按钮每次旋转 90°，并交换画布的宽度和高度。裁剪框、区域选区和参考线会随图像一起变化。拖动裁剪框时这些操作不可用；将指针停在图标上可查看名称。若只想对所选图层执行这些操作，请使用 **Transform**。

在 Resize 模式下，裁剪会隐藏新边界之外的内容，但不会删除图层像素。扩展画布会显示旧边界之外的现有内容；没有图层内容的位置保持透明。依赖画布的程序化图案和 FX 会按新边界重新计算，因此外观可能变化。

裁剪框会吸附到画布边缘和中心、参考线及其交点，以及当前区域选区的边界。所选图层也会以 FX 之后非透明内容的合并边界吸引裁剪框，不计图层自身的 Opacity 和 Visibility。边界由 Alpha 非零的最外侧像素确定，不计透明边距。共享的 **Snap Radius (px)** 控制吸附距离；隐藏的参考线或关闭吸附的参考线不会吸引裁剪框。

**Pixel Scale** 设置一个逻辑像素占用多少画布像素，默认值为 **1**。它调整以像素表示的描边、文字、画笔和效果距离，同时保留输入的参数值。例如，宽度 3 在 Pixel Scale 为 2 时占用 6 个画布像素。画布尺寸、纹理像素和屏幕吸附半径保留各自的像素单位。

在 **Scale** 中，**Auto** 默认开启。无论等比或非等比缩放，它都会用宽度与高度缩放系数中的较小值乘以已应用的 Pixel Scale：宽度扩大两倍、高度扩大三倍时，像素尺寸扩大两倍。反复修改预览始终从已应用的文档计算。关闭 Auto 可手动输入倍率；**Resize** 也允许手动输入。倍率和框的修改在 **Apply** 前保持待应用状态。**Reset** 或非拖动时的 `Escape` 会将两者恢复到已应用的文档，同时保留 Auto 选择；Apply 后的新结果成为下一次重置的起点。

## 参考线

### 创建和编辑参考线

从画布视图左侧的标尺拖出可创建垂直参考线，从顶部标尺拖出可创建水平参考线。
从两条标尺的交角拖拽可同时创建两条参考线。取消或在画布视图之外松开会放弃两条线；Undo/Redo 也将整对参考线视为一次操作。
即使在旋转后的画布上，新线条也与该标尺平行；之后它会随画布一起移动、缩放和旋转。

拖拽现有线条可重新定位它。将其放回任一标尺或画布视图之外可删除它；`Esc` 取消拖拽。
使用任意工具都能从标尺创建参考线。移动现有参考线时，可使用 Layer Select、Zoom 或框外的 Transform；临时 FX Edit on Canvas 工具也支持在控制点之外操作参考线。Transform 控制点及其框内区域优先，包括多图层变换和临时 FX 变换；Point 和 Normal 控制点也优先。按住 `Ctrl` 可跳过参考线并使用当前工具。画笔、Pencil、Fill、Shape、Crop 和区域选择工具会忽略现有参考线。线条仍然可见，并绘制在所有工具控制点下方。
单击参考线可将其选中：方向键可微调，`Shift` 会将步长增大十倍，`Delete` 可将其删除。单击其他位置或按 `Esc` 取消选择。双击参考线可输入精确的 **Position (px)** 和 **Angle (°)**。角度相对于画布：0° 为水平，90° 为垂直。对于这两种方向，Position 是从顶部或左边缘起算的距离；其他角度下则是从左上角起算的有符号垂直距离。

右键单击参考线可对其进行 **Edit**、**Duplicate** 或 **Delete**。右键单击任一标尺可打开共享控件：

- **Show Guides** — 隐藏或显示线条。画布视图底栏中 **Tiled** 旁边的 **Guides** 按钮作用相同。隐藏的参考线不会吸引工具；创建新参考线会再次显示它们。
- **Lock Guides** — 保护现有线条不被编辑。你仍然可以创建新参考线，并让工具吸附到已锁定的参考线。
- **Snap to Guides** — 切换吸附；按住 `Ctrl` 可临时跳过。
- **Undo Guide Change / Redo Guide Change** — 撤销或重做参考线编辑，不影响绘制。
- **Clear Guides** — 移除所有参考线。

### 让工具吸附到参考线

移动或缩放图层（包括 Shader FX Transform 2D 区域）时，其边缘会吸附到平行的参考线。移动时其中心线也会吸附。边缘会忽略倾斜的参考线；旋转变换可使其与某条参考线平行或垂直对齐。`Shift` 保留其通常的旋转和缩放约束。

附近的参考线交点优先于单条线，无论缩放如何，吸附半径都相同。它们会吸引画笔/铅笔中心、选区和形状点、轴心，以及变换的中心、角点和边缘中点。当移动受到约束时，只有允许路径上的交点会吸引该点。按住 `Ctrl` 可跳过吸附。

轴心和多边形套索顶点也可以吸附到任意角度的单条参考线。矩形选区仅在单条线与画布轴平行时吸附到它们；交点在任意角度都有效。

### 沿参考线绘制

**Brush** 和 **Pencil** 也会在任意角度将笔触中心吸附到参考线和交点，包括擦除时。光标会显示吸附后的位置。如果你的笔触是吸附到某条参考线开始的，按住 `Shift` 会让它保持在该线上，无论指针移开多远。松开 `Shift` 可进行普通的附近吸附；在同一次笔触中再次按下它可回到原来的参考线。在交点处，会使用最靠近起始指针的参考线。如果你从远离参考线处开始，`Shift` 会保留其通常的屏幕水平或垂直方向。按住 `Ctrl` 可跳过参考线吸附和锁定。Pencil 笔触仍遵循像素网格；画笔的 Scatter 在笔触路径吸附之后应用。

### 吸附放置参考线

拖拽参考线会将其吸附到平行的画布边缘、画布中心、所选图层的平行边缘和中心线，但不会吸附到其他参考线。它也可以吸附到参考线交点，但如果有与拖动线平行的参考线经过该交点，则忽略该交点。按住 `Ctrl` 可自由放置。

参考线不会导出，切换文档时会清除。

### 外观与吸附距离

在当前画布视图中水平或垂直的参考线显示为明亮的青色；倾斜的参考线使用更柔和的蓝灰色。颜色会随视图旋转而更新，但不改变吸附。

在 **User Settings → Guides & Snapping** 中，为 **Aligned Guides**、**Angled Guides** 和 **Active Guide**（悬停、选中或拖拽中）选择颜色。即将被删除的参考线保持红色。
**Snap Radius (px)** 设置参考线、交点、画布边缘和轴心锚点的吸引距离：1–64 个 UI 像素，默认 8，与缩放无关。角度吸附保持不变。这些偏好设置会跨窗口应用并在会话之间保存；**Reset Guides & Snapping** 会恢复其默认值。

## 平衡细节与响应速度

**Live Quality** 默认为 **100%**。你手动选择的值会被记住。
如果在大图像上绘制感觉缓慢，可在页脚中调低它。
水平拖动 **Live Quality** 数值可调整，双击可输入精确百分比；按 `Enter`、`Tab` 或离开字段确认，`Escape` 取消。
保存和导出仍使用完整分辨率。

Canvas View 会根据缩放和可见区域调整细节。放大到 100% 或更高时，可见部分使用原始像素，而不是放大 512 像素预览。添加 HSV 等图层 FX 后仍保留这些细节，包括其他图层上的文字。**Live Quality** 可降低笔画期间的细节；松开画笔后恢复正常预览质量。

Brush/Pencil 绘制时也使用可见区域预览，保留柔和选区和 HDR；绘制过程中平移视图，可以看到此前位于屏幕外的笔触。
需要视野外像素的效果可能更新较慢，但不会降低整个画布的细节。**Post FX**、**Tiled** 和 Crop 裁切框预览仍使用完整画布的缩小预览。在这些模式下，选择 **Pencil**（无需绘画）可查看完整分辨率，检查接缝时启用 **Tiled**。
Patch Quilting 在低分辨率预览中可能选择不同片段；导出前请检查完整分辨率结果。

## 在模型上查看你的绘制

1. 保存文档并将其纹理指定给模型材质。
2. 在画布视图底栏中 **Live Quality** 旁边开启 **Live Update**（圆形按钮）。
3. 绘制或调整图层：使用该纹理的对象会在 Scene View 中更新。

<a href="{{ '/Images/uv-rubik-cube.png' | relative_url }}"><img src="{{ '/Images/uv-rubik-cube.png' | relative_url }}" alt="Live Update in WhimTex: white lettering painted across the cube's texture appears on the model in Unity Scene view" width="720"></a>

白色文字在纹理中横跨两个面；Live Update 让你在绘制时检查它如何环绕立方体。

关闭 Live Update 或关闭 WhimTex 时，材质会保留其纹理引用。
关闭它或未保存就关闭会恢复上次保存的图像。按 **Save** 或 `Ctrl+S`
可保留你的编辑；**Save As** 会创建一个不同的资源，且不会重定向现有材质。

Live Update 显示的作品不包含 EV、通道显示遮罩、Debug 或预览 Post FX。
编辑时它使用预览质量，停止后会细化结果。
如果你调整画布尺寸，实时图像会适配已保存纹理的尺寸，直到你再次保存。
打开窗口时 Live Update 处于关闭状态，切换文档或重新加载脚本时也会关闭。

### 在另一个文档中使用合成器

将已保存文档的输出纹理指定给另一个文档中的 **File** 图层。
保存源文档会自动刷新接收窗口。要在编辑时看到更改，请在
**源窗口中启用 Live Update**。接收窗口无需启用 Live Update 就能显示它们。
关闭 Live Update 也会让接收窗口恢复为已保存的图像。

同时只能有一个 TIFF 文档发布 Live Update。接收窗口可以显示源文档的实时变化，
但要沿文档链继续传递结果，需要保存各个中间文档。
**Save As** 创建新资源；现有 File 图层仍引用原始资源。
循环链接（例如 A 使用 B，而 B 使用 A）之间的自动刷新已禁用，以防止反复更新。

## 检查亮度和通道

**EV** 更改的是查看曝光，而不是图像本身。保持为 **0** 以获得正常视图。
如果白色看起来发灰或颜色看起来过曝，请先检查此字段。

**R / G / B / A** 让你分别检查颜色通道或透明通道。
显示模式参见[颜色与通道](color.md)。

> 通道按钮也会影响新的绘制：被禁用的颜色通道接收零值，
> 关闭 A 会阻止 Brush、Pencil 和 Fill 留下痕迹。
> 普通绘制时请开启全部四个通道。

## 背景和问题像素

在 **Window tab ⋮ → User Settings…** 中更改透明棋盘格的颜色和大小。

bug 按钮会高亮显示颜色值无效的像素。用它来排查看起来损坏的
效果；其高亮颜色也在 User Settings 中。该叠加层不会包含在保存的图像中。

Zoom、EV 和 [Post FX](post-fx.md) 只改变查看效果。**Tiled** 还会影响绘制，让笔触跨越画布边缘。
