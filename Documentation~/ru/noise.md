# Процедурный Noise

Noise пригодится для облаков, зерна, каменных узоров или основы карты высот.
Добавь **Noise** через **+ → Noise** внизу списка Layers и меняй настройки, наблюдая за изображением.

## Начать с узора

| Настройка | Что попробовать |
| :--- | :--- |
| Noise Type | OpenSimplex2 или Perlin для плавных переходов; OpenSimplex2S — более гладкий вариант OpenSimplex2; Cellular для ячеек; Value для более простого случайного узора; ValueCubic — сглаженный Value. |
| Seed | Получить другой рисунок с тем же характером. |
| Scale | Увеличить для мелких деталей, уменьшить для крупных форм. |
| Offset | Сдвинуть узор. |
| Fractal | FBm добавляет детали; Ridged подчёркивает гребни; PingPong создаёт повторяющиеся полосы; None отключает фрактал. |
| Octaves | Добавить больше уровней детализации. |
| Domain Warp | Изогнуть и исказить узор; **Warp Strength** задаёт силу. Пока выбрано None, искажения нет. |
| Warp Scale | Множители X/Y обычного Scale: итоговый масштаб искривления равен `Scale × Warp Scale` по каждой оси. По умолчанию [1,1], диапазон множителей 0.01–1000. Цепочка сохраняет пропорции; отключи её для раздельного редактирования. Random All выбирает 0.25–4, сохраняя связанные пропорции. |

Для более тонкой настройки **Lacunarity** меняет соотношение размеров деталей,
а **Gain** — выраженность мелких деталей.
В Cellular попробуй **Distance**, **Return** и **Jitter**, чтобы изменить форму и регулярность ячеек.


## Масштаб, 3D-срезы и бесшовность

**Scale X/Y** меняет размер деталей независимо по осям. Кнопка-цепочка связывает значения
пропорционально; при включении связи текущие пропорции сохраняются. Масштаб измеряется по короткой стороне холста.

### 3D-срезы

У OpenSimplex2, OpenSimplex2S, Cellular, Perlin, ValueCubic и Value доступен **Dimensions → 3D**.
В поле **Offset** появляется **Z**: меняй его, чтобы выбирать срез объёмного шума.
Ячейки Cellular на 3D-срезе отличаются от обычного 2D. Fractal и Domain Warp работают в обоих режимах.

### Повтор без шва

Квадратный контрол **Seamless** замыкает сам шум без смешивания краёв.
Левая и правая грани переключаются вместе — ось X; верхняя и нижняя — ось Y.
Все четыре включают XY; снятие обеих пар отключает периодичность. Клик по картинке в центре инвертирует выбранные пары.
Fractal и Warp сохраняют периодичность; Z никогда не зацикливается. В период должны помещаться
целые ячейки решётки, поэтому Scale меняется ступенчато, особенно у OpenSimplex при малом масштабе.
Произвольные трансформации и FX могут снова создавать швы на холсте. У White/Blue этой настройки нет.

В **1D** вместо квадрата доступна галочка **Seamless**: шум повторяется вдоль своей оси,
включая Fractal и Warp. Один период занимает проекцию холста на эту ось; Scale задаёт
детализацию внутри периода и по-прежнему меняется ступенчато. Direction 0 замыкает левый
и правый края, 90 — верхний и нижний. При произвольном угле повторение вдоль оси шума
не гарантирует совпадение краёв холста. Галочка по умолчанию выключена и запоминается
независимо от выбора граней в 2D/3D.

В 2D OpenSimplex2/2S значения Scale меньше 1 теперь позволяют укрупнять фрактальные детали:
каждая октава подбирает свой период от заданного Scale. Изменения остаются ступенчатыми,
минимум — одна ячейка на октаву. При Fractal None ограничение одной ячейкой остаётся.
Рисунок существующих 2D бесшовных Simplex-шумов может измениться, в том числе при Scale больше 1;
остальные типы шума и 3D не изменены.


Warp Scale работает в 1D, 2D и 3D; частота по Z не меняется. При Seamless период Warp
подгоняется по выбранным осям уже после умножения. BasicGrid с одной ячейкой по обеим
осям даёт равномерный сдвиг: увеличь множители Warp Scale, чтобы получить искривление,
не увеличивая Scale шума. Например, Scale 0.5 × Warp Scale 6 даёт масштаб Warp 3.
White/Blue Noise игнорируют Warp Scale.
## Белый шум

Выбери **Noise Type → White Noise** для случайного зерна без плавных переходов.
**Color → Monochrome** даёт чёрно-белое зерно, а **Color → Color** — независимые значения красного, зелёного и синего.
**Grain Size (px)** по умолчанию равен одному пикселю холста; увеличь его для крупных квадратных зёрен.
Меняй **Seed**, чтобы получить другой рисунок, и **Offset**, чтобы сдвинуть его в пикселях.
Fractal и Domain Warp не применяются к белому шуму; при переключении типа их настройки сохраняются.
Белый шум также поддерживает **Dimensions → 1D** — случайные полосы; подробнее в разделе
[Полосовой шум](#полосовой-шум).

## Синий шум

Выбери **Noise Type → Blue Noise** для более равномерного зерна с меньшим количеством случайных сгущений.
Он пригодится для масок дизеринга и мелких крапинок.
Настройки **Monochrome / Color**, **Grain Size (px)**, **Offset**, **Inverted** и **Output**
работают так же, как у White Noise; **Dimensions → 1D** создаёт полосы.
Для маски дизеринга выбирай **Output → Linear Data**, для видимой текстуры — **Output → Color Values**.

Период синего шума в пикселях холста равен 128 × размер зерна по каждой оси,
а в режиме 1D — 256 × размер зерна вдоль направления изменения.
При крупном зерне повторение может стать заметным. Seed меняет расположение рисунка, сохраняя характер распределения.
Fractal и Domain Warp к Blue Noise не применяются.

## Полосовой шум

Выбери **Dimensions → 1D**, чтобы получить прямые шумовые полосы вместо двумерного узора.
**Direction (deg)** поворачивает направление изменения шума: при 0 полосы вертикальные, при 90 — горизонтальные.
Направление доступно для любого типа шума. **Scale** задаёт ширину полос;
у White Noise и Blue Noise вместо него используется **Grain Size (px)**.
**Offset X** сдвигает рисунок вдоль направления изменения, а **Offset Y** выбирает другой срез шумового поля.
Кроме White Noise и Blue Noise, в режиме 1D доступны Fractal и Domain Warp.
Warp меняет рисунок, но полосы остаются прямыми.
Верни **2D** для обычного узора — настройка направления сохранится.

## Цветная текстура или карта высот?

**Output** определяет, как значения шума превращаются в пиксели:

| Output | Применение |
| :--- | :--- |
| Linear Data (по умолчанию) | Карты высот и данные в каналах текстуры. |
| Color Values | Исходный шум как видимое изображение. |
| Gradient | Палитра для монохромных значений, включая её альфу и HDR-цвета. |

**Inverted** переворачивает значения до выборки градиента и работает во всех режимах вывода.
Начальная палитра — от чёрного к белому, **Perceptual**; переключение Output её сохраняет.

Цветные White/Blue Noise поддерживают только Color Values и Linear Data.
Сохранённый выбор Gradient временно использует Color Values до возврата в Monochrome.
Какие настройки меняет Random All — см. [Случайные варианты](#случайные-варианты).

Чтобы получить рельеф поверхности:

1. Добавь Noise и выбери **Output → Linear Data**.
2. Включи **Fractal → FBm**, начни с трёх октав и подбери Scale.
3. Добавь **Normal Map** над шумом и выбери **Generation → Height Map**.
4. В Advanced у Normal Map установи **Input Space → Linear**.
5. Настрой Strength и Smoothing. Меняй Seed у Noise, чтобы попробовать другую поверхность.

Превью **Tiled** помогает заметить швы; **Seamless** делает исходный шум повторяемым.
Следующий шаг — [Normal Map](normal-map.md).

## Случайные варианты

**Random All** вверху настроек шума подбирает новое сочетание параметров генератора,
включая неактивные параметры генератора и **Inverted**. Output меняется только между Color Values и Linear Data; выбранный Gradient сохраняется. Палитра градиента, **Dimensions**, **Direction**, **Seamless**, пропорции связанных Scale и Warp Scale, **Offset X/Y/Z**, трансформация, смешивание и FX
слоя не меняются. Один Undo возвращает предыдущее сочетание. **Random** рядом с **Seed** меняет только сид.
Noise Type меняется только внутри выбранной группы: **White Noise / Blue Noise** либо все остальные типы шума.

### Распределение Scale в Random All

Random All немного чаще выбирает средний Scale по X/Y около **8**, не исключая мелкие и крупные узоры.
Связанные оси сохраняют пропорции. Формула распределения и пределы — в [технической справке](../AgentAPI.md#noise-settings).
