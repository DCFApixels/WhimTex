# Слой Shader

**Shader** создаёт текстуру или маску через граф узлов или код WhimTex HLSL.
Оба режима могут читать входное изображение. **Composite Below** читает нижнюю композицию,
а **Crossfade** смешивает её с обработанным результатом по Opacity. Обычная цепочка **FX** выполняется после графа или Code.

**Shader Program** — общая программа слоя Shader или FX. **Draft** — редактируемый черновик; **Working** — последняя успешно скомпилированная версия. **Compile** обновляет рабочую версию, а **Apply** у FX запекает результат.

## Повторение ветки через For

Добавь **Utility → Loop → For Begin** или **For End**: появится связанная пара.
У Begin задай **Iterations** и **Initial**. Используй **Value** в теле цикла и подключи
новое значение к End. **Index** начинается с 0; **Result** выдаёт итог цикла.
Например, Initial=1 и умножение Value на 2 за 4 итерации дают 16.
При нулевом или отрицательном числе итераций возвращается Initial; дробная часть
количества итераций отбрасывается.

Циклы можно вкладывать друг в друга; значение может быть числом, вектором или цветом.
Превью внутри тела показывает первую итерацию, превью End — итог всех повторений.
Внутри можно читать заранее вычисленный Buffer, а после цикла — запечь весь результат.
Запись изображения на каждой итерации не поддерживается. Копирование или удаление
одного конца включает его пару; для копирования всего цикла выдели также ноды тела.

## Выбрать Graph или Code

Черновик с незавершённым кодом или ошибкой можно сохранить, если у выбранного режима есть рабочая версия.
При открытии восстановится её результат, а черновик останется редактируемым, в том числе без исходного пресета.
Если рабочей версии нет, перед сохранением TIFF нужна успешная компиляция.

В **Properties** поле **Mode** переключает **Shader Graph** (режим по умолчанию) и **Code**.
Граф, код и значения параметров каждого режима сохраняются при переключении. Граф не
превращается в код, а код — в граф. Сохрани документ, чтобы позднее вернуться к любому варианту.

В Code вставь или напиши WhimTex HLSL с `ApplyFX` и `@param`, затем нажми **Compile**.
Новый вариант Code даёт непрозрачную белую заливку. Правка текста меняет изображение только
после успешной компиляции. При ошибке остаются прежний применённый результат и значения
параметров; исправь текст и нажми Compile снова. Принятые параметры настраиваются в Properties
через общие [элементы управления шейдером](shader-controls.md), включая превью.

Code создаёт изображение в локальных координатах слоя. Входной цвет и `SampleInput` читают
выбранный **Input**, описанный ниже. Для дополнительных изображений объяви параметры Texture
и прочитай их через `SampleTexture`. Интерфейс описан в
[контракте HLSL](../ShaderLayer.md#independent-graph-and-code-modes).

При возврате в Shader Graph граф и его значения остаются на месте. Уже открытое окно графа
доступно только для чтения, пока выбран Code; переключись обратно для редактирования.

## Использовать пресет шейдера

Выбери **Preset…** в Properties, чтобы загрузить Code или Graph из общего каталога проекта
и пользовательской библиотеки. Те же пресеты доступны в [Shader FX](shader-fx.md).
**Save Preset…** сохраняет Code в `.hlsl`, а Graph — в `.whimtexshader`. Пресет Graph
сохраняет оба режима, функции, Sub Graphs и включённые исходники для дальнейшего редактирования.
Перед сохранением пресета очисти ссылки Layer у Texture-параметров обоих режимов, включая неактивные.

Связанный пресет использует только сохранённые ID и точную версию. Если исходник пропадёт,
редактируемая копия с графом останется в документе. **Embed Copy** делает её независимой.
Сохрани документ, чтобы оставить черновики и оба режима. Input, Transform и смешивание
остаются настройками слоя. Тот же пресет в FX может дать другие пиксели из-за другого входа
и координат; проверь результат после смены места применения или трансформации.

## Выбрать входное изображение

**Input** в Properties общий для Shader Graph и Code:

| Источник | Результат |
| --- | --- |
| **None** | Прозрачный чёрный; выбран по умолчанию. |
| **Texture** | Чтение назначенной текстуры. |
| **Layer** | Чтение выбранного слоя или группы. |
| **Composite Below** | Нижняя композиция, включая внешний фон проходных групп. Сам Shader и слои выше него исключены. |

В графе изображение читает **Sampling/Sample Input**. Подключи цветовой выход **Out** к
вычислению; **UV** по умолчанию использует локальные координаты и принимает искажённые
координаты от других нод. Wrap и Filter работают как у Sample Texture. В Code используй
`SampleInput(uv)` или входной `color` в `ApplyFX`. Отсутствующий источник даёт прозрачный
чёрный. Переключение Input или Mode сохраняет назначенные источники.

Чтобы обрабатывать изображение снизу, выбери **Code**, **Composite Below** и **Crossfade**. Скомпилируй `float4 ApplyFX(float4 color) { return color; }`, затем добавь эффекты в **FX**. Opacity смешивает исходник и результат без накопления альфы. В графе вместо кода соедини **Sample Input → Output**. Проходные группы включают внешний фон; изолированные и обтравленные группы ограничивают вход своим содержимым.

## Создать и настроить изображение

1. Добавь слой **Shader** через **+** внизу Layers.
2. Открой **Properties**, выбери **Shader Graph** в **Mode** и нажми **Edit Graph**.
   Добавляй узлы через **Create Node** в контекстном меню графа или клавишу **Space**.
3. Подключи вычисление к **Output**, который задаёт красный, зелёный, синий и альфа-канал изображения.
4. Объяви параметры для значений, которые хочешь менять в **Properties** слоя.
   Узел **Parameter** читает такой параметр в графе; **Constant** выдаёт математические константы.
5. Вернись в **Properties** слоя, чтобы настраивать результат, не перестраивая граф.

В новом графе параметр Color уже подключён к Output. Для примера задай непрозрачный красный в Properties.
Чтобы оставить значение внутри графа, отключи вход и задай значение в поле рядом с портом.

Центры портов расположены на краях внутреннего фона нод, а точки видны поверх контура выделения.
Начальные участки соединений укорочены под компактную раскладку.
У Reroute порты остаются на прежних местах.
Фон областей превью и дополнительных настроек совпадает с фоном колонки выходных портов.

К результату применяются обычные **Transform**, **Rendering**, **FX** и смешивание слоя.
Для общего изображения используй **Input** и **Sample Input**, а для дополнительных объяви
параметры **Texture** и прочитай их через **Sample Texture**. По умолчанию Input равен None.

## Математические константы и Swizzle

**Utility/Expression** заменяет короткую цепочку вычислений формулой. Выражение
`a + b * c / 2` создаёт входы `a`, `b`, `c` и выход **Out**. При значениях 1, 2 и 10
результат равен 11. **Type** задаёт Float–Float4 сразу для всех портов.
Можно использовать HLSL-функции, скобки, swizzle и конструкторы векторов: например,
`saturate(a * b)` или `float2(a.x, b.y)` с типом Float2.
Формула применяется после выхода из поля. Пустое выражение возвращает ноль.
Связи следуют за именами переменных с учётом регистра; исчезнувшие из формулы
подключённые входы остаются неактивными до возвращения имени. Ошибка показывается
рядом с нодой. Для тела функции с отдельными инструкциями используй Custom Function.

**Input/Instance Index** и **Input/Time** имеют один выход **Out** типа Float.
У них нет собственного превью. У обеих нод есть Float-входы **Start** (по умолчанию `0`) и **Scale** (по умолчанию `1`).
**Instance Index** возвращает **Start + индекс × Scale**; сейчас индекс равен `0`, поэтому результат равен Start.
**Time** передаёт время редактора в секундах в зависимые превью нод и результат в окне графа.
Его выход — **Start + время × Scale**. Оба входа можно задать вручную или подключить к другим нодам.
Canvas использует отдельные [Play/Pause и перемотку документа](preview.md#document-playback), которые не останавливают часы графа. Save, обычный экспорт и Live Update используют время `0`, поэтому Time возвращает там Start.
В HLSL-нодах и Custom Function доступны `_WhimTexTime` и `_WhimTexInstanceIndex`.
FX Shader-слоя получают то же время анимации в превью результата графа.

**Constant** выдаёт число из списка: **PI**, **TAU** (2π), **PHI** (золотое сечение),
**E**, **SQRT2** (√2). По умолчанию выбран PI.

**Swizzle** переставляет или повторяет каналы входа. В поле **Mask** введи 1–4 символа
из `xyzw` или `rgba`; регистр не важен. `_` вставляет ноль.
Для двухкомпонентного входа `_x_y` выдаст четырёхкомпонентный вектор `(0, x, 0, y)`.
Длина выражения задаёт число компонентов выхода. Изменение применяется по Enter или при выходе из поля.
Ширина входа — максимум из ширины источника и требований маски: `y` требует Float2, `z` — Float3,
`w` — Float4. У неподключённого входа появляется нужное число полей. Подключённый скаляр повторяется
по компонентам, короткий вектор дополняется нулями. `_` всегда вставляет ноль.

## Дополнительные вычисления и узоры

**Sign** различает отрицательные, нулевые и положительные значения, **Saturate** ограничивает
значение диапазоном `0..1`. **Modulo** повторяет числовой интервал, **Atan2** вычисляет угол по
Y и X, **Asin** и **Acos** выполняют обратные тригонометрические операции. Эти углы заданы
в радианах. Asin/Acos нужны значения `-1..1`, а **Log** — положительные значения.
**Exp** и Log используют натуральное основание. **Cross** даёт перпендикулярный 3D-вектор.
**Reflect** и **Refract** отражают или преломляют направление относительно нормали: передавай
единичные векторы, а коэффициент преломления задавай через Eta.
Объединяй логические условия через **And**, **Or** и **Not** перед Select.

Для повторяющегося шума включи **Periodic** и задай положительный **Period** у ноды, например **Perlin Noise**.
**Scale** задаёт плотность; для сдвига рисунка поставь **Add** перед **Position**. **Cellular Noise → Distance to Edge** выдаёт
нормализованное расстояние до границ; примени порог к Value, чтобы получить линии ячеек.
**Flipbook** выбирает ячейку атласа через Columns, Rows и Frame. Подключай Out к
Sample Texture.UV. Номера кадров повторяются по кругу, включая отрицательные; порядок строк
снизу вверх или сверху вниз не переворачивает изображение внутри кадра.

**Dither** уменьшает число цветовых уровней с узором Bayer 2 × 2, 4 × 4 или 8 × 8.
Levels задаёт число уровней, PixelSize — размер узора в пикселях документа. Альфа сохраняется;
HDR и отрицательные цвета автоматически не обрезаются.

## Записки и группы

Нажми ПКМ в графе и выбери **Add Note**, чтобы добавить записку с изменяемым размером,
или **Group Selection**, чтобы объединить выбранные узлы и записки рамкой.
Без выделения создаётся пустая группа. Это отдельные пункты контекстного меню, вне **Create Node**.
Заголовок группы можно переименовать. Перетаскивай элементы внутрь группы, а саму группу —
за заголовок вместе с её содержимым. **Ungroup Selection** выводит выбранные элементы из группы;
удаление группы сохраняет узлы и записки. Вложенные группы не поддерживаются.

Пункт **Hue…** в меню записки открывает радужный ползунок. Он меняет Hue фона, обводки и текста,
сохраняя насыщенность и яркость каждого исходного цвета, размеры и остальные стили.
При смене темы записки сдвиг Hue сохраняется. **Reset** возвращает стандартные цвета.
При вводе заголовка или текста сохраняются размер шрифта и область редактирования.

Записки и группы сохраняются с документом и поддерживают **Undo/Redo**. При копировании группы
копируется её содержимое и внутренние связи. На изображение они не влияют.

Справа от узла появляется значок информации, предупреждения или ошибки. Наведи на него курсор,
чтобы прочитать сообщения в блоке справа. При нескольких сообщениях значок показывает самый
серьёзный уровень. Ошибки всего графа остаются в общей области сообщений.
Векторные значки остаются чёткими при приближении.

## Скопировать узлы

Выдели узлы и нажми **Ctrl+C / Ctrl+V**, чтобы скопировать и вставить, или **Ctrl+D**,
чтобы дублировать (**Cmd** на macOS). Эти команды есть и в контекстном меню графа.
Сохраняются настройки, взаимное расположение и связи между выбранными узлами, включая
Reroute и HLSL-функции. Sub Graph переносит вложенные определения: в том же графе экземпляры
используют существующие определения, а другой граф получает собственные копии.
Output и интерфейсные узлы Sub Graph не копируются. Вставка и дублирование поддерживают **Undo/Redo**.
Копии появляются в центре текущего вида графа. Центрирование учитывает общий прямоугольник
нод, записок и рамок групп вместе с их размерами. Повторная вставка тоже остаётся по центру.

В том же графе копии Parameter используют прежние параметры. В другой граф нужные параметры
переносятся вместе со значениями. При вставке в другой документ текстурные входы из слоёв
нужно назначить заново. При редактировании поля копируется его текст.
После перекомпиляции скриптов сочетания копирования и вставки продолжают работать,
в том числе при новом копировании. Буфер узлов тоже сохраняется и действует до закрытия редактора.

## Выбрать узлы

**Canvas Position** задаёт координаты относительно документа: **Normalized(2)** — `0..1`,
**Aspect X(2)** умножает X на ширину/высоту, **Aspect Y(2)** умножает Y на высоту/ширину.
Начало всех координат — левый нижний угол канваса. Для канваса 2:1 диапазон Aspect X равен
`0..2 × 0..1`, Aspect Y — `0..1 × 0..0.5`. Трансформация слоя не перемещает это поле.
**Canvas Data** выдаёт **Size(2)**, **Texel(2)** и **Pixel Scale(1)** — множитель пикселя из
инструмента рамки. Масштаб просмотра графа и размер превью не влияют на эти значения.

| Узлы | Для чего |
| --- | --- |
| **Parameter**, **Constant** | Настраиваемые значения слоя или математические константы: PI, TAU, PHI, E, SQRT2. |
| **UV**, **Canvas Position**, **Canvas Data**, **Texture Size** | Локальные координаты или позиция на канвасе, размер и множитель пикселя документа, размер входной текстуры. |
| **Sample Texture** | Прочитать изображение по UV. Изменение координат позволяет его искажать. |
| **Sample Gradient**, **Sample Curve** | Превратить число в цвет градиента или изменить его с помощью кривой. |
| **Split**, **Combine**, **Swizzle** | Разделить, собрать или переставить каналы вектора/цвета. |
| **Add**, **Subtract**, **Multiply**, **Divide** | Смещать, масштабировать и комбинировать значения. |
| **Min**, **Max**, **Clamp**, **Abs**, **One Minus**, **Negate** | Ограничить значения, взять модуль или инвертировать их. One Minus вычисляет `1 − x`. |
| **Power**, **Square Root**, **Floor**, **Ceil**, **Round**, **Fraction** | Менять форму переходов, создавать ступени и повторять числовой интервал. |
| **Sine**, **Cosine** | Создавать волны и повторяющиеся узоры. |
| **Lerp**, **Remap**, **Step**, **Smoothstep** | Смешивать значения, менять диапазоны, создавать жёсткие и плавные пороги. |
| **Unlerp** | Найти положение T в диапазоне A–B: `(T-A)/(B-A)`, без ограничения результата. По умолчанию A = 0, B = 1, T = 0. Поддерживает векторы покомпонентно; при равных границах результат не определён. |
| **Range Mask** | Выделить значения вокруг Center. Width задаёт весь диапазон, включая направленный внутрь Feather на каждом краю. Falloff выбирает Linear или Smooth. Компоненты вектора обрабатываются независимо; для выделения яркости цвета сначала используй Luminance. |
| **Length**, **Distance**, **Dot**, **Normalize** | Вычислять расстояния и направления. |
| **Compare**, **Select** | Выбирать одно из двух значений по условию. |
| **Transform UV** | Смещать, масштабировать или вращать координаты для следующих узлов. |
| **Apply Transform 2D** | Перевести UV в локальную рамку параметра Transform2D или обратно во входное пространство. |
| **Pixelate UV** | Привязывать координаты к центрам ячеек перед выборкой текстуры или генерацией узора. |
| **Perlin Noise**, **Cellular Noise**, **Random** | Получать шум, расстояния до ячеек или повторяемые случайные значения по координатам и Seed. |
| **Checkerboard**, **Stripes**, **Grid**, **Rings**, **Gradient Factor** | Создавать сглаженные узоры или координату для выборки градиента. |
| **Shape**, **Combine Distance** | Создавать маски фигур и комбинировать их знаковые расстояния. |
| **Polar Coordinates**, **Repeat**, **Mirror**, **Kaleidoscope** | Преобразовывать координаты для повторения и отражения рисунка. |
| **OpenSimplex2 Warp Noise**, **Vector Displacement**, **Twirl**, **Bulge / Pinch**, **Wave**, **Ripple** | Искажать координаты перед генерацией узора или выборкой изображения. |
| **Hue**, **Saturation**, **Exposure**, **Lightness**, **Contrast**, **Levels**, **Color Balance**, **Posterize** | Менять цвет, яркость и число тональных ступеней. |
| **Convert Color**, **Luminance**, **Gradient Map**, **Color Curves** | Преобразовывать цветовые компоненты или тона изображения. |
| **Color Mask**, **Hue Range**, **Mix Color**, **Set Alpha** | Выделять цвета, смешивать их и управлять прозрачностью. |
| **Channel Mixer**, **White Balance** | Смешивать RGB-каналы или менять Temperature и Tint, сохраняя альфу и HDR. |
| **Directional Blur**, **Radial Blur** | Размывать ветку графа вдоль линии, вокруг центра или по направлению к нему и от него. |
| **Height Blend** | Смешивать высоты и использовать ту же маску для их цветов. |
| **Tile UV**, **Perspective UV** | Размещать повторяющиеся мотивы в ячейках или вписывать изображение в четырёхугольник. |
| **Gabor Noise**, **Rotate Vector**, **Blackbody** | Создавать направленный узор, поворачивать векторы или получать цвет по температуре. |
| **Slope Blur**, **Bilateral Blur** | Размывать по склону высоты или смягчать детали с сохранением границ по направляющему сигналу. |
| **Height to Normal**, **Normal Blend**, **Height to Distortion**, **Normal to Distortion** | Получать нормали и смещения из текстуры или вычисления высоты, смешивать детали нормалей. |
| **Blend** | Смешивать два цвета с режимом наложения и альфой. Mix Color интерполирует цвета, Lerp — числовые компоненты. |
| **Output** | Получить итоговое RGBA-изображение. |

Для цветного шума собери **UV → Perlin Noise (Position → Value) → Sample Gradient → Output** и передай в
Sample Gradient параметр **Gradient**. Палитру можно менять в Properties.
Для пороговой маски поставь **Smoothstep** после Perlin Noise и назначь результат в альфа-канал через **Combine**.

У **Pixelate UV** размер ячейки **CellSize** `(8,8)` и смещение **Offset** `(0,0)` задаются
в пикселях документа. Минимальный размер по каждой оси — один пиксель. Подключай Out к UV текстуры или узора.
У **Channel Mixer** векторы Red, Green и Blue задают вклад исходных RGB-каналов; `1` означает полный вклад.
Начальные значения сохраняют исходный цвет; отрицательные коэффициенты и HDR поддерживаются.
У **White Balance** Temperature и Tint по умолчанию равны `0`, диапазон обоих — `-1..1`.
Положительная Temperature делает цвет теплее, отрицательная — холоднее; положительный Tint
добавляет пурпурный оттенок, отрицательный — зелёный.

У **Directional Blur** Radius задаётся в пикселях документа, Angle — в градусах; выборки идут
на расстояние Radius в обе стороны. **Radial Blur** предлагает **Spin** (±Angle вокруг Center)
и **Zoom** (расстояние от Center умножается на `1 ± abs(Strength)`). При Strength = `0.1` это `0.9..1.1`.
Неиспользуемое поле остаётся видимым, но неактивным. Оба размытия учитывают прозрачность Color,
чтобы скрытый RGB не давал цветных ореолов. **Samples** по умолчанию равен `17` и округляется вверх
до нечётного числа в пределах `3..129`. Для длинного размытия и мелких деталей увеличивай Samples;
это повышает стоимость вычисления.

У неподключённых входов **Texture**, **Gradient** и **Curve** тоже есть поля шириной
108 пикселей: выбор ассета Texture2D, редактор градиента и стандартный редактор кривой.
Подключение скрывает поле, сохраняя его значение; отключение возвращает его.
Значение сохраняется в документе и рабочей копии графа, изменения обновляют превью и FX.
Это работает и для входов Sub Graph и Color Curves. Без назначенной текстуры используется
белый цвет; значения градиента и кривой по умолчанию совпадают с параметрами графа.

У входа **T** в Sample Gradient и Sample Curve можно выбрать **UV.x**, **UV.y** или
**Custom** для ввода числа. Такой же выбор есть у скалярного Position в шумах 1D.
У новых нод по умолчанию выбран UV.x; сохранённые
числовые значения и подключения остаются без изменений.
Sample Gradient и Sample Texture имеют цветовой выход **RGBA** и отдельные скалярные
выходы **R**, **G**, **B**, **A**. Старые подключения полного цвета продолжают работать через RGBA.

Поля неподключённых числовых входов видны и доступны для редактирования снаружи узла,
слева от портов. Порты остаются свободными для соединения. При подключении поле исчезает, при отключении
возвращается. Неподключённые UV-порты сохраняют неявные координаты текущего пикселя (`PixelUV`):
локальный переключатель **Custom / UV** позволяет ввести координаты или использовать UV.
У одиночного Float тоже есть подпись **X**: перетаскивай её по горизонтали, чтобы менять значение, как у компонентов вектора.
В зависимости от ноды неприменимые входы скрываются или становятся неактивными вместе с полями.
Например, у Warp **Fractal = None** отключает Octaves, Lacunarity и Gain, а PingPongStrength отдельной ноды Fractal доступен
только для Ping Pong. Причина показана при наведении на порт. К неактивным портам, включая
отсутствующие компоненты Split, нельзя подключить новые связи. Если настройка скрывает подключённый порт,
он остаётся видимым и приглушённым вместе с сохранённой связью. Возврат настройки восстанавливает её работу.
Неподключённые скрытые порты не показываются. Пока выход недоступен, принимающий вход использует своё сохранённое значение или значение по умолчанию.

Перетащи соединение из входного или выходного порта на пустое место графа, чтобы открыть поиск
совместимых узлов. Меню открывается справа от курсора, левым краем у него. Для выхода предлагаются
входы: например, `Multiply(A)` и `Multiply(B)`. Для входа — выходы: например, `Cellular Noise(F1)` и
`Cellular Noise(F2)`, включая подходящие параметры графа и HLSL-функции.
Выбор создаёт узел в месте отпускания и подключает выбранный порт. У занятого входа прежняя связь
заменяется новой. Создание и подключение отменяются одним Undo; отмена поиска оставляет граф без изменений.

## Смешать высоты и разместить детали поверхности

**Height Blend** смешивает высоты **Bottom** и **Top**, выдавая **Height** и **Mask**.
Подключи Height к расчёту поверхности, а Mask — к смешиванию соответствующих цветов.
Offset поднимает или опускает Top, Smoothness смягчает переход, Opacity уменьшает вклад Top.
Начальные значения: Bottom `0`, Top `1`, Offset `0`, Smoothness `0.1`, Opacity `1`.
Отрицательные и HDR-высоты сохраняются.

**Tile UV** повторяет мотив в ячейках **Grid** или **Staggered**. Подключи выход **UV** ко входу
UV мотива и умножь его альфу на **Mask**. **Count** по умолчанию `(4,4)`, **Offset** измеряется
в ячейках. **RowOffset** `0.5` сдвигает чередующиеся ряды только в Staggered.
**RandomRotation** задаёт диапазон случайного поворота в градусах, **RandomScale** — разброс
масштаба от `0` до `1`; оба начинают с `0`. **Seed** `1337` позволяет повторять тот же узор.
**Cell**, **Center** и **Random** дают координаты ячейки, её центр в UV изображения и случайное
число для ячейки. Мотив остаётся в своей ячейке: выступающие после поворота или увеличения
части обрезаются и не перекрывают соседей.

**Perspective UV** вписывает изображение в четыре угла: **BottomLeft**, **BottomRight**,
**TopRight** и **TopLeft**. По умолчанию это `(0,0)`, `(1,0)`, `(1,1)` и `(0,1)`.
Подключи выход **UV** к выборке изображения, а **Mask** умножь на его альфу, чтобы скрыть
область снаружи четырёхугольника. Преобразование сохраняет перспективу. Вырожденный,
самопересекающийся или невыпуклый четырёхугольник даёт нулевые UV и Mask.

**Gabor Noise** из **Procedural/Noise** создаёт направленные детали в 1D/2D/3D.
**Frequency=2** задаёт частоту колебаний, **Bandwidth=1** — ширину огибающей,
**Anisotropy=0.8** — согласованность направлений, вектор **Direction** (вдоль X по умолчанию) — ориентацию.
**Value**, **Phase**, **Intensity** и **Phasor** используют одно вычисление шума.
**Phasor** даёт полосы с более равномерным контрастом. **Profile: Sine / Triangle / Pulse**
выбирает форму полос, **Phase Offset=0** сдвигает их в циклах (1 повторяет рисунок).
**Width=0.5** задаёт долю светлого в Pulse: 0 — чёрный, 1 — белый. В других профилях Width
скрыт без подключения; подключённый порт остаётся видимым, но неактивным. Значение и связь сохраняются.
Эти настройки влияют только на Phasor. Filtering сглаживает мелкие полосы к среднему значению
профиля; настоящие особенности фазы сохраняются, с затуханием возле нулей сигнала внутри пикселя.
**Gradient** и **Curl** в 2D/3D сохраняют знаковую силу. Многократная выборка фильтром увеличивает стоимость шума.

**Rotate Vector** из **Vector** поворачивает **In** на **Angle** градусов, сохраняя длину.
В **2D** используются две компоненты, в **3D** — три и дополнительная ось **Axis** `(0,0,1)`.
Начальное In направлено вдоль X, Angle равен `0`. Нулевая Axis оставляет In без изменений.
Для поворота UV вокруг выбранного центра сначала вычти центр, а после поворота прибавь его обратно.

**Blackbody** из **Color/Generation** выдаёт на **Out** приближённый линейный RGB-цвет по температуре
с альфой `1`. **Temperature** начинается с `6500` Кельвинов и ограничена `1000..40000`:
низкие значения дают тёплые красные и оранжевые тона, высокие — холодные синие.
Температура задаёт нормализованный цвет; яркость регулируй отдельно через Multiply или Exposure.

## Процедурные узоры и искажения

Ищи эти узлы во вложенных категориях **Create Node**. Такие же ветки доступны при создании
узла из протянутого соединения:

| Категория | Узлы |
| --- | --- |
| **Procedural/Noise** | Perlin Noise, Value Noise, Value Cubic Noise, OpenSimplex2 Noise, OpenSimplex2S Noise, Flow Noise, Cellular Noise, Triangle Voronoi Noise, Gabor Noise, Spots Noise, Shard Noise. |
| **Procedural/Noise/Warp** | OpenSimplex2 Warp Noise, OpenSimplex2 Reduced Warp Noise, Basic Grid Warp Noise. |
| **Procedural/Noise/Grain** | White Noise, Blue Noise. |
| **Math/Random** | Random. |
| **Sampling** | Buffer. |
| **Procedural** | Fractal. |
| **Procedural/Pattern** | Checkerboard, Stripes, Grid, Rings, Gradient Factor. |
| **Procedural/Shape** | Shape, Combine Distance. |
| **UV** | Transform UV, Apply Transform 2D, Polar Coordinates, Repeat, Mirror, Kaleidoscope. |
| **UV/Distortion** | Vector Displacement, Twirl, Bulge / Pinch, Wave, Ripple. |

Ноды шума используют общую библиотеку WT. **Dimensions** выбирает **1D** для линии,
**2D** (по умолчанию) для плоскости или **3D** для объёма. Неподключённый **Position**
берёт UV пикселя, его X в 1D или UV с отдельно редактируемым **Z** (по умолчанию 0) в 3D.
В 3D переключатель UV занимает место X/Y, а Z остаётся обычным числовым полем: за его
подпись можно тянуть. Переключение UV/Custom и Dimensions сохраняет Z. **Scale=8** задаёт плотность по осям,
Для сдвига рисунка используй **Add** перед **Position**. **Periodic** по умолчанию выключен. Включи его, чтобы показать **Period=1** на каждой оси: положительное значение задаёт повтор, неположительное отключает ось. При выключении расчёты периода исключаются; подключённый Period остаётся видимым и неактивным, его значение и связь сохраняются. **Seed=1337** выбирает вариант.
Смена Dimensions сохраняет значения и все связи. Подключённый Curl остаётся видимым, но неактивным в 1D.
**Filtering** выключен по умолчанию и уменьшает слишком мелкие детали, в том числе внутри фильтров.
**Triangle Voronoi Noise** работает только в **2D**, без переключателя Dimensions; координаты и настройки по осям остаются двухкомпонентными.

Первый выход скалярного шума — **Value**, поле `0..1` для масок и градиентов.
Perlin, Value, Value Cubic, OpenSimplex2/2S, Flow и Gabor также дают **Gradient**,
а в 2D/3D — **Curl**. Эти знаковые векторы сохраняют силу поля.
У **Flow Noise** вход **Phase=0** плавно вращает градиенты; фаза измеряется в циклах,
поэтому 0 и 1 дают одинаковый рисунок.

**Shard Noise** создаёт рисунок с гранями. **Sharpness=0.7** меняет мягкие переходы
при 0 на резкие осколки при 1. Выход **Value** поддерживает общие настройки 1D/2D/3D,
Period и Filtering. Для анимации выбери 3D и меняй Position Z.

**Triangle Voronoi Noise** создаёт угловатые ячейки в 2D. Это не треугольная сетка:
отдельные ячейки могут иметь другую форму. **Distribution** выбирает
**Uniform** (по умолчанию) или **Fixed Radius**, **Jitter=1** смещает опорные точки,
а **Stretch=(1,1)** меняет форму ячеек по X/Y. Компоненты Stretch берутся по модулю
и ограничиваются диапазоном `0.5..2`, Jitter — диапазоном `0..1`. При Jitter=0 могут
возникать области равных значений треугольной меры; их внутренняя часть не считается границей.
Примени порог к **Value** —
нормализованному полю границ `0..1`, — чтобы выделить края ячеек. **Distance** даёт
ненормализованное евклидово расстояние до выбранной точки, **CellValue** — её повторяемое значение,
**ToPoint** — вектор к ней. **BorderNormal** — единичный вектор к ближайшей границе;
в вырожденном случае он равен нулю.
Эти дополнительные выходы не фильтруются; выходов Gradient/Curl у ноды нет.

Для нескольких слоёв деталей подключи результат к отдельной ноде **Fractal** в **Procedural**.
Она повторяет числовую или Color-ветку в 2D-координатах графа. Это не точное вычисление
фрактала конкретного семейства WT, даже если источник содержит шум 1D/3D. **Out** сохраняет
тип **In**. У скалярных нод шума больше нет встроенного фрактала и входов октав.
**FBm** (по умолчанию) смешивает детали, сохраняя отрицательные и HDR-значения.
**Ridged** создаёт гребни по `1-abs(2*v-1)`, **Ping Pong** складывает сигнал по
`1-abs(frac(v*max(strength,0))*2-1)`. Нормализованное взвешенное смешивание выполняется
для каждой компоненты, включая альфу Color. **Octaves=3** задаёт число октав
(`1..8` после приведения к целому), **Lacunarity=2** — шаг частоты (`0.01..16`),
**Gain=0.5** — шаг амплитуды (`0..1`), **Weighted Strength=0** — влияние предыдущих значений
на амплитуду (`0..1`). **Ping Pong Strength=2** управляет складыванием; вне Ping Pong
он скрыт без подключения; значение и связь сохраняются. **Filtering** изначально включён и ослабляет
октавы по размеру пикселя в локальных UV; фильтрация исходного шума остаётся независимой.
**Seed Step=1** меняет seed шумовых нод между октавами, включая White/Blue grain.
Произвольные seed-параметры пользовательских HLSL-функций автоматически не меняются.

**Multifractal** создаёт неоднородную детализацию перемножением октав.
**Hybrid Multifractal** сочетает гладкие участки с шероховатыми вершинами, а **Hetero Terrain**
добавляет детали пропорционально уже полученной высоте. **Ridged Multifractal** возводит
гребни в квадрат и связывает их между октавами; прежний **Ridged** сохраняет своё поведение.
Эти режимы ожидают исходный шум в 0..1, внутри переводят его в диапазон вокруг нуля
и возвращают ненормализованную высоту, которая может выходить за 0..1.
**Bias=1** сдвигает уровень высоты у Hybrid/Hetero и уровень гребней у Ridged Multifractal.
**Feedback=2** управляет передачей деталей между октавами у Hybrid/Ridged Multifractal;
**Gain** по-прежнему задаёт затухание амплитуды. Weighted Strength в этих четырёх режимах
не используется. Неприменимые поля скрываются без подключения; подключённые порты
остаются видимыми и неактивными. Значения и связи сохраняются.

**Buffer** в **Sampling** позволяет один раз вычислить тяжёлую ветку и затем читать её результат.
Подключи числовой или Color-вход **In**; **Out** сохранит его тип. **UV** по умолчанию берёт
UV текущего пикселя, **Wrap** и **Filter** задают выборку. **Resolution → Canvas** использует
размер текущей цели рендера, поэтому превью ноды берёт разрешение превью. **Custom** использует
точный **Size** (изначально `512 × 512`). Буфер сохраняет float32-точность, отрицательные
и HDR-значения, переиспользует выделенную память и обновляется при изменении источника.
Его пиксели не сохраняются в документе. Внешний RenderTexture или пользовательская функция
обновляют источник при каждом рендере владельца; вложенные буферы выполняются в порядке зависимостей.
Generated HLSL с Buffer требует промежуточных текстур и проходов, которыми управляет граф;
копирование одного кода их не создаёт.

Проходы, заполняющие Buffer, и шейдер, который читает его текстуру, компилируются отдельно.
Неизменившиеся скомпилированные программы используются повторно, поэтому правка одной
стороны сама по себе не вызывает перекомпиляцию другой. Изменения входных данных или времени
по-прежнему перерисовывают затронутые буферы, даже если перекомпиляция шейдеров не нужна.
Это относится к явно добавленным нодам Buffer: автоматической вставки буферов нет,
новые настройки ноды не требуются.

Связь **Buffer → Fractal** требует неподключённый **Seed Step=0**: готовый буфер не может
менять seed между октавами. Подключённый Seed Step отклоняется даже при текущем нуле.
**Fractal → Buffer** разрешён и сохраняет готовый результат фрактала.
Buffer сохраняет исходное поле только в локальной области `0..1`. При выборке за её пределами
Fractal использует **Wrap** буфера: по умолчанию **Clamp**, для повторяющихся октав — **Repeat**.
Увеличение одного готового изображения в буфере не добавляет новых деталей.
Warp оставляет **None**, **Progressive**, **Independent** как отдельную операцию искажения домена.

**Evolution=0** у Cellular и Triangle Voronoi плавно
двигает точки в пределах разброса Jitter. Подключи Time для анимации; отрицательные
значения ведут движение в обратную сторону, ноль сохраняет исходный рисунок.
Общего цикла 0..1 нет. Fixed Radius сохраняет радиус вращения в 2D/3D; в 1D точки
двигаются между двумя крайними положениями. При одинаковых Evolution и остальных
настройках точек оба шума используют одну сетку. Бесшовность сохраняется, если
Evolution одинаков по всему изображению или повторяется с тем же пространственным периодом.

**Cellular Noise** объединяет значения ячеек, рисунки расстояний и границы ячеек.
**Output** выбирает **Cell Value**, **F1** (по умолчанию), **F2**, **Add**, **Subtract**,
**Multiply**, **Divide** или **Distance to Edge**. **Smoothness=0** сохраняет жёсткий
рисунок; увеличение смешивает значения соседей или смягчает гребни расстояний.
**Metric** предлагает **Euclidean**, **Euclidean Squared**, **Manhattan**, **Hybrid**.
Она скрыта только для Distance to Edge, который использует евклидовы границы.
**Distribution** выбирает **Uniform** или **Fixed Radius**, **Jitter=1** задаёт разброс
точек. Отдельные выходы **F1**, **F2**, **CellValue**, **ToPoint** сохраняют точную
геометрию без фильтрации. CellValue повторяем, но не является уникальным ID.

**Spots Noise** создаёт мягкие пятна. **Density=1** задаёт их количество,
**Radius=0.35** — размер, **Softness=0.5** — мягкость края, **Elongation=1** —
вытянутость, вектор **Direction** (изначально вдоль X) — направление.

Три ноды **Procedural/Noise/Warp** используют общие Position, Scale, Period и Seed.
**Strength=0.1** задаёт силу смещения. Их фракталы — **None**, **Progressive**
(октава искривляет координаты следующей) и **Independent** (октавы читают исходную позицию),
с входами Octaves, Lacunarity и Gain. **Displacement** — знаковое смещение,
**Position** — исходная позиция плюс смещение. Подключи Position к следующему шуму
или выборке изображения; Strength=0 сохраняет координаты. Weighted Strength и Ping Pong Strength у Warp нет.

**White Noise** и **Blue Noise** в **Procedural/Noise/Grain** создают полосы **1D** или зерно **2D**.
**Position** всегда содержит две компоненты UV; для сдвига используй **Add**. Смещение в пикселях сначала раздели на **ImageSize**.
**Grain Size=1** — в пикселях, **Direction=0** — в градусах. **Seed=1337** выбирает вариант.
**Image Size** в режиме **Canvas** берёт размер холста; **Custom** позволяет ввести свой. **Inverted** выключен.
**Value** даёт монохромный шум, **Color** — независимые RGB с альфой 1. Фрактала у зерна нет; его Direction действует только в 1D. Direction у Gabor/Spots,
Anisotropy и Elongation действуют только в 2D/3D.

Старые Noise, Cellular, Domain Warp, Tileable Noise, Voronoi Edge и старый Gabor
не поддерживаются и автоматически не преобразуются. Создай их заново текущими нодами.
Поведение отдельного слоя Noise сохраняется.

У **Random** неподключённый вход Coordinates по умолчанию использует **UV** текущего пикселя.
Выбери **Custom** для постоянных координат или подключи **Repeat.Cell** для одного значения
на повторяемую ячейку. Ранее сохранённые постоянные координаты остаются в Custom; их можно переключить на UV.

У **Shape** есть Ellipse, Rectangle, Rounded Rectangle, Polygon, Star, Capsule и Line Segment.
Выход **Out** содержит сглаженную маску; **Distance** отрицателен внутри фигуры и положителен снаружи.
У Polygon и Star расстояние и ширина Feather остаются равномерными при растяжении по одной оси.
Подключи два выхода Distance к **Combine Distance**, затем используй его **Mask** как покрытие.
Выбери Union, Intersection или Subtract (B вычитается из A). Smoothness сглаживает соединение
фигур, Feather смягчает край маски. Capsule использует Center, Size и Rotation; Line Segment —
Start, End и Width. Смена режима Shape меняет поля и удаляет соединения с исчезнувшими входами.
Расстояние до эллипса приближённое, поэтому построенная по нему обводка может иметь переменную толщину.

Для цветного градиента соедини **Gradient Factor.Out → Sample Gradient.T**, а параметр
**Gradient** подай в **Sample Gradient.Gradient**. Полученный цвет подключи к **Output**.
У масок Checkerboard, Stripes, Grid, Rings и фигур сглажены края.
У **Stripes**, **Rings**, **Wave** и **Ripple** есть отдельный вход **Phase**, задающий сдвиг в циклах.
Его можно связать с параметром или с **Time**, чтобы увидеть анимацию в превью графа.
Phase повторяется через каждый цикл, в том числе при отрицательных значениях. Период Offset
по каждой оси равен 1 у Grid и 2 у Checkerboard. Большие сдвиги сохраняют ровную заливку и края узора.
У Stripes есть профили Square, Triangle и Sine; Width действует только в Square.
Angle, Rotation и Direction узоров/зерна задаются в градусах, как и Strength у Twirl.
У Gabor/Spots Direction — вектор.

Подключай **Out** UV-узла к следующему генератору или к **Sample Texture.UV**.
**Repeat.Cell** содержит координаты ячейки, в том числе отрицательные. **Input/Instance Index**
использует отдельный индекс (сейчас нулевой) и с Cell не связан. У **OpenSimplex2 Warp Noise** выход **Displacement**
даёт смещение, а **Position** — преобразованные координаты. При **Strength = 0** искажения
сохраняют исходные координаты; векторы смещения сохраняют свою длину. UV могут выходить за
пределы `0..1`: нужное поведение на краях изображения выбирается в Sample Texture.
Transform UV меняет координаты внутри графа независимо от Transform самого слоя.

**Vector Displacement** принимает вектор напрямую в режиме **Signed RG** или декодирует
**Packed RG** из `0..1`, где `(0.5,0.5)` означает нулевое смещение. Strength масштабирует X и Y отдельно.
Положительный Strength у **Bulge / Pinch** увеличивает рисунок, отрицательный стягивает его.
**Polar Coordinates** переводит координаты в угол в оборотах и удвоенное расстояние от Center
или обратно в UV. **Mirror** отражает выбранные оси в положительную сторону относительно Center;
**Kaleidoscope** повторяет радиальные секторы.
Точные порты и режимы описаны в [контракте процедурных узлов](../ShaderLayer.md#procedural-and-uv-nodes).

## Изменить цвет и прозрачность

Чтобы перекрасить текстуру, соедини **Sample Texture → Hue → Saturation → Output**.
Коррекции находятся в **Color/Adjustments** меню Create Node. Начни с **Degrees = 0** и
**Amount = 1**, затем меняй угол оттенка или уменьшай насыщенность до нуля для серого изображения.
Эти коррекции сохраняют прозрачность исходного цвета.

| Настройки | Что меняется в изображении |
| --- | --- |
| **Exposure / Stops** | Осветляет или затемняет линейный RGB: +1 удваивает его, −1 уменьшает вдвое. |
| **Lightness / Amount** | Меняет светлоту от −100 до 100; 0 оставляет её прежней. |
| **Contrast / Amount** | Меняет контраст вокруг 0.5; 1 сохраняет исходный цвет. |
| **Levels / Input Range, Gamma, Output Range** | Задаёт чёрную и белую точки и средние тона. Luminance меняет общую яркость, RGB — каналы отдельно. Отключи Clamp, чтобы сохранить значения за Input Range. |
| **Color Balance / Shadows, Midtones, Highlights** | Окрашивает тени, средние тона и света. Range меняет охват этих областей; Preserve Luminance сохраняет яркость. |
| **Posterize / Levels** | Превращает плавные переходы в ступени; используются как минимум два уровня. |

Для окраски по палитре добавь **Color/Mapping/Gradient Map**. Подай изображение в Color,
параметр **Gradient** — в Gradient и выбери Channel. Luminance распределяет тёмные и светлые
тона по градиенту. Режим Preserve по умолчанию сохраняет альфу изображения; Multiply умножает
её на альфу градиента, Replace берёт только альфу градиента.

**Color Curves** меняет тона через поля кривых или подключённые параметры Curve. Master действует на RGB вместе или на
яркость, затем Red, Green и Blue уточняют отдельные каналы. Неназначенная кривая ничего не
меняет. Альфа меняется только через кривую Alpha. Кривые без коррекции сохраняют
значения выше белого и ниже чёрного.

Для выделения цвета добавь **Color/Selection/Color Mask**, выбери Key Color и настрой
Tolerance и Softness. Chroma сравнивает цветовую составляющую, RGB учитывает различия яркости,
Perceptual измеряет разницу в Oklab. **Hue Range** выделяет интервал оттенков в градусах:
`(330,30)` проходит через красный. Feather смягчает края, а Saturation Range исключает или
ослабляет почти серые цвета. Оба узла выдают маску, где белый означает выделение; альфа
изображения на неё не влияет. Подключи маску к **Color/Alpha/Set Alpha.Alpha**: Replace
использует её напрямую, Multiply также сохраняет исходную прозрачность. RGB остаётся прежним.

**Color/Mixing/Mix Color** смешивает A и B по T; по умолчанию выбран Perceptual. Linear RGB
и sRGB дают другие промежуточные цвета. При T = 0 получается A, при T = 1 — B; значения за
этими границами продолжают переход. Альфа тоже интерполируется. Для наложения с учётом альфы
используй **Blend**.

Соединения цветовых портов не преобразуют цветовое пространство автоматически.
**Color/Conversion/Convert Color** явно переводит Linear RGB, sRGB, HSV, HSL и Oklab друг в друга.
Неподключённый вход показывает выбор цвета для Linear RGB и числовые поля Float4 для остальных пространств.
Перед обычной обработкой цвета или Output верни компоненты в Linear RGB. HSV и HSL используют
sRGB-компоненты и оттенок в оборотах. HSV теряет отрицательный RGB, но сохраняет HDR-яркость;
HSL ограничен `0..1` и теряет как HDR, так и отрицательный RGB. Linear RGB/sRGB/Oklab их сохраняют.
**Luminance** получает яркость из линейного RGB. Цветовые коррекции обычно сохраняют HDR и отрицательные значения.
У Levels есть явный переключатель Clamp; Set Alpha не ограничивает прозрачность. При необходимости
добавь Clamp и выбери нужный диапазон цвета в Rendering слоя.

## Создать нормали и смещения

Для карты нормалей добавь **Normal/Height to Normal**. В режиме **Source: Texture**
подключи параметр Texture к Height и выбери Channel. Radius измеряется в текселях исходной
текстуры; Wrap и Filter управляют выборкой на краях.
Выбери **Source: Value**, чтобы подключить шум, маску или другое скалярное вычисление
высоты. Узел вычисляет его в соседних координатах; Radius здесь измеряется в пикселях документа
и не зависит от размера превью.
Такой же выбор есть у **Height to Distortion**. Strength регулирует силу рельефа, Radius —
расстояние выборки. Оба источника поддерживают Scharr, Sobel и Central Difference;
Flip X и Flip Y меняют направление наклона. Ветка с постоянными координатами даёт постоянную высоту.

В **Packed RGB** плоская нормаль равна `(0.5,0.5,1)` — это удобно для видимой карты нормалей.
В **Signed XYZ** она равна `(0,0,1)`. Выбирай одинаковые **Output Encoding** у Height to Normal
и **Normal Encoding** у следующих узлов: граф не применяет к этим векторам цветовое преобразование.
**Normal Blend** объединяет Base и Detail методом Reoriented или Whiteout; Strength регулирует
силу деталей. Выход нормализован и использует выбранную кодировку.

Для искажения изображения выбери **UV/Distortion/Height to Distortion** с текстурой высоты
или **Normal to Distortion** с вектором нормали. Подключи выход к
**Vector Displacement.Displacement**, выбери одинаковый Signed RG или Packed RG на обоих узлах,
затем соедини **Vector Displacement.Out → Sample Texture.UV**. Первые два узла дают смещение,
а итоговые UV формирует Vector Displacement. Векторы смещения сохраняют величину, без нормализации.
Normal to Distortion масштабирует X и Y отдельно. Нулевое смещение равно `(0,0)` в Signed RG
и `(0.5,0.5)` в Packed RG. Height to Normal направляет XY против уклона высоты, а Height to
Distortion — вдоль него. Если искажение по нормали направлено не туда, поменяй знак Strength
или используй Flip X/Flip Y. Величина смещения тоже отличается из-за нормализации нормали.
Точные входы и режимы — в [контракте цветовых узлов и нормалей](../ShaderLayer.md#color-and-normal-nodes).

**Normal Encode** преобразует знаковые нормали в Packed RGB, **Normal Decode** — обратно.
Они меняют представление без нормализации. **Normal Strength** сглаживает рельеф при 0,
сохраняет единичную нормаль при 1 и разворачивает XY при отрицательных значениях.
Для освещения подключи результат к **Normal Lighting.Normal**, выбери соответствующий
Normal Encoding и настрой Color поверхности, LightDirection, LightColor, Intensity и Ambient.
Увеличь **SpecularIntensity** с начального 0, чтобы добавить блик: SpecularColor задаёт его цвет,
Roughness расширяет его, SpecularOnly оставляет только блик. Альфа поверхности сохраняется.

**Premultiply** умножает RGB на альфу, **Unpremultiply** восстанавливает прямой RGB при ненулевой
альфе и возвращает чёрный RGB при нулевой. Сама альфа не меняется. Output ожидает прямой цвет:
после вычислений с умноженным на альфу цветом поставь Unpremultiply.

## Применить фильтр к вычислению

Подпись входов с повторным вычислением начинается с **↻** и пробела даже без подключения.
Символ использует тот же шрифт и выравнивание, что и остальной текст.
У Buffer, Caustics и Caustics Noise после подписи выхода, перед точкой порта, виден значок
цилиндра хранилища даже без подключения. Он обозначает чтение из промежуточной текстуры
и входит в общую область подсветки, выделения и перетаскивания подписи.
Наведи курсор на подпись любого подключённого входа или значок рядом с ней: подсветится
его исходная ветка без всплывающей подсказки. Подпись выхода подсвечивает использующие его ноды
дальше по активным связям. Исходная нода, её другие выходы и посторонние источники не выделяются.
Для выходных подписей, включая параметры, действует та же механика клика и перетаскивания.
Клик выделяет ноды ветки при отпускании без движения,
**Ctrl+клик** добавляет их к текущему выделению (на macOS также работает **Command+клик**).
Перетаскивание за подпись перемещает ноду и отменяет выделение ветки. Точки портов остаются для создания соединений.
Наведение на подпись неподключённого порта не подсвечивает его точку.
После ухода курсора подсветка исчезает, а выделение сохраняется. Короткая черта у выхода
Buffer обозначает границу кеша: исходная ветка буфера не подсвечивается, а вычисления его UV
остаются видимыми. Подключённые параметры и математические константы входят в ветку.

Подключи узор или **Sample Texture.Out** к **Blur.In**, а Blur.Out — к Output, чтобы смягчить
изображение. **Sharpen** усиливает локальный контраст, **Edge Detection** выделяет перепады,
**Dilate** расширяет светлые области, а **Erode** сужает их. Blur учитывает альфу Color, чтобы
невидимые цвета не создавали ореолы; на входе и выходе Blur используется прямой RGBA.
Sharpen и Edge Detection сохраняют альфу Color.
Числовые векторы и Dilate/Erode обрабатываются покомпонентно; для общего контура подключай скалярную маску.

Radius задаёт расстояние выборки в пикселях документа. У Blur, Sharpen, Dilate и Erode поле
**Minimum Kernel** задаёт минимальное ядро: **3 × 3**, **5 × 5** или **9 × 9**. При большом радиусе
добавляются выборки, чтобы шаг не превышал один пиксель. Более плотное минимальное ядро помогает с субпиксельными деталями.
Edge Detection использует фиксированное ядро Sobel 3 × 3. Strength регулирует Sharpen и
Edge Detection. Результат может выйти за `0..1`; для ограниченной маски добавь Clamp или Saturate.

Фильтр вычисляет подключённую ветку в соседних координатах. Сохраняй зависимость узора от UV:
постоянные координаты дают постоянный результат. Большие радиусы, особенно в цепочках фильтров,
могут замедлять превью. Масштаб Radius одинаков в превью узла и при рендере всего слоя.
Radius может меняться по изображению: встроенные фигуры и узоры сохраняют сглаживание
внутри фильтра. При нулевом Radius узлы Blur, Sharpen, Dilate и Erode сохраняют исходное изображение.

**Slope Blur** размывает **In** вниз по склону скалярного поля **Slope**. Подключи к Slope
высоту или шум; начальное значение `0` сохраняет изображение. **Strength** по умолчанию `8`,
отрицательные значения разворачивают путь. Градиент не нормализуется, поэтому крутые склоны
смещают выборку дальше. **Samples** по умолчанию `16`, округляется до целого в `1..64`;
больше шагов позволяет точнее следовать изгибам пути. **Average** усредняет значения,
**Min** сохраняет более тёмные, **Max** — более светлые. Average учитывает альфу Color;
Min/Max обрабатывают каждую компоненту, включая альфу. Нулевая Strength сохраняет In.
У этого фильтра нет Radius.

**Bilateral Blur** смягчает детали, сохраняя границы по направляющему сигналу.
**Radius** по умолчанию `2` пикселя документа. **Tolerance** начинается с `0.1`:
меньшее значение сохраняет больше различий в сигнале, большее допускает сглаживание между ними.
Отрицательная Tolerance считается нулевой; при `0` участвуют только точно совпадающие значения.
**Guide = Source** использует сам In; **Custom** добавляет числовой вход или Color **Guide**
для отдельного узора, по умолчанию скалярный `0`. В обоих режимах цветовой Guide сравнивается
в premultiplied RGBA и не учитывает скрытый RGB полностью прозрачных областей.
Тип Guide не меняет тип выхода: он определяется только In. Фильтрация Color учитывает альфу;
при нулевом Radius исходный In сохраняется.

Оба узла сохраняют числовой тип или Color входа. Slope Blur многократно читает изображение
и склон, Bilateral Blur — изображение и Guide. Большие Samples и Radius, а также цепочки
фильтров могут замедлить превью, особенно если на входе есть Gabor Noise.
Первая компиляция цепочки с глубоко вложенными фильтрами также может занимать несколько минут.

## Повторно использовать Sub Graph

Выдели вычисление и выбери **Convert Selection to Sub Graph** в контекстном меню. Внешние
соединения станут входами и выходами нового узла. Дважды щёлкни по нему, чтобы открыть
вычисление; редактируй **Inputs** и **Outputs** в боковой панели и возвращайся через **Back to Graph**.
Для повторного использования выбери определение в разделе **Sub Graphs** меню создания.

Изменения определения действуют на все его экземпляры в этом Shader-графе. Имена портов можно
менять: соединения сохраняют их постоянные идентификаторы. Определения остаются в документе.
Sub Graph может содержать другие определения, но не может прямо или косвенно вызывать себя.
Общие для всех экземпляров значения выноси в параметры, а различающиеся — во входы Sub Graph.

## Переместить и удалить узлы

Выбери **Replace Node** в контекстном меню узла, чтобы заменить его через список создания.
Список открывается в текущей категории, а текущая нода слегка подсвечена. Стрелка назад
ведёт к родительским категориям; поиск находит ноды во всём списке.
При совпадении имени и типа порта сохраняются соединения и введённые значения. Остальные
соединения удаляются. Новый узел получает свои настройки по умолчанию, сохраняя положение,
выделение и группу. Один Undo отменяет всю замену. Обязательный Output и узлы интерфейса
Sub Graph заменить нельзя.

Нажми **Del**, чтобы удалить выбранные узлы, включая **Reroute**. **Output** обязателен,
его удалить нельзя. При редактировании текстового или числового поля **Del** редактирует
значение, не удаляя узел.

При перетаскивании слабая привязка выравнивает центры соединённых входных и выходных портов по высоте.
Она не меняет X; штатная привязка прямоугольников узлов по Y имеет приоритет.
Удерживай **Shift**, чтобы отключить привязку. Совместно перемещаемые узлы сохраняют взаимное расположение.

## Упорядочить соединения с Reroute

Дважды щёлкни по существующему соединению, чтобы вставить **Reroute**, или выбери
**Add Reroute** в контекстном меню соединения. Reroute создаётся только на существующем
соединении; в поиске узлов его нет.

У мини-ноды нет заголовка, превью и полей параметров. **In → Out** передаёт исходный тип
и значение без изменений: числа, векторы, Color, Boolean, Texture, Gradient и Curve.
Reroute не добавляет вычислений и не меняет изображение. Перетаскивай мини-ноду, чтобы
расположить провода удобнее, и подключай **Out** к нескольким входам для ветвления одного значения.
Тяни за любой порт для создания связи, за корпус — для перемещения ноды. Цепочка Reroute без источника считается разрывом связи без ошибки: каждый последующий вход использует своё сохранённое значение или значение по умолчанию. Точки и провода остаются в графе; подключение источника восстанавливает сигнал.

При удалении Reroute его источник соединяется напрямую с последующими входами, в том числе
в цепочке из нескольких Reroute. Обычное удаление соединения разрывает эту связь.
Положение Reroute и соединения сохраняются вместе с документом; вставка, перемещение,
изменение соединений и удаление поддерживают **Undo/Redo**.

## Посмотреть результат узла

Наведите курсор на узел: внизу слева появятся иконки **Image** и **Height**.
Height показывает изображение узла на рельефе в ортографическом виде под 45°.
Кнопка **⋮** открывает настройки **Height Channel** (R, G, B, A или Luminance),
**Height Scale** и **Texture**. Текстура изначально включена; отключите её,
чтобы рассмотреть рельеф без исходной окраски. У каждого узла свои настройки
в окне графа. Когда кнопки скрыты, режим Height обозначен неброской иконкой рельефа.
Если у узла несколько выходов, список справа выбирает выход для обоих режимов.

Height использует то же небольшое изображение, что и обычное превью узла.
Оно помогает оценить форму и склоны, но не отдельные пиксели большого холста.
Более подробный рельеф итогового результата доступен в [Layer Preview](preview.md).

**Accurate Lighting** управляет освещением в превью нод. По умолчанию Global Normal Lighting
использует один белый направленный свет сверху слева под углом 45°. Включи переключатель
в шапке графа или User Settings → Shader Graph, чтобы видеть свет документа, включая Area и Cookie.
Выбор сохраняется после закрытия окна и перезапуска редактора. Local сохраняет свои настройки;
Layer Preview, Canvas и экспорт всегда используют настоящее освещение.

Значок Info сообщает о нескольких расчётах Global Lighting в одном проходе. Если задача позволяет,
смешай входные параметры поверхности по маске перед одной Normal Lighting. Смешивание уже
освещённых результатов всё равно вычисляет обе ветки. Смешивание входов может изменить рисунок,
особенно зеркальные блики.

**SVM Nodes Only** оставляет в Create Node, Replace Node и списке при сбросе связи
только ноды, поддерживаемые SVM с начальными настройками. Фильтр независим от
**SVM Preview (Experimental)**. Изменение настроек или подключение неподдержанной
ветки по-прежнему может перевести превью на HLSL.

**Layer Preview** обновляется на ближайшем обновлении редактора без фиксированной паузы.
Частые правки объединяются; готовый результат Canvas используется повторно.
Скрытое или свёрнутое превью не рендерится.

Спиннер в центре показывает, что изображение превью ожидает обновления.
Во время ожидания изображение затемнено, а сверху вниз по нему проходит мягкая светлая волна. Бирюзовая молния в заголовке ноды
показывает, что её текущее превью рассчитано через SVM; у Output она относится к итоговому превью.
Спиннер исчезает после отрисовки актуального изображения или сообщения об ошибке.
Скрытые превью не анимируют индикатор; обычная анимация времени не держит его включённым.

Включи **SVM Preview (Experimental)** на панели графа, чтобы попробовать другой
способ расчёта превью. Он применяется к поддерживаемым превью нод и результату
Shader-слоя в этом окне. FX и обтравка слоя продолжают применяться.
Превью результата Shader FX, холст документа и экспорт используют
штатный рендер; обычная компиляция графа продолжается в фоне.
При первом включении компиляция общего SVM-шейдера может занять значительное время.
Пока готовится новый результат, превью сохраняет предыдущее изображение.
Экспериментальная опция по умолчанию выключена.

Прототип поддерживает числовую и логическую математику, Swizzle, цветокоррекцию,
нормали, преобразования UV, Time и числовые, Color- и Boolean-параметры.
Perlin, Value, Value Cubic, OpenSimplex, Flow, Gabor, Cellular и Shard поддерживают
1D/2D/3D. Phase у Flow можно анимировать через Time. Gradient сохраняет размерность
шума, Curl доступен в 2D/3D. Для них доступны Filtering и Periodic, в том числе фильтрация
источника внутри Fractal. Fractal сохраняет свою фильтрацию и вложенность до двух нод.
Sample Gradient и Sample Curve принимают значения прямо в порте или параметры.
Blend, Height to Normal/Distortion с текстурой или числовой веткой высоты, Local Lighting и
упрощённый Global Lighting тоже работают через SVM. Accurate Global Lighting
сохраняет точный расчёт источников света документа. Если входные ветки поддерживаются,
SVM подготавливает все данные для освещения вместе; иначе используется HLSL.
Результат освещения сохраняется.

Также поддерживаются Canvas Position/Data, Pixelate UV, Tile UV, Blackbody, Dither,
Shape, Combine Distance, Checkerboard, Stripes, Grid и Rings, включая сглаживание
паттернов внутри Fractal. Gradient Map и Color Curves сохраняют HDR и настройки альфы.

Spots Noise и все три Warp Noise поддерживают 1D/2D/3D; Triangle Voronoi Noise —
все выходы в 2D. Filtering, Periodic, распределения и накопление Warp сохраняют
обычные расчёты. White/Blue Noise поддерживают 1D/2D, Value/Color, Invert и заданный
Image Size. Edge Detection сохраняет альфу центральной выборки для входа Color.
Apply Transform2D принимает значение в порте или параметр и поддерживает Local/Input,
включая проективные преобразования. Эти ноды также могут питать Fractal в пределах лимитов SVM.

Texture Size, Sample Texture и Sample Input тоже работают через SVM. Сохраняются HDR,
альфа, отдельные каналы, Point/Bilinear и режимы границ. Sample Input читает выбранный
вход слоя или изображение перед текущим FX. Текстурные параметры могут читать другой
слой; Self читает вход текущего FX. Неподдержанные сочетания используют HLSL.


Целочисленные скалярные и векторные параметры и параметры в пикселях тоже работают
через SVM. Pixel Scale применяется во время рендера. Sub Graph использует общее с HLSL
раскрытие: сохраняются вложенные вызовы, несколько выходов и значения каждого экземпляра.
Превью внутри определения используют значения интерфейса по умолчанию. Неподдержанные
зависимости сохраняют обычный HLSL-путь.

В превью Shader-слоя поддерживаемые ноды после явно добавленного **Buffer** могут
снова использовать SVM, даже если исходная ветка буфера рассчитана через HLSL.
Это также доступно после **Caustics**, **Caustics Noise** и прямого результата
**Global Normal Lighting**. Size, Wrap и Filter буфера по-прежнему определяют
результат выборки. Это не распространяется на Global Lighting внутри Fractal
или фильтра размытия.
Остальные ветви, настройки и графы, превышающие ограничения прототипа, автоматически
используют обычный HLSL. Выключи опцию, чтобы вернуть штатные превью во всём окне.
Подробнее — в [перечне поддерживаемых возможностей и ограничений](../ShaderGraph.md#experimental-svm-preview).

**Layer Preview** находится поверх графа, изначально справа внизу. Перетаскивай заголовок или
изображение, чтобы переместить блок, и его стороны или углы, чтобы изменить размер. Рядом с краями
области графа блок примагничивается вплотную, без отступа, и сохраняет привязку при изменении размера окна. У угла
он привязывается сразу к двум краям; привязанные границы подсвечены. Чтобы открепить блок,
оттяни его от края. Окно запоминает положение, привязку и размер. Масштабирование и перемещение
графа не сдвигают превью. Кнопки **R/G/B/A** в заголовке переключают каналы только для превью.

Превью до **128 × 128** есть у UV, выборок, генераторов и математических операций обработки изображения.

Итоговое изображение имеет приоритет при компиляции. Затем обновляются превью непосредственно изменённых нод, в том числе нод с подключёнными или отключёнными входами, после них — ближайшие к месту последнего изменения. Панорамирование и зум не перемещают эту точку приоритета. До первого редактирования порядок определяется расстоянием от центра вида. Код графа готовится в фоне, а до завершения компиляции остаётся последнее рабочее изображение. Первая компиляция сложного шейдера всё ещё может занимать время.

В графах с множеством раскрытых превью подготовка после правки выполняется совместно. Готовые изображения обновляются без повторного обновления неизменённых полей и без дополнительного ожидания после компиляции. Значения, связи и выбор выходов превью работают по-прежнему.

Превью нод компилируются асинхронно и обновляются с общим бюджетом времени. При отдалении разрешение уменьшается под экранный размер, при приближении восстанавливается. Изменение независимой ветки не требует повторной компиляции остальных. Анимация обновляется до 30 раз в секунду в активном окне графа и до 10 в остальных случаях.

Пока изменения графа компилируются, слой или FX показывает последнюю рабочую картинку. При возврате к недавно скомпилированному варианту он используется повторно, если ещё доступен. **Compile**, сохранение и экспорт дожидаются нужного результата; при ошибке черновика остаётся рабочая версия и сообщение об ошибке.

Первоначальная подготовка превью для графов из встроенных нод ускорена без снижения разрешения и изменения расчётов.

У **Constant**, **Canvas Data**, **Texture Size**, **Split**, **Compare**, **Output**, **Parameter**
и **Reroute** превью нет: полезная информация уже видна в полях и портах.
У узлов без превью или со свёрнутым превью нет общей минимальной ширины: размер определяется содержимым.
При раскрытии превью минимальная ширина возвращается.
У HLSL-функций показываются числовые и Color-выходы; Boolean и ресурсы исключены.
Если подходящих выходов несколько, наведи курсор на ноду и выбери нужный
в переключателе внутри правого нижнего угла превью. Список открывается вверх,
его правый край выровнен по правому краю превью.
При приближении графа всё меню увеличивается пропорционально, включая галочки, текст и отступы,
чтобы пункты не становились мельче поля выбора.

Строки Preview больше нет. Наведи курсор на узел: сверху поверх изображения появится стрелка вверх.
Нажми её, чтобы свернуть превью в тонкую полоску с небольшой кнопкой со стрелкой вниз по центру.
Нажатие на кнопку раскрывает превью обратно.
Состояние превью каждого узла сохраняется в документе и при копировании узлов.
Общего превью выбранного узла на боковой панели нет.
Превью обновляется при изменении результата, только когда оно раскрыто и находится в видимой
области графа. Свёрнутое или находящееся за её пределами превью ждёт раскрытия и возвращения в видимую область.

Число отображается оттенком серого; двухкомпонентный вектор — в красном и зелёном каналах,
трёхкомпонентный — в RGB, четырёхкомпонентный вектор и Color — с альфой. Ресурсы Texture, Gradient и Curve
напрямую не показываются: подключи соответствующий Sample и раскрой его превью.

**Output** оформлен как горизонтальный конечный блок: вход слева, **Output / Layer result**
справа, со скруглённым правым краем. **RGBA** принимает цвет с альфой либо RGB с альфой 1.
**Alpha Scale** по умолчанию равен **1** и умножает входную альфу: можно ввести число или
подключить маску. RGB не меняется, результат умножения не ограничивается диапазоном 0..1. Результат слоя смотри в
**Layer Preview**. Превью узлов показывают значения до Transform и FX слоя.
При ошибке превью узла очищает изображение и показывает сообщение,
чтобы прежняя картинка не выглядела результатом выбранного вычисления.

## Выбрать элементы управления параметрами

Эти типы параметров позволяют настраивать граф из **Properties**:

| Тип | Управление и результат |
| --- | --- |
| **Enum** | Список именованных числовых вариантов. Каждому варианту задаётся своё значение, в том числе дробное: например, `0.25` или `0.5`. При выборе граф получает это значение. |
| **Seed** | Целочисленное поле с кнопкой **Random** для выбора повторяемой вариации. Значения и границы находятся в пределах −16777216…16777216. При выключенном **Range** Random использует весь этот интервал, включая обе границы. Сохранение и открытие документа сохраняют выбранное число. |
| **Point** | Положение из двух координат, по умолчанию `(0.5,0.5)`. `(0,0)` — левый нижний угол, `(1,1)` — правый верхний; точка может находиться за канвасом. |
| **Normal** | Направление из трёх компонентов, которое поступает в граф с единичной длиной. По умолчанию и при нулевом векторе используется `(0,0,1)`. |
| **Transform2D** | Общая рамка с положением, размером и поворотом; параметр позволяет редактировать её на канвасе. Подключите её к **Apply Transform 2D**. |

У **Float** минимум и максимум включаются независимо. Жёсткая граница ограничивает ввод,
мягкая задаёт рекомендуемый предел слайдера и допускает ручной ввод за ним. Циклический
диапазон требует двух жёстких границ и повторяет значения: для `0…360` ввод `370` даст `10`.
Если у Float включена только одна граница, она должна быть жёсткой; мягкие требуют обеих
границ, причём минимум должен быть меньше максимума.
**Vector2** может оставаться свободным вектором или задавать интервал с двумя жёсткими
границами. В циклическом режиме интервал может пересекать стык, например `(330,30)`;
полный оборот сохраняет угол встречи концов. Мягких границ у интервала Vector2 нет.
У Seed мягкие границы ограничивают **Random**, а вручную можно выйти за них в пределах
точных целых чисел, указанных выше.

Чтобы перемещать процедурную рамку, добавьте **Transform2D** и **Apply Transform 2D**.
Подключите параметр к **Transform**, а выход **Local** — к координатному входу узора или
сэмплера. Выход **Input** переводит локальные координаты в обратном направлении. Оба выхода
используют вход **UV**, по умолчанию — UV текущего пикселя. Узел не обрезает изображение
и не создаёт маску; при необходимости добавьте её отдельно. Порт трансформации нельзя
подключить напрямую к числовым вычислениям.

Неподключённый **Transform** показывает компактную кнопку **Transform**; по умолчанию
координаты не меняются. Кнопка открывает всплывающее окно с полями положения, размера,
поворота и **Reset**. Кнопки редактирования на канвасе в нём нет — она относится к параметру.
Подписи параметров, варианты Enum, границы и настройки пиксельных
единиц сохраняются при копировании и повторном открытии документа.

## Параметры и цвет

Перетащите заголовок параметра внутри **Parameters**, чтобы изменить порядок, или на граф,
чтобы создать узел Parameter в месте сброса. ПКМ по заголовку открывает **Use in Graph**,
**Duplicate** и **Remove**. Duplicate создаёт независимый параметр с теми же настройками
и значением; Remove удаляет также его узлы и соединения. Индикатор справа повторяет форму
и цвет выходного порта параметра.
При наведении подсвечиваются сам параметр и все его узлы Parameter; выделение не меняется.

Параметры включают числа, векторы, Boolean, цвета, текстуры, градиенты, кривые,
Enum, Seed, Point, Normal и Transform2D.
Несколько узлов Parameter могут читать один объявленный параметр: тогда одно поле
Properties управляет несколькими частями изображения.

Узел **Parameter** занимает одну компактную строку с именем параметра и выходным портом, без
подписи **Out**, внутреннего превью и выпадающего списка. Другой объявленный параметр можно
выбрать через контекстное меню узла; его значение настраивается в **Properties** слоя.

Подписи портов показывают тип в скобках: `1`–`4` для чисел и векторов, `T2` для текстур,
`G` для градиентов, `C` для кривых, `TR2` для Transform2D, `col` для цвета и `bool` для логических значений.
Например, `UV(2)` и `Color(col)`. Обозначение обновляется вместе с типом порта.

Числовые порты и **Color** имеют форму круга, **Boolean** — ромба, а **Texture**,
**Gradient**, **Curve** и **Transform2D** — квадрата.

Можно соединять числовые векторы с разным количеством компонентов. При подключении `float4`
к входу `float2` сохраняются X и Y, а Z и W отбрасываются. Недостающие компоненты короткого
вектора заполняются нулями: `float2(x, y)` превращается в `float4(x, y, 0, 0)`.
При подключении вектора к скалярному входу сохраняется X. Скаляр повторяется во всех компонентах
числового вектора: для `float4` значение `x` становится `(x, x, x, x)`.

**Color** — отдельный тип порта с теми же компонентами RGBA, что у `float4`. Вход RGBA у Output,
цветовые входы и результат Blend, цветовые выходы Sample Texture и Sample Gradient, а также
выходы параметров Color имеют фиксированный тип Color. Sample Curve выдаёт число.

Подключение числа или вектора к входу Color даёт следующие значения:

| Источник | Результат Color |
| --- | --- |
| `float(x)` | `(x, x, x, 1)` — непрозрачный серый. |
| `float2(x, y)` | `(x, y, 0, 1)`. |
| `float3(x, y, z)` | `(x, y, z, 1)`. |
| `float4(x, y, z, w)` | `(x, y, z, w)` — альфа сохраняется. |

При подключении Color к числовому входу действуют обычные правила преобразования `float4`.
Математические узлы с динамическим типом, например Add, Multiply и Lerp, рассматривают Color
как `float4` и выбирают наибольшее число компонентов среди числовых входов. Скаляр повторяется
во всех компонентах, короткие векторы дополняются нулями; альфа 1 при вычислении не добавляется.
Например, Multiply с Color и `0.5` уменьшает вдвое все четыре канала, включая альфу.
Числовые результаты с динамическим типом остаются векторами или скалярами, а не Color.

Значения из поля выбора цвета подготавливаются так же, как в других полях цвета WhimTex;
соединение портов не добавляет преобразование цветового пространства.

Граф сохраняет HDR и отрицательные числовые значения. Для явного ограничения используй Clamp,
а для HDR-вывода проверь настройки диапазона цвета в **Rendering** слоя.
Альфа управляет прозрачностью; перед Output не нужно умножать RGB на альфу.

## Посмотреть Generated HLSL

Панель показывает FX-скрипт WhimTex, созданный из графа: объявления `@param`, функции и `ApplyFX`.
Это код до добавления обёртки ShaderLab для Unity.
В сгенерированных функциях, ветвлениях и циклах используются отступы по четыре пробела;
они сохраняются при копировании.

Потяни нижнюю полосу **Generated HLSL** вверх, чтобы прочитать код, созданный из графа.
Полоса с подписью и горизонтальными линиями захвата работает так же, как у превью в Layer Settings.
Изначально панель скрыта; чтобы открыть её, потяни полосу вверх более чем на 14 логических
пикселей независимо от масштаба графа. Обычный щелчок ничего не меняет. Продолжай перетаскивание,
чтобы настроить высоту, или потяни вниз, чтобы скрыть код. Высота ограничена размером окна
и оставляет место для графа. Окно запоминает высоту и открытое или закрытое состояние панели.

Здесь используется то же поле кода, что и в FX Code, в режиме только для чтения: текст можно
выделять и копировать. Подсветка синтаксиса, номера строк, горизонтальная и вертикальная прокрутка
работают так же, как в FX Code в используемой версии Editor. При повторном открытии виден
актуальный код; если он не изменился, выделение сохраняется.
Чтобы изменить сгенерированный код, измени граф.

## Узлы HLSL и Custom Function

Выбери **Utility/Custom Function**, чтобы написать вычисление внутри узла. В **Ports** настрой
имена, типы и направления входов и выходов, затем отредактируй тело функции в **Code** и нажми
**Compile**. Здесь используется тот же редактор HLSL, что и в FX. Код можно свернуть или изменить
ширину узла и высоту поля за ручку в правом нижнем углу. Минимальная ширина совпадает с обычным узлом.
Поле кода занимает всю ширину узла, без нижнего отступа.
При сворачивании Code узел возвращается к обычной ширине, при раскрытии — к выбранному размеру.
Состояние Code и размер сохраняются в документе отдельно для каждого узла.

Изменения тела и портов сохраняются как черновик до успешного Compile. Настройки объявленных
портов сохраняются при перезагрузке скриптов и копировании узла, включая ещё не применённые
изменения. При ошибке продолжают работать прежний код и порты; проверка доступна и для неподключённого узла.
Поддерживаются векторы float/half, Boolean и Color; Texture доступен как вход.
Возвращаемое значение функции становится выходом **Result**, выходные аргументы сохраняют имена,
а у аргумента inout есть оба порта. Двухкомпонентные входы с именем **UV** или **uv** по умолчанию
используют координаты текущего пикселя; **Custom / UV** позволяет задать постоянное значение.

Помеченные библиотеки HLSL появляются в поиске узлов по категориям. Узел **Color/Adjustments/Contrast**
находится в `Packages/com.dcfapixels.whimtex/src/ShaderGraphFunctions.hlsl`: Amount 1 сохраняет
цвет, другие значения меняют контраст с сохранением альфы и HDR. **Refresh HLSL** заново сканирует
каталог. Кнопка **File…** у Custom Function позволяет выбрать `.hlsl` и поддерживаемую функцию
из него, даже если у неё нет метки каталога.

Библиотечные HLSL-узлы выглядят как обычные: название, порты и превью, без блока кода.
В их контекстном меню доступны **Refresh HLSL** и **Choose HLSL File…**. Документ использует
резервную копию исходников до успешного явного обновления. Отсутствующий или несовместимый файл
не меняет сохранённую копию; изменение библиотеки не обновляет документ автоматически.

Выбери **Convert to Custom Function** в контекстном меню, чтобы получить независимую
редактируемую копию. Порты, значения, соединения и текущий результат сохраняются, привязка
к файлу удаляется. В **Code** находится основной исходник целиком, включая вспомогательные
объявления; бэкапы include остаются в документе. Для изменения портов отредактируй объявление
функции в Code и нажми **Compile**. Прежние бэкапы include сохраняются, поэтому редактирование
работает и без исходных файлов. Конвертация поддерживает **Undo/Redo**.
Метаданные и создание библиотек описаны в [контракте функций](../ShaderLayer.md#hlsl-functions).

## Возможности

Граф принадлежит слою Shader и сохраняется в документе редактируемым. Изменение параметров
настраивает изображение, а изменение операций и соединений меняет само вычисление.
Связи должны вести к Output без циклов.

Незавершённый граф можно сохранить, в том числе с узлом Parameter
без назначенного параметра. Если граф не компилируется, редактор показывает ошибки и оставляет
последний рабочий результат, когда он доступен. Это изображение не отражает незавершённые
изменения. В документе сохраняется редактируемый граф, который можно закончить позже.

Для дополнительной обработки используй обычный список FX слоя. Типы портов и правила
выполнения описаны в [контракте Shader-слоя](../ShaderLayer.md).

## Каустика

**Caustics Noise** в **Procedural/Noise** сразу создаёт рисунок света под водой.
**Caustics** в **Filter** строит такой рисунок по входу **Height**: например,
**Perlin Noise → Fractal → Caustics** или по текстуре высоты. Обе ноды работают в 2D.

У **Caustics Noise** переключатели **Periodic** и **Filtering** шума тоже изначально выключены. Period по умолчанию равен 1 на каждой оси; отдельный Wrap управляет чтением уже рассчитанного изображения.

- **Strength** задаёт силу рельефа, **Depth** — расстояние, которое проходит свет.
  При увеличении переходы сжимаются в световые складки, затем начинают перекрываться.
- **IOR** управляет преломлением; **1** убирает его. **Light Direction** направлен к
  принимающей плоскости; `(0,0,-1)` соответствует свету сверху.
- **Softness** смягчает световые пятна, **Intensity** меняет яркость. Выход **Value**
  может превышать 1; для сохранения ярких пиков используйте HDR. Плоская поверхность
  даёт равномерное освещение.
- Для сдвига **Caustics Noise** поставь **Add** перед **Position**. Параметры **Scale**, **Period** и **Seed** задают
  поверхность. **Phase** меняет её по циклу; подключите Time для анимации.
- **UV** размещает готовый рисунок. **Resolution** по умолчанию — Custom **512 × 512**.
  Его увеличение повышает чёткость результата, но детализация поверхности имеет предел.
- **Wrap = Repeat** повторяет рисунок. Для бесшовного результата у **Caustics** входная
  высота тоже должна быть плавной и бесшовной: повторение не исправляет разрыв источника.

Плавные входные поверхности дают текучие складки, резкие перепады высоты — угловатые
формы. Чтобы усложнить поверхность, поставьте Fractal перед Caustics. Fractal после
любой ноды каустики повторяет готовое изображение и требует **Seed Step = 0**.
