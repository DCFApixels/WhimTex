# Наложение и обтравка

Поле **Blend** в строке слоя меняет смешивание его цветов с изображением ниже.
Уменьшай **Opacity**, чтобы сделать результат менее выраженным.

## Выбрать режим наложения

Начни с основных вариантов:

| Режим | Для чего подходит |
| :--- | :--- |
| Normal | Наложить слой поверх изображения с учётом его прозрачности. |
| Multiply | Добавить тени или затемнить текстуру. |
| Screen | Осветлить изображение или добавить мягкое свечение. |
| Add | Добавить яркие блики и светящиеся детали. |
| Overlay / Soft Light | **Overlay** резко усиливает контраст, **Soft Light** мягко добавляет оттенок и свет, сохраняя детали. |
| Darken / Lighten | Оставить более тёмные или светлые части двух слоёв. |
| Difference | Сравнить изображения или получить контрастный узор. |

**Overwrite** заменяет изображение ниже целиком, включая прозрачные пиксели: там, где слой пустой, нижнее изображение тоже стирается.
**None** оставляет его без изменений.
**Subtract** вычитает значения цветов, **Divide** делит их,
**Color Dodge** осветляет изображение, а **Linear Light** даёт резкий контраст.

У групп **Pass Through** позволяет содержимому смешиваться со слоями вне группы.
Другой режим рассматривает группу как единое изображение.

## Рисовать внутри формы другого слоя

Обтравка пригодится для теней на персонаже, текстуры внутри букв или раскрашивания силуэта:

1. Помести слой с формой под слоем, который хочешь ограничить.
2. Открой **⋮** верхнего слоя и включи **Clipping Mask**.
3. Рисуй или добавляй эффекты на верхнем слое — они останутся внутри нижней формы.

Переключить обтравку можно и через `Alt`-клик по границе над базовым слоем.
Несколько обтравочных слоёв подряд могут использовать одну базу. Держи их вместе с базой
в одной группе или на верхнем уровне списка: обтравка не ищет источник за пределами группы.
Если базовый слой скрыт или пуст, его обтравочные слои тоже не видны.
Если ниже нет базового слоя, обтравочный слой не отображается,
а в подсказке слоя появится **Clipping Mask: no base below this layer**.
