# Параметры шейдера

Объяви значение через `// @param`, чтобы добавить поле в Layer Settings. WhimTex создаст uniform и соответствующий контрол. После изменения кода или объявлений нажми **Apply**.

## Тип поля и подписи каналов

В объявлениях `toggle(тип)`, `color(тип)`, `enum(тип)` и `seed(тип)` вид поля выбирается отдельно от типа значения HLSL. По умолчанию используются float, float4, float и int соответственно. Toggle и color поддерживают bool, int, uint, half и float с одним–четырьмя компонентами. Enum принимает числовой скаляр, seed — int, uint или float.

`// @param rgba toggle(float4) _Channels = (1, 1, 1, 0)` показывает четыре независимых переключателя R/G/B/A в одной строке. `rgba float4` оставляет стандартное векторное поле и меняет только подписи. `color(float4)`, `color(float3)`, `color(float2)` или `color(float)` открывает выбор RGBA, RGB, RG или R соответственно. Для целых типов цвет округляется, для bool применяется порог 0,5; автоматического перевода в шкалу 0–255 нет. Float-цвета сохраняют HDR и прежнее понимание цвета. Seed вводится целым числом, а Random выбирает значение внутри диапазона, включая его границы. В условии можно указать один компонент: `_Channels.a`.

## Начать с числа и цвета

```hlsl
// @param float _Amount = 1 [0 .. 1]
// @param color _Tint = #FFAA66

float4 ApplyFX(PinnedUV uv, float4 color)
{
    return float4(lerp(color.rgb, color.rgb * _Tint.rgb, _Amount), color.a);
}
```

Эффект окрашивает RGB, сохраняя альфу. Начальное значение `_Amount` — 1, диапазон ползунка — 0–1.
Входные текстуры, пространства координат и полный список типов описаны в [справочнике HLSL](../ShaderFX.md#parameter-declarations).

## Процедурный шум в коде

Встроенная [библиотека WT noise](../NoiseLibrary.md) создаёт шум, ячейки и зерно без
дополнительного слоя Noise и явного include. Scale задаёт плотность, Period — повтор по
выбранным осям, фракталы добавляют детали. У White и Blue свои настройки размера зерна в
пикселях и Color. [Ноды графа](shader-layer.md#процедурные-узоры-и-искажения) используют WT.
Отдельный слой Noise сохраняет собственные настройки и вычисления; совпадение названия и Seed
не гарантирует одинаковый рисунок. Примеры HLSL и единицы значений — в справочнике по ссылке.
Большие смещения задавай через Offset в настройках шума, не прибавляя их заранее к UV:
так библиотека лучше сохраняет небольшие перемещения и мелкие детали.
У бесшовного шума нет фиксированного потолка плотности. Слишком мелкий рисунок может давать
муар; числовые ограничения для предельных настроек описаны в справочнике.
F1 и F2 в Cellular используют одну шкалу яркости: без фрактала и фильтрации F2 не темнее F1.
Add даёт их среднее, Subtract — разность, Multiply — произведение, Divide — отношение.
Эти правила применяются к каждой октаве до фрактальной обработки и фильтрации.
Smooth F1 смягчает переходы между ближайшими ячейками через Smoothness; ноль возвращает обычный F1.
Voronoise смешивает случайные значения ячеек: при Smoothness 0 видны отдельные области,
при 1 переходы шире. Фильтрация ячеек использует приближённые средние, поэтому контраст может меняться.
Вызовы шумов принимают позицию и общие настройки с фракталом в `settings.fractal`; затем
идут настройки семейства. Cellular и Gabor могут дополнительно вернуть данные первой октавы
через выходной аргумент. Общие шаги выборки ослабляют детали, которые мельче пикселя;
нулевые шаги сохраняют точечную выборку. Фильтрация приближённая: фрактальные преобразования
могут менять контраст и давать муар. В прежних скриптах Gabor шаги нужно перенести в общие настройки.
Perlin, Value, Value Cubic, OpenSimplex2/2S, Gabor и Flow поддерживают аналитические поля
Gradient и Curl для направленных искажений. Их сила зависит от скорости изменения шума;
знак сохраняется, длина вектора не нормализуется.
Flow плавно меняет рисунок вращением градиентов. Phase задаётся в циклах: 0 и 1 дают
одинаковый рисунок, начальное значение — 0. Увеличение Bandwidth у Gabor сужает огибающую
независимо от Frequency несущей. Spots создаёт мягкие светлые пятна: Density меняет их
количество, Radius — размер, Softness — края, Elongation/Direction — форму и направление.
В графе эти семейства доступны как отдельные ноды шума; настройки слоя Noise не меняются.
Исправление соседей решётки может изменить рисунок прежнего кода WT Value Cubic 2D/3D.

## Подписи и поля в заголовке

| Директива | Назначение |
| --- | --- |
| `// @param label(Сила оттенка) float _Strength = 1` | Задать понятную подпись поля. Подпись со скобками заключи в кавычки. |
| `hidden` в объявлении параметра | Скрыть обычную строку поля, не меняя значение и работу HLSL. Можно ставить до или после `label(...)`. |
| `// @control(_Opacity)` | Показать существующий параметр перед **⋮** в заголовке FX. |
| `// @header(Lighting)` | Добавить жирный заголовок без сворачивания перед следующим параметром. |
| `// @helpbox(Текст подсказки.)` | Добавить информационную подсказку перед следующим параметром. |

Размести `@control` сразу после `// @whimtex-effect Category/Name` или первой строкой, если маркера каталога нет.
Поддерживаются toggle, enum, float, color и float2/3/4. Без `hidden` поля в заголовке и содержимом меняют одно значение.
Неподдерживаемый тип не меняет заголовок. Повторные директивы вызывают предупреждение; применяется последняя.

Директивы описывают интерфейс, а не действие эффекта: поле прозрачности само по себе не добавляет смешивание.
Заголовки и подсказки без следующего параметра игнорируются. Метаданные сохраняются в пресетах и экспортируемом коде.

## Условия и группы

Используй `@if`, чтобы показывать настройки только для выбранного режима:

```hlsl
// @param enum _Mode = 0 { Basic: 0, Advanced: 1 }
// @if _Mode == 1
// @param float _Detail = 0.5 [0 .. 1]
// @param toggle(float) _UseExtra = false
// @endif
```

Условия поддерживают числовые сравнения `==` и `!=` с безусловно объявленным скаляром или явно указанным компонентом вектора; также можно сравнивать с true/false.
Вложенные условия не поддерживаются. Скрытые значения остаются и влияют на HLSL; если режим должен менять расчёт, добавь условие и в шейдер.
Экспорт пресета сохраняет условия.

Объедини поля строками `// @group(Tint; _Parameter)` и `// @endgroup`.
Связанный параметр должен быть объявлен внутри группы без условия.

| Тип параметра | Вид заголовка |
| --- | --- |
| toggle | Галочка слева от названия. Она меняет значение; для скрытия зависимых полей нужен `@if`. |
| enum, float, color, float2/3/4 | Компактное поле справа, с названием группы вместо отдельной подписи. Перетягивание названия float меняет значение. |
| Неподдерживаемый или многострочный тип | Остаётся в содержимом; заголовок не меняется. |

Компактное связанное поле убирается из содержимого. `hidden` не скрывает поддерживаемое поле в заголовке; несвязанные скрытые поля не показываются.
Если условия скрыли все строки содержимого, остаётся только заголовок.
Группа может содержать `@if`, но не другие группы.
`// @group(Advanced)` создаёт группу с обычным заголовком, а `// @group` — рамку без названия.

## Начальные кривые

Например, `// @param curve _Profile = easeInOut` создаёт поле профиля.

| Значение | Форма |
| --- | --- |
| `linear` | Прямая от (0,0) до (1,1). |
| `easeInOut` | Те же концы, с плавным выравниванием на обоих. |
| `easeIn` / `easeOut` | Квадратичная кривая 0→1 с плавным стартом / завершением. |
| `one` | Постоянная 1, ключи во времени 0 и 1. |

## Переименовать параметр

Меняй объявление `@param` и все обращения к нему в HLSL вместе. При переименовании на месте
значение и идентичность могут сохраниться; при добавлении, удалении или перестановке параметров проверь значения.
Алиасы пресетов и автоматический перенос по прежним именам не поддерживаются.

## Координаты и время

`LayerToLocal(uv)` позволяет процедурной форме следовать трансформу слоя. Подробнее — [соглашения о координатах](../ShaderFX.md).

`_WhimTexTime` содержит время в секундах, `_WhimTexInstanceIndex` — целочисленный индекс
экземпляра, пока равный 0. Читай их напрямую, без `@param` и повторного объявления.
Canvas и его зависимые слои/FX используют [время просмотра документа](preview.md#document-playback).
Редактор графа сохраняет независимые часы, включая FX превью результата. Save, обычный экспорт
и Live Update используют 0. Индекс меняет Seed только тогда, когда это явно написано в коде.

Временные входы Unity (`_Time`, `_SinTime`, `_CosTime`, `_TimeParameters`, `unity_DeltaTime`) разрешены и не блокируют **Apply**.
Они вызывают предупреждение: WhimTex не управляет их обновлением, поэтому Canvas, миниатюры и экспорт могут отличаться.
Для предсказуемого результата используй `_WhimTexTime` или свой числовой параметр вместо часов Unity.

Обычно FX повторно использует результат, пока входы и параметры не меняются; временные входы отключают этот кеш.
Предупреждение доступно через [общую диагностику FX](shader-fx.md#ошибки-компиляции), в том числе в Console и агенту.
Правила вывода описаны в [технической справке](../ShaderFX.md#shader-fx-a-first-snippet-parameters-and-reusable-code).
