# Руководство WhimTex

Пройди путь от первого документа до экспорта или сразу открой нужный инструмент.

Используй WhimTex для быстрых правок текстур, масок для VFX и небольших спрайтов прямо в Unity.
Начни с изображения, расположи слои, дорисуй детали и сохрани результат для своего проекта.
Названия настроек в руководстве совпадают с подписями в редакторе.

## Создание текстур для VFX

Комбинируй градиенты, [Noise](noise.md) и [Shader Processor](shader-fx.md), чтобы создавать маски для энергетических колец, вспышек и других эффектов. В этом кольце яркий ободок сочетается с тонкими радиальными полосами; слои позволяют отдельно настраивать форму и детали.
