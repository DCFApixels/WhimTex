# Слои эффектов

Слои эффектов создают обводку, смягчают изображение или превращают детали текстуры в рельеф.
Источник остаётся редактируемым: меняй его, и эффект подстроится.

| Вариант | Где находится | Что меняет |
| --- | --- | --- |
| **Effect Layer** | Отдельная строка в Layers | Выбранный источник: например Outline вокруг скрытого Shape. |
| **FX** | Секция FX выбранного слоя | Изображение этого слоя. Пресеты и HLSL описаны в [Shader FX](shader-fx.md). |
| **Shader Processor** | Отдельная строка в Layers | Композицию под ним. См. [область действия](shader-fx.md). |
| **Post FX** | Настройки просмотра в панели холста | Только вид, без изменения сохранённых пикселей. См. [Post FX](post-fx.md). |

## Выбрать эффект

Нажми **+** внизу Layers:

| Задача | Слой | С чего начать |
| :--- | :--- | :--- |
| Обвести форму | Outline | Ширина, мягкость и положение внутри или снаружи. |
| Сделать маску по расстоянию от края | SDF | Канал источника, Threshold и Max Distance. |
| Получить рельеф поверхности | Normal Map | Height Map или Texture. Подробнее — [Normal Map](normal-map.md). |
| Смягчить изображение | Blur | Mode → Gaussian, затем Radius. |
| Создать след движения | Blur | Mode → Linear или Circular. |
| Вернуть локальную резкость | Sharpen | Strength и Radius. |
| Состыковать противоположные края | Make Seamless | Method, Channels, грани и смешивание выбранного метода, дополнительная Poisson Correction. |

## Выбрать источник

| Input | Источник |
| :--- | :--- |
| Previous | Слой непосредственно под эффектом в той же группе. |
| Specific | Слой или группа, выбранные в **Target**. |
| All Below | Объединённые видимые слои ниже эффекта с их прозрачностью, смешиванием и FX. |

Для **Specific** выбери Target из списка или перетащи слой в поле.
При перетаскивании нескольких выбранных слоёв источником станет активный. **None (Layer)** означает, что источник не назначен.

Previous и Specific могут использовать скрытый источник. У группы скрывай саму группу, а не нужные в результате дочерние слои.
Используется только её содержимое, без фона за ней.

**All Below** ограничен текущей группой, даже в Pass Through; на верхнем уровне используется нижняя часть документа.
Пустой стек прозрачен, поле Target скрыто.
Непрозрачный фон делает общую альфу сплошной: Outline/SDF по Alpha не различают силуэты над ним.
Для таких силуэтов используй Specific или отдельную группу источников.

## Outline и SDF

**Outline** добавляет обводку. **SDF** превращает расстояние от контура в плавный переход —
для маски, свечения или профиля высоты. Источник в обоих случаях остаётся редактируемым.

### Outline: обводка и заливка

Выбери **Source Channel** (по умолчанию Alpha, также Red, Green, Blue и Luminance),
затем положение обводки: внутри, снаружи или по обе стороны края.

| Настройка | Видимый результат |
| :--- | :--- |
| Width (px) | Ширина обводки; допускает дробные значения. |
| Softness (px) | Растушёвывает обе границы без изменения Width. Ноль оставляет чёткий сглаженный край. |
| Offset (px) | Сдвигает обводку внутрь при отрицательном значении, наружу при положительном, сохраняя ширину. |
| Color | Цвет обводки. |
| Fill Center / Fill Color | Заполняет центр отдельным цветом и прозрачностью. |

Попробуй небольшой отрицательный Offset, если обводка оторвана от мягкого источника.
Чтобы подложить сплошной силуэт под рисунок, помести Outline ниже и выбери рисунок как Specific.
Выше рисунка заливка перекроет его. Она следует контуру, а не мягкой альфе источника; отверстия сохраняются.

### SDF: расстояние как градиент или данные

Выбери **Source Channel**: Alpha, RGB-канал или Luminance, в том числе для группы.
**Threshold** определяет контур; **Max Distance (px)** — дальность перехода. Ноль подбирает дальность автоматически.

| Output | Результат |
| :--- | :--- |
| Gradient (по умолчанию) | Палитра задаёт RGB, HDR-интенсивность и альфу. Альфа источника не сохраняется. |
| Linear Data | Нормализованное расстояние в RGB 0–1, без гамма-преобразования, с непрозрачной альфой. |

Начальная палитра — чёрный на 0, белый на 1, интерполяция **Perceptual**.
**Inverted** переворачивает нормализованное расстояние; затем **Profile** меняет его форму до выборки палитры.
Оба действуют в обоих Output. Линейный Profile ничего не меняет; переключение Output сохраняет палитру и инверсию.

**Position** выбирает область расстояния: Outside, Inside, Center (обе стороны) или **Signed** (по умолчанию).
У Signed низкие значения внутри, высокие снаружи; до Profile контур соответствует 0.5.
**Inside Distance** и **Outside Distance** независимо задают дальность по сторонам; ноль наследует Max Distance или авто.
**Contour Offset (px)** расширяет форму при положительном значении и сужает при отрицательном.

Для тиснения используй Linear Data или чёрно-белый градиент и настрой высоту через Profile.
Со стандартной палитрой оба Output имеют одинаковое направление яркости изнутри наружу.

### Края источника и качество расстояния

**Source Offset (px)** смещает источник SDF, сохраняя влияние контуров за пределами холста.
**Source Edges** продолжает изображение: Transparent (по умолчанию), Clamp, Repeat с расстояниями через стык или Mirror.
Уже обрезанные исходным слоем детали восстановить нельзя.

Большие смещения и Repeat требуют больше памяти. Если расширенная область превышает 64 миллиона пикселей,
уменьши смещение или разрешение: WhimTex выдаст ошибку вместо скрытой обрезки результата.

Алгоритм расстояния меняет углы и диагонали:

| Алгоритм | Результат |
| :--- | :--- |
| Euclidean | Округлые линии расстояния. |
| Manhattan / Chebyshev | Более угловатые линии. |
| Euclidean Antialiased | Учитывает плавный полупрозрачный край источника. |
| Euclidean Exact | Силуэт с жёстким порогом, полезный для пиксельных масок. |

В Euclidean Antialiased Outline следует порогу 50% Source Channel, SDF — своему Threshold.
Участки, которые не достигают порога, не образуют силуэт.

## Blur

Добавь **Blur** и выбери **Mode** в Properties: **Gaussian**, **Linear** или **Circular**.
Показываются только нужные параметры; при переключении режима их значения сохраняются.

### Gaussian

Увеличивай **Radius**, чтобы сильнее размыть изображение.
Начни с небольшого значения для смягчения краёв или возьми больший радиус для широких мягких форм.

**Strength (%)** управляет интенсивностью: 0% показывает исходник, 100% — обычное размытие,
а значения до 400% делают полупрозрачные участки плотнее без изменения радиуса и яркости цветов.
На полностью непрозрачные участки значения выше 100% не влияют.

Чтобы размыть несколько слоёв вместе:

1. Помести их в группу и добавь Blur над ней с режимом Gaussian.
2. Оставь Input → Previous.
3. Скрой саму группу, чтобы видеть только размытый результат.
4. Настрой Radius и Strength.

### Linear и Circular

**Linear** создаёт прямой след: **Distance (px)** задаёт длину, **Angle (deg)** — направление.
**Circular** создаёт след вращения: выбери **Center** и настрой дугу **Arc**.

**Direction** размещает след вокруг источника, перед ним или позади.
**Strength** ниже 100% возвращает больше чёткого исходного изображения.
Выше 100% делает полупрозрачный след плотнее, не увеличивая его длину.

## Sharpen

Добавь **Sharpen**, чтобы усилить локальный контраст краёв, не меняя альфу источника.
Выбери **Gaussian** для обычного нерезкого маскирования или **Adaptive**, чтобы локально
усиливать направленные границы сильнее, чем слабые и хаотичные детали.
**Strength (%)** задаёт силу (0–400%), а **Radius (px)** — расстояние сравнения в пикселях холста.
**Threshold** задаёт минимальную контрастность усиливаемых деталей. **Noise Reduction** дополнительно
подавляет хаотичные детали только в режиме Adaptive; он не удаляет шум из исходного изображения.
**Halo Suppression** ограничивает выбросы контраста у границ.
**Channels** может обрабатывать RGB или яркость. **Edges** определяет поведение за границей: Transparent, Clamp, Repeat или Mirror.
Операция сохраняет HDR-значения цвета.
Во время активного редактирования WhimTex использует быстрый приближённый расчёт,
а после завершения жеста пересчитывает более качественный вариант с Gaussian-взвешиванием.

## Make Seamless

Добавь **+ → Make Seamless** над текстурой или группой, выбери **Input** и скрой источник, если нужен только обработанный результат.
Включи **Tiled**, чтобы сравнивать края повторяющихся копий.

| Метод | Как соединяет края | Основное ограничение |
| --- | --- | --- |
| **Offset Blend** | Смешивает копии, сдвинутые на половину периода. | Хорошая отправная точка для шума и поверхностей; цвета и повторяющиеся детали могут измениться. |
| **Mirror** | Отражает противоположный край в полосу перехода. | Легко настроить, но узнаваемые детали могут выглядеть зеркальными. |
| **Screened Poisson** | Плавно корректирует несовпадение противоположных краёв. | Может менять центр и другие грани; не восстанавливает непрерывность деталей. |
| **Patch Quilting** | Подбирает полосы из исходника и соединяет их по линии наименьшего расхождения. | Может лучше сохранить резкие детали, но возможны повторения и заметные склейки на мягком шуме. |

Новый слой использует **Offset Blend**. У Offset Blend и Mirror начальные значения — **Blend Width 20%**, **Transition Start −25%**, включённая **Poisson Correction → All Edges**.
Включены все копирующие грани и обе оси отражения. Переключение метода сохраняет его настройки; существующие слои используют записанные значения.

### Грани и каналы

**Channels → R / G / B / A** выбирает обрабатываемые каналы; изначально включены все.
Выключи A, чтобы сохранить исходную прозрачность. При всех выключенных каналах обработка шва пропускается.
Последующие FX, Mapping и смешивание слоя всё ещё могут менять изображение.

Квадрат выбирает грани текущего прохода:

- **Copy Edges:** четыре независимые грани Offset Blend.
- **Mirror Direction:** выбранная грань принимает отражение противоположной. Повторный клик отключает ось, клик по противоположной грани меняет направление. Две включённые оси также стыкуют углы.
- **Patch Edges / Poisson Edges:** противоположные грани переключаются вместе. **Top & Bottom** — повтор по вертикали, **Left & Right** — по горизонтали, **All Edges** — оба направления. Обе пары можно выключить.

Связанные грани подсвечиваются вместе. Клик по центру инвертирует выбор.
У Mirror он выключает обе оси, если хоть одна включена; следующий клик включает Left To Right и Bottom To Top.
Отключение прохода приглушает его зависимые поля, но не квадрат и не другой проход; значения сохраняются.

**У Poisson Correction собственный выбор граней.** Она может работать даже при выключенном копировании, отражении или подборе полос.

### Offset Blend

| Настройка | Результат |
| --- | --- |
| **Blend Width (%)** | Ширина копируемых полос: 2–50%, по умолчанию 20. |
| **Transition Start (%)** | Начало затухания внутри полосы, а не всего холста: −100…95%, по умолчанию −25. До этой точки копия имеет полное влияние. |
| **Contrast Compensation / Strength (%)** | Уменьшение потери контраста при смешивании. Изначально включено; Strength 0–100%, по умолчанию 100. |

Уменьшение Transition Start расширяет переход; 0 начинает его на краю, положительные значения сужают.
Отрицательные значения растягивают переход за холст и могут вернуть шов. **Poisson Correction** помогает его сгладить; изменение Transition Start само её не переключает.

Полосы пересекаются в углах; минимальная ширина — два пикселя. Без Poisson Correction пиксели вне полос сохраняются с учётом округления цвета и альфы.
Компенсация сохраняет распределение приблизительно. Выключение или Strength 0 пропускает анализ гистограммы.

### Mirror

**Blend Width (%)** задаёт ширину перехода. Чем выше **Falloff**, тем ближе к краю назначения сосредоточено отражение.
Отражённая полоска плавно переходит в исходник; ось без выбранной грани не меняется.

**Transition Start (%)** работает внутри Blend Width: −100…95%, по умолчанию −25.
Ноль сохраняет исходный профиль перехода; положительные значения откладывают и сужают его, отрицательные расширяют за холст и могут вернуть шов.
Настройка работает с Contrast Compensation и без неё, независимо от Offset Blend.

**Contrast Compensation** изначально выключена. Компенсация по гистограмме уменьшает потерю контраста в отражённом переходе, но может менять цвета и не убирает зеркальные мотивы.
**Strength (%)** — 0–100; при 0 используется обычное отражение.

### Screened Poisson и Poisson Correction

**Radius (%)** задаёт дальность коррекции относительно меньшей стороны: 0,5–25%, по умолчанию 5.
Жёсткой границы полосы нет. Яркость центра сохраняется приблизительно; центр и невыбранные грани могут измениться, но стыкуются только выбранные пары.
Светлые значения могут выйти за допустимый диапазон и обрезаться. Настройки Mirror на этот метод не влияют.

Offset Blend, Mirror и Patch Quilting предлагают тот же расчёт как **Poisson Correction**:

- У каждого свой **Poisson Edges**. Действие не ограничено полосой копирования или подбора.
- У Offset Blend и Mirror коррекция включена по умолчанию, у Patch Quilting — выключена.
- У Offset Blend и Mirror есть **Automatic Radius**, изначально включённый: четверть Blend Width, минимум 0,5%. Поле Radius показывает расчётное значение; выключи Automatic Radius, чтобы вернуть и настроить сохранённый ручной радиус.
- Коррекция увеличивает время расчёта. Проверяй и контраст, и швы в Tiled.

### Patch Quilting

Перестраиваются только краевые полосы, а не всё изображение.

| Настройка | Результат |
| --- | --- |
| **Patch Width (%)** | Ширина каждой полосы: 2–45%, по умолчанию 20. Широкая полоса даёт больше места для разреза, но меняет большую область. |
| **Feather (%)** | Доля доступного симметричного перехода вокруг каждого разреза: 0–100%, по умолчанию 50. Это смешивание участков, не размытие текстуры и не процент от Patch Width. |
| **Search Quality** | Draft, Normal (по умолчанию), High. Повышение увеличивает число кандидатов и разрешение анализа, но не гарантирует более красивый результат. |
| **Along-Seam Search (%)** | Сдвиг донорской полосы вдоль шва: 0–25%, по умолчанию 0. При 0 кандидаты не сдвигаются. Смещение затухает у концов без циклического переноса; детали могут растянуться. |
| **Seed / Random** | Другой воспроизводимый подбор. Разные значения могут давать одинаковый результат. |
| **Channel Matching** | **Linked** (по умолчанию) использует общий участок и разрез. **Independent** подбирает их отдельно для каждого включённого канала: полезно для упакованных карт, но не для сохранения цвета и прозрачных цветных краёв. |

Feather 0 оставляет жёсткую склейку; 100 использует самый широкий симметричный переход без выхода из полосы и раскрытия стыка.
В очень узких полосах разница процентов может быть незаметна. При ширине один выходной пиксель места для перехода нет; на слишком узкой карте анализа используются центральные разрезы.
Без Poisson Correction пиксели за полосами сохраняются с учётом округления.

**Contrast Compensation** изначально выключена. При Feather выше 0 она уменьшает потерю контраста в переходах.
**Strength (%)** — 0–100. Коррекция учитывает сходство исходника и выбранного участка и может менять цвета.
При Strength 0 или Feather 0 расчёт пропускается; при Feather 0 контрол недоступен.
Если включены обе оси, второй поиск использует результат первого с коррекцией и может выбрать другой участок.

### Превью и расчёт

- Источник остаётся редактируемым: изменения обновляют результат, слой его не запекает.
- Patch Width и Feather применяются после отпускания ползунков. Расчёт Quilting может временно блокировать редактирование; высокое качество и широкий поиск требуют больше времени.
- Уменьшенное превью может выбрать другие участки и разрезы. Обычное превью ограничено 512 пикселями; **Live Quality 100%** не снимает ограничение вне рисования. Для проверки полного разрешения выбери **Pencil**, не рисуя, и включи **Tiled**.

**Старые документы:** значения Feather читаются как проценты без миграции (16 означает 16%), поэтому вид может измениться.
Открытие не перезаписывает файлы автоматически.
Последующие трансформы и FX могут нарушить стыковку — проверяй итоговую композицию.

Для скриптов и агентов: [параметры Make Seamless](../AgentAPI.md#make-seamless-settings) и [clipboard-рецепт](../Examples/Clipboard/seamless-noise.json).
Чтобы восстановить участок, а не соединить противоположные края, используй [заполнение по содержимому](selection.md#заполнить-по-содержимому).

## Настроить края

У размытия есть настройка **Edges**:

- **Transparent:** затухание в прозрачность.
- **Clamp:** продолжение крайних цветов.
- **Repeat:** перенос через противоположный край; подходит для бесшовных текстур.
- **Mirror:** отражение изображения на границе.

У Normal Map набор другой: **Clamp**, **Repeat** и **Mirror**, без **Transparent**.

Для бесшовной работы настрой Edges у самого эффекта, а не только включи [превью Tiled](symmetry.md).
