# Слои эффектов

Слои эффектов создают обводку, смягчают изображение или превращают детали текстуры в рельеф.
Источник остаётся редактируемым: меняй его, и эффект подстроится.

## Выбрать эффект

Нажми **+** внизу Layers:

| Задача | Слой | С чего начать |
| :--- | :--- | :--- |
| Обвести форму | Outline | Ширина, мягкость и положение внутри или снаружи. |
| Сделать маску по расстоянию от края | SDF | Канал источника, Threshold и Max Distance. |
| Получить рельеф поверхности | Normal Map | Height Map или Texture. Подробнее — [Normal Map](normal-map.md). |
| Смягчить изображение | Blur | Mode → Gaussian, затем Radius. |
| Создать след движения | Blur | Mode → Linear или Circular. |
| Вернуть локальную резкость | Sharpen | Strength и Radius. |
| Состыковать противоположные края | Make Seamless | Method, Channels, грани и смешивание выбранного метода, дополнительная Poisson Correction. |

## Выбрать источник

**Input → Previous** использует слой непосредственно под эффектом в той же группе.
Выбери **Specific**, чтобы указать другой слой или группу. Нажми **Target** и выбери источник
из списка либо перетащи слой прямо в поле.
**None (Layer)** означает, что источник ещё не выбран.
При перетаскивании нескольких выбранных слоёв источником становится активный.

**All Below** использует объединённые видимые слои ниже эффекта с их прозрачностью, смешиванием и эффектами. Режим ограничен текущей группой, даже для Pass Through; на верхнем уровне используется нижняя часть документа. Пустой стек прозрачен. Поле Target в этом режиме скрыто. Непрозрачный фон делает общую альфу сплошной: Outline/SDF по Alpha перестают различать отдельные силуэты над ним. Для них выбирай Specific или отдельную группу источников.

В Previous и Specific источник можно скрыть — эффект продолжит его использовать. Для группы скрывай саму группу,
а не те слои внутри неё, которые нужны в результате.
Эффект обрабатывает только содержимое группы, без фона за ней.

## Outline и SDF

**Outline** добавляет границу вокруг формы. Подбери ширину и мягкость,
выбери **Source Channel** (по умолчанию Alpha, также доступны Red, Green, Blue и Luminance),
затем выбери положение: внутри, снаружи или по обе стороны края.

**SDF** пригодится для плавного перехода, зависящего от расстояния до формы.
**Threshold** задаёт порог, по которому определяется контур, а **Max Distance (px, 0 = авто)** —
дальность перехода. При 0 дальность подбирается автоматически.
**Position** выбирает, какую сторону контура покрывает градиент: Outside — только снаружи,
Inside — только внутри, Center — по обе стороны сразу.
По умолчанию стоит **Signed** — градиент покрывает обе стороны контура.
В обоих режимах **Inverted** переворачивает нормализованное расстояние перед Profile.
**Output → Gradient** выбран по умолчанию; градиент — от чёрного на 0 к белому на 1, с интерполяцией **Perceptual**. **Inverted** остаётся доступен и разворачивает нормализованное расстояние перед Profile и выборкой палитры. **Output → Linear Data** выдаёт нормализованное расстояние как линейные значения RGB 0–1 с непрозрачной альфой, без цветового гамма-преобразования. Inverted и Profile работают в обоих режимах. Переключение Output сохраняет палитру и инверсию. В Signed низкие значения находятся внутри, высокие снаружи; оба режима имеют одинаковое направление яркости со стандартной палитрой.

**Source Offset (px)** смещает источник по X/Y, сохраняя влияние контура, ушедшего за край. **Source Edges** задаёт продолжение изображения: Transparent — пустота (по умолчанию), Clamp — крайний пиксель, Repeat — повтор с учётом расстояний через стык, Mirror — отражение. Уже обрезанные исходным слоем детали восстановить нельзя.

**Contour Offset (px)** двигает сам контур: положительное значение расширяет форму, отрицательное сужает. В **Signed** поля **Inside Distance** и **Outside Distance** независимо задают дальность внутрь и наружу; 0 использует Max Distance или авто. До Profile граница соответствует 0.5. **Profile** меняет форму перехода в обоих режимах: после Inverted и перед выборкой палитры; линейная кривая ничего не меняет. Для тиснения используй Linear Data или чёрно-белый градиент и настрой профиль высоты здесь.

Большие смещения и Repeat требуют больше памяти. Если расширенная область расчёта превышает 64 миллиона пикселей, уменьши смещение или разрешение: вместо неверного обрезанного результата будет сообщение об ошибке.
Алгоритм расстояния влияет на углы и диагонали:
Euclidean даёт округлые переходы, Manhattan и Chebyshev — более угловатые.

Для источника с плавным полупрозрачным краем выбери **Distance Algorithm → Euclidean Antialiased**
в SDF или Outline. Outline следует порогу 50% выбранного **Source Channel**, даже при широком мягком переходе;
SDF использует настройку **Threshold**. Участки, которые не достигают порога, не образуют силуэт.
Оставь **Euclidean Exact**, если нужен силуэт с жёстким порогом или пиксельная маска.

Outline поддерживает дробную ширину: **Width (px)** принимает нецелые значения.
**Softness (px) = 0** оставляет чёткий сглаженный край;
увеличение **Softness (px)** растушёвывает обе границы, не меняя настройку **Width (px)**.
**Offset (px)** сдвигает обводку без изменения её ширины: отрицательное значение — внутрь, положительное — наружу.
Попробуй небольшой отрицательный сдвиг, если обводка выглядит оторванной от мягкого источника.

Включи **Fill Center**, чтобы получить заполненную форму вместо пустого контура. **Color** задаёт цвет обводки,
а **Fill Color** — отдельный цвет и прозрачность центра. Чтобы подложить сплошной силуэт под мягкий рисунок,
помести Outline ниже рисунка и выбери этот слой как конкретный Input. Выше рисунка заливка будет его перекрывать.
Заливка следует контуру, а не исходной мягкой прозрачности. Отверстия в исходной форме сохраняются.
В SDF **Source Channel** позволяет выбрать Alpha, отдельный RGB-канал или Luminance, в том числе для группы-источника.

## Blur

Добавь **Blur** и выбери **Mode** в Properties: **Gaussian**, **Linear** или **Circular**.
Показываются только нужные параметры; при переключении режима их значения сохраняются.

### Gaussian

Увеличивай **Radius**, чтобы сильнее размыть изображение.
Начни с небольшого значения для смягчения краёв или возьми больший радиус для широких мягких форм.

**Strength (%)** управляет интенсивностью: 0% показывает исходник, 100% — обычное размытие,
а значения до 400% делают полупрозрачные участки плотнее без изменения радиуса и яркости цветов.
На полностью непрозрачные участки значения выше 100% не влияют.

## Sharpen

Добавь **Sharpen**, чтобы усилить локальный контраст краёв, не меняя альфу источника.
Выбери **Gaussian** для обычного нерезкого маскирования или **Adaptive**, чтобы локально
усиливать направленные границы сильнее, чем слабые и хаотичные детали.
**Strength (%)** задаёт силу (0–400%), а **Radius (px)** — расстояние сравнения в пикселях холста.
**Threshold** задаёт минимальную контрастность усиливаемых деталей. **Noise Reduction** дополнительно
подавляет хаотичные детали только в режиме Adaptive; он не удаляет шум из исходного изображения.
**Halo Suppression** ограничивает выбросы контраста у границ.
**Channels** может обрабатывать RGB или яркость. **Edges** определяет поведение за границей: Transparent, Clamp, Repeat или Mirror.
Операция сохраняет HDR-значения цвета.
Во время активного редактирования WhimTex использует быстрый приближённый расчёт,
а после завершения жеста пересчитывает более качественный вариант с Gaussian-взвешиванием.

Чтобы размыть несколько слоёв вместе:

1. Помести их в группу и добавь Blur над ней с режимом Gaussian.
2. Оставь Input → Previous.
3. Скрой саму группу, чтобы видеть только размытый результат.
4. Настрой Radius и Strength.

### Linear и Circular

**Linear** создаёт прямой след: **Distance (px)** задаёт длину, **Angle (deg)** — направление.
**Circular** создаёт след вращения: выбери **Center** и настрой дугу **Arc**.

**Direction** размещает след вокруг источника, перед ним или позади.
**Strength** ниже 100% возвращает больше чёткого исходного изображения.
Выше 100% делает полупрозрачный след плотнее, не увеличивая его длину.

## Make Seamless

Добавь **+ → Make Seamless** над текстурой или группой. Выбери источник через **Input**
и скрой сам источник, если хочешь видеть только обработанный результат.

В **Method** доступны **Offset Blend** (по умолчанию у новых слоёв), **Mirror**, **Screened Poisson** и **Patch Quilting**.
Существующие слои сохраняют записанный режим.
У новых слоёв для Offset Blend и Mirror заданы **Blend Width 20%**, **Transition Start −25%**
и включённая **Poisson Correction → All Edges**. Все копирующие грани Offset и обе оси отражения Mirror включены.
Существующие слои сохраняют настройки; переключение метода их не сбрасывает.

**Copy Edges**, **Mirror Direction** и **Patch Edges** выбирают грани основного прохода; **Poisson Edges** — независимой коррекции. Когда грани прохода сняты, его зависимые поля недоступны, но квадраты и другой проход остаются активными. Значения сохраняются. При **Feather 0%** компенсация контраста Quilting недоступна; увеличь Feather, чтобы снова её использовать.

Связанные противоположные грани подсвечиваются вместе при наведении. Клик по картинке в центре
инвертирует выбор. У **Mirror Direction** центр выключает обе оси, если хотя бы одна включена;
следующий клик включает обе с направлениями Left To Right и Bottom To Top.

**Contrast Compensation** добавляет вычисления. Первый расчёт после долгого простоя или смены размера может быть медленнее последующих.

**Channels — R / G / B / A** выбирает каналы, в которых обрабатывается шов, во всех режимах,
включая дополнительные компенсацию и коррекцию Mirror. По умолчанию включены все четыре.
Выключенные каналы сохраняют входные значения. Выключи **A**, чтобы сохранить исходную прозрачность;
все четыре галочки выключены — обработка шва пропускается. Последующие FX, Swizzle и смешивание слоя могут менять итоговый вид.

**Screened Poisson** глобально сглаживает выбранные пары противоположных граней. **Poisson Edges**:
**All Edges** (по умолчанию), **Top & Bottom** (повторение по вертикали), **Left & Right** (по горизонтали).
Нажимай на грани квадрата: противоположные грани включаются и выключаются вместе. Можно снять обе пары — соответствующий проход не выполняется, а контрол остаётся активным.
Это также работает для граней Patch Quilting и всех Poisson Correction. Выбор для каждого прохода независимый.
**Radius (%)** (0,5–25, по умолчанию 5) задаёт дальность относительно меньшей стороны.
Жёсткой границы краевой полосы нет. Яркость центра сохраняется приблизительно; невыбранные
грани тоже могут измениться, но не состыковываются. Поля Mirror не применяются.
Слой обновляется при изменении источника. Светлые значения могут выйти за диапазон и обрезаться;
непрерывность деталей не гарантируется. Проверяй **Tiled**. Миграции и автоматической перезаписи файлов нет.

**Offset Blend** смешивает копии, сдвинутые на половину периода, без отражения.
**Blend Width (%)** (2–50, по умолчанию 20) задаёт ширину полос.
**Transition Start (%)** (−100…95, у новых слоёв −25) задаёт начало смешивания внутри полосы,
а не относительно всего холста. До этой точки участок полностью скопирован. Уменьшение значения
расширяет плавный переход; 0 начинает его от края. Увеличение сужает переход.
Отрицательные значения начинают переход за пределами холста и могут вернуть шов. При необходимости
включи **Poisson Correction** и выбери нужные пары граней. У новых слоёв она уже включена, но изменение Transition Start не переключает её.
Дополнительные коррекции:

- **Contrast Compensation** (по умолчанию включена) уменьшает потерю контраста;
  **Strength (%)** (0–100, по умолчанию 100) задаёт силу. Выключение или нулевая сила пропускает анализ гистограммы.
- **Poisson Correction** (по умолчанию включена) добавляет глобальный Screened Poisson со своим
  **Poisson Edges**, независимым от граней копирования. Может менять пиксели вне полос смешивания.
  **Automatic Radius** по умолчанию включён: четверть Blend Width,
  минимум 0,5%. Выключи его для ручной настройки **Radius (%)** (0,5–25).
  Радиус считается относительно меньшей стороны. Этот проход дороже и может вывести цвет за допустимый диапазон.

Повторяющиеся детали и цвета могут изменяться, особенно на нешумовых изображениях.
Распределение сохраняется приблизительно — проверяй **Tiled**.
Слой обновляется при изменении источника; результат не запекается.

В Offset Blend четыре грани вокруг иконки независимо выбирают полосы копирования; по умолчанию включены все.
При выключенной Poisson Correction пиксели вне полос сохраняются (с учётом погрешности float/альфы).
Полосы пересекаются в углах, минимальная ширина — два пикселя. Выключение всех граней отключает
копирование, но включённая Poisson Correction продолжает работать.

**Patch Quilting** подбирает сдвинутые полосы из исходника и соединяет их по линии наименьшего
расхождения. Обрабатываются краевые полосы, а не вся текстура заново. Детали могут сохраняться
резче, но возможны повторения рисунка и видимые линии склейки на мягком шуме. Проверяй **Tiled**.

- **Patch Edges:** All Edges, Top & Bottom или Left & Right; противоположные рёбра квадрата переключаются вместе.
- **Patch Width (%)** (2–45, по умолчанию 20): ширина каждой обрабатываемой полосы. Больше ширина — больше места для поиска разреза, но больше изменённая область.
- **Feather (%)** (0–100, по умолчанию 50): доля доступной ширины перехода, отдельно для каждого разреза. 0 оставляет жёсткую склейку; 100 использует максимально широкий симметричный переход без выхода из полосы и раскрытия стыка. Это смешивание участков, а не размытие текстуры и не процент от Patch Width.
- **Contrast Compensation** (по умолчанию выключена) уменьшает потерю контраста внутри переходов Feather. **Strength (%)** задаёт силу от 0 до 100. Учитывается сходство исходника и выбранного участка; цвета могут измениться. Включение увеличивает время расчёта, но при силе 0% или Feather 0% компенсация не выполняется. При обработке обеих пар граней второй проход получает результат первого с компенсацией и может выбрать другой участок.
- **Search Quality:** Draft, Normal (по умолчанию), High. Повышение качества увеличивает число кандидатов и разрешение анализа; расчёт медленнее, но визуальное улучшение не гарантируется.
- **Along-Seam Search (%):** 0–25%, по умолчанию 0 — прежний поиск. Добавляет смещение донорской полосы вдоль шва относительно её доступной длины. Смещение плавно исчезает у концов без циклического переноса; детали могут растягиваться. При ненулевом значении прежнее число кандидатов делится между прямыми и смещёнными полосами, расчёт становится тяжелее; улучшение не гарантируется.
- **Seed / Random:** другой воспроизводимый подбор участка. Некоторые значения могут давать одинаковый результат.
- **Channel Matching:** Linked (по умолчанию) использует общий участок и разрез для выбранных каналов цвета. Independent подбирает их отдельно для каждой галочки — полезно для упакованных масок/шума, но не для сохранения цвета и прозрачных цветных краёв.
- **Poisson Correction** (по умолчанию выключена): дополнительная глобальная коррекция со своими **Poisson Edges** и **Radius (%)** (0.5–25, по умолчанию 5). Может менять центр, контраст и HDR-диапазон.

Без коррекции область за пределами полос сохраняется с точностью до округления вычислений.
Patch Width и Feather применяются после отпускания ползунка. Если полоса слишком узкая на карте анализа,
используются центральные разрезы с работающим Feather. В полосе шириной один выходной пиксель места для
сглаживания нет; при малом числе пикселей разные проценты могут выглядеть одинаково.
Старые числа Feather читаются как проценты без миграции: сохранённое 16 становится 16%, поэтому прежний вид может измениться.
Уменьшенное превью может выбрать другие участки и разрезы. Обычное превью ограничено 512 пикселями; **Live Quality 100%** не переключает просмотр вне рисования в полное разрешение. Выбери **Pencil**, не рисуя, и включи **Tiled**, чтобы проверить полноразмерный результат перед сохранением или экспортом.
Поиск ускорен без уменьшения выбранного Search Quality. Настройка Poisson Correction не запускает
повторный подбор участков; изменение исходника или параметров Quilting требует нового поиска.
В High одинаковые участки-кандидаты не рассчитываются повторно, без изменения результата при том же
seed. Выигрыш может быть заметнее на широких полосах; пересчёт пока остаётся блокирующим.

В режиме **Mirror** нажми на грань квадратного контрола — она выбирает край назначения для отражённой противоположной грани.
Повторное нажатие на подсвеченную грань отключает ось, на противоположную — меняет направление.
Ось без подсвеченных граней остаётся без изменений. Полоска отражается зеркально
и плавно переходит в исходное изображение; при включённых обеих осях стыкуются и углы.

**Blend Width (%)** задаёт ширину перехода. Чем выше **Falloff**, тем ближе к краю назначения
сосредоточено отражение. Включи **Tiled**, чтобы видеть стыки.
**Transition Start (%)** (−100…95, у новых слоёв −25) задаёт начало затухания отражения внутри Blend Width.
Ноль сохраняет прежний переход; положительные значения откладывают его начало и сужают переход.
Отрицательные растягивают его за пределы холста и могут вернуть шов — при необходимости включи
**Poisson Correction**. Работает с Contrast Compensation и без неё, независимо от настройки Offset Blend.

Для настройки через скрипты или ИИ смотри [справочник параметров Make Seamless](../AgentAPI.md#make-seamless-settings)
и [готовый clipboard-рецепт](../Examples/Clipboard/seamless-noise.json).

В Mirror есть две независимые опции: у новых слоёв Contrast Compensation выключена, Poisson Correction включена:

- **Contrast Compensation** включает смешивание отражённых пикселей с компенсацией по гистограмме.
  **Strength (%)** задаёт силу (0–100); 0 оставляет обычный Mirror. Уменьшает потерю контраста
  в переходе, но может менять цвета и не устраняет зеркальные мотивы.
- **Poisson Correction** добавляет глобальный Screened Poisson с независимым выбором **Poisson Edges**.
  **Automatic Radius** по умолчанию включён: четверть **Blend Width**, минимум 0,5%. Поле Radius
  показывает расчётное значение без редактирования. Выключи Automatic Radius, чтобы вернуть сохранённый ручной радиус и настроить его.
  **Radius (%)** (0,5–25, по умолчанию 5) задаёт дальность относительно меньшей стороны
  без ограничения полосой **Blend Width**. Коррекция может менять центр и другие грани и работает,
  даже если оба направления отражения Off. Светлые значения могут обрезаться; обработка заметно тяжелее.

Приём хорошо подходит для шумов и поверхностей, но узнаваемые детали у стыка могут выглядеть зеркальными.
Последующие трансформы и эффекты могут нарушить стыковку, поэтому проверяй и итоговый результат.
Нужно не состыковать края, а восстановить участок по окружающим деталям — используй
[заполнение по содержимому](selection.md#заполнить-по-содержимому).

## Настроить края

У размытия есть настройка **Edges**:

- **Transparent:** затухание в прозрачность.
- **Clamp:** продолжение крайних цветов.
- **Repeat:** перенос через противоположный край; подходит для бесшовных текстур.
- **Mirror:** отражение изображения на границе.

У Normal Map набор другой: **Clamp**, **Repeat** и **Mirror**, без **Transparent**.

Для бесшовной работы настрой Edges у самого эффекта, а не только включи [превью Tiled](symmetry.md).
