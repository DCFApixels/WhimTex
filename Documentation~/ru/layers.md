# Слои и группы

Собирай изображение из отдельных слоёв, чтобы независимо двигать и настраивать каждую часть.
Верхние строки списка — передний план изображения.

## Добавить слой

Нажми **+** внизу Layers и выбери тип:

| Слой | Для чего |
| :--- | :--- |
| File | Готовая текстура из Project. |
| Drawing Layer | Рисование, стирание и заливка. |
| Color Fill | Сплошной цвет, UV-координаты или геометрический SDF-узор. |
| Gradient | Плавный переход цветов. |
| Noise | Генерируемый узор. Подробнее — [Noise](noise.md). |
| Shape | Редактируемый прямоугольник, эллипс, многоугольник, звезда или линия. |

Текстуру из Project можно перетащить в панель холста, чтобы добавить её сверху,
или между строками списка, чтобы выбрать место. При первом назначении изображение сохраняет исходные пропорции.
При назначении HDR-текстуры File-слою **Color Range** и **Blend Range** переключаются в **HDR**.
После этого оба режима можно изменить вручную в **Rendering**.

File-слои со ссылкой на другой документ WhimTex отмечены тонкой оранжевой линией слева.
Дважды нажми на миниатюру или фон строки, чтобы открыть этот документ или перейти в его окно, не заменяя текущий.

У слоёв эффектов тоже есть миниатюры результата. Для анимированных Shader FX используется статичный снимок.

## Выбрать и расположить

Кликни по строке для выбора. Зажми `Ctrl`, чтобы выбрать несколько слоёв, или `Shift` — диапазон.
**Последний выбранный слой становится активным**: на нём ты рисуешь, а его параметры видишь в Layer Settings.

Перетаскивай строку, чтобы переместить выбранные слои; удерживай у верхнего или нижнего края списка для прокрутки.
Заверши редактирование текста, прежде чем тянуть за поле. Перетаскивание за поле отменяет неподтверждённый ввод.
Изменение имени и прозрачности подтверждается через `Enter` или выход из поля.
Имя редактируется прямо в строке. **Opacity** отвечает за прозрачность,
**Blend** — за смешивание с изображением ниже. Изменение любого из этих полей применяется ко всем выбранным слоям.

Глазик скрывает слой. Глазик в заголовке столбца показывает все слои.

Выдели несколько слоёв в **Layers** и включи **Transform (T)**. Начальная общая рамка не повёрнута и охватывает только рамки выделенных слоёв. Для группы учитывается её собственная рамка, без обхода детей. Перемещение, вращение, масштаб, скос и перспектива применяются относительно общей рамки. Если выделены и группа, и её ребёнок, трансформация не применяется дважды. **Esc** отменяет текущий жест; Undo откатывает операцию целиком. Индивидуальные настройки в шапке инструмента при мультивыделении недоступны.

## Настроить слой

Настройки выбранного слоя собраны в четырёх сворачиваемых разделах:

- **Transform:** положение, размер, вращение и тайлинг.
- **Rendering:** прозрачность (Opacity), режим наложения (Blend Mode), диапазоны цвета и Mapping. Прозрачность и режим наложения также доступны в списке Layers. Переключатель Standard/HDR остаётся доступен в шапке раздела.
- **Properties (тип слоя):** настройки конкретного типа слоя — например, исходная текстура, источник эффекта или симметрия рисования.
- **FX:** добавление и настройка шейдерных эффектов.

Те же настройки можно открыть отдельно через **меню слоя ⋮ → Properties**.
Разделы, недоступные для выбранного слоя, отображаются серым.

## Собрать связанные части в группу

Выдели слои и нажми **Folder** или перетащи их в существующую группу.
Стрелочка группы раскрывает и сворачивает её содержимое.

По умолчанию выбран **Pass Through**: слои могут смешиваться с изображением вне группы.
Другой режим наложения смешивает группу как единое изображение. Прозрачность группы ослабляет её целиком.
Добавь **FX** группе, чтобы обработать её как единое изображение. FX автоматически изолируют группу Pass Through с наложением Normal и не затрагивают изображение вне неё. После удаления всех FX сквозной режим возвращается, если обтравка или Mapping не требуют изоляции. **Properties → Compositing** показывает фактический режим только для чтения. У группы также есть **Transform**: перемещение, вращение, масштаб, скос и перспектива применяются ко всем детям. Трансформы детей задаются относительно группы. Рамка показывает собственный трансформ группы, а не границы детей. Перенос между группами и разгруппировка сохраняют положение на холсте.

## Дублировать, объединить или удалить

Кликни по строке правой кнопкой или открой **⋮** для действий с выделением.
**Duplicate** создаёт копию, которую можно редактировать отдельно.
У File-слоёв источником остаётся та же текстура.

| Иконка внизу списка | Клик | Перетаскивание слоёв на иконку |
| :--- | :--- | :--- |
| **+** (меню типов) | Выбрать тип слоя. | Дублировать. |
| **Page +** (лист с плюсом) | Добавить рисовальный слой. | Создать объединённую рисовальную копию. |
| **Folder** | Сгруппировать выделение. | Сгруппировать. |
| **Trash** | Удалить выделение. | Удалить. |

Если нужно рисовать поверх объединённого результата, смотри [слияние и конвертацию](transform.md).

## Поделиться слоями

Перетащи один или несколько выделенных слоёв в другое открытое окно WhimTex, чтобы скопировать их. Вне списка Layers копии вставятся наверх; внутри списка — по индикатору вставки, а при наведении на группу — внутрь неё. Исходные слои и буфер обмена не меняются. Группы и пиксели Drawing копируются независимо, весь перенос отменяется одним Undo. В исходном окне перетаскивание по-прежнему перемещает слои.

Выдели слои и выбери **Copy as JSON**. Отправь текст или файл `.json`; получатель копирует
содержимое и нажимает **Ctrl+V**. Обычный Ctrl+C не меняется.

Копирование использует FullOptimized: активные настройки и их значения по умолчанию сохраняются,
неактивные настройки пропускаются. Выключенные слои и FX остаются. Для Full или Compact выбери JSON в **Export**.

Добавь в выделение источники Target, текстур FX и обтравочных масок. Пиксели Drawing не встраиваются:
копирование предупреждает о пустых слоях, даже если картинка изначально загружалась по URL.
Для сохранения нарисованного содержимого используй TIFF или перенос между окнами.
File ссылается на ассеты проекта; отсутствующий ассет даёт предупреждение и пустой вход до восстановления.

Код FX сохраняется. Include разворачиваются по возможности; недоступные зависимости могут помешать
компиляции у получателя. После вставки проверь предупреждения и превью.
Технические подробности — в [едином формате JSON](../JSON_FORMAT.md).

## Геометрическая заливка

В **Color Fill** выбери **Mode → Pattern**. **Shape**: Triangles, Squares, Hexagons
или Circles. У кругов есть сетки **Square** и **Dense**: во второй строки сдвинуты
на половину шага и расположены плотнее. Расстояние до контура рассчитывается
напрямую из геометрии, в том числе в промежутках; отдельный слой SDF не нужен.

- **Size (px)** — масштаб сетки по X/Y до трансформов. Цепочка связывает пропорциональное изменение размеров; без связи оси меняются независимо. Включение связи сохраняет текущие пропорции. **Offset (px)** и **Rotation** — смещение и поворот.
- **Gap** уменьшает фигуры (0–0.99), **Roundness** скругляет углы внутрь. При нуле углы острые; скругление открывает промежутки у общих вершин даже с нулевым Gap.
- **Bulge** делает внутренний профиль выпуклым, не сдвигая контур. При нуле это геометрическое расстояние, при ненулевом значении — его художественное преобразование.
- **Distance**: Signed, Inside, Outside или Center (модуль расстояния). **Distance Range** измеряется в радиусах вписанной окружности фигуры. В Signed контур соответствует середине градиента.
- **Inverted**, **Profile** и **Gradient** задают итоговые цвета и альфу.
- **Cell Color** добавляет окраску фигур: **Uniform** оставляет градиент расстояний, **Random** выбирает цвета из **Palette** по **Seed**, **Pattern** чередует два цвета для квадратов/треугольников или три для шестиугольников. У кругов схема зависит от сетки.
- **Variation** задаёт диапазон палитры в Random: ноль — её середина, один — весь градиент. Для фиксированного набора цветов выберите режим Fixed у палитры. **Color Blend → Multiply** сохраняет светотень SDF; **Replace RGB** даёт плоскую окраску. Оба режима сохраняют альфу градиента расстояний, игнорируя альфу палитры. В зазорах используется цвет ближайшей фигуры.
- Цвета следуют за фигурами при смещении и повороте. Seamless повторяет Random по границам холста, а для Pattern подгоняет число ячеек под цикл цветов: чётное для шахматки, кратное трём по горизонтали для сот и плотной сетки кругов.

**Seamless** вписывает в холст целые периоды сетки, включая пары смещённых рядов.
Суммарный поворот слоя и группы округляется до 90°, масштаб подгоняется по двум
осям. Скос и перспектива заменяются осевой сеткой, рассчитанной в центре холста.
Исходные настройки сохраняются; после рендера инспектор показывает фактическую
сетку. Отключение Seamless возвращает свободные трансформы.
Многоугольники могут слегка растянуться; круги остаются кругами, поэтому по одной
оси возможны дополнительные зазоры. Seamless имеет приоритет над Tiling слоя.
Бесшовность гарантируется для самого узора, но не для произвольных FX после него
или других слоёв композиции.

## Нарисовать фигуру

Выбери **Shape** (`U`), укажи фигуру в верхней строке панели холста и протяни мышью для создания.
Новый слой получает имя фигуры: например, **Rectangle 1**, **Line 2** или **Star 3**. Нумерация общая для всех фигур.
Каждое протягивание добавляет отдельный Shape-слой, в том числе в пустом документе.
Зажми `Shift` для равных пропорций или угла линии с шагом 45°; `Ctrl` отключает привязку к направляющим.
Нажми `Escape` до отпускания мыши, чтобы отменить создание.

Существующую фигуру можно двигать, масштабировать и вращать через **Transform**.
В **Properties (Shape)** меняются тип, цвета заливки и обводки, скругление прямоугольника,
число сторон многоугольника или лучей звезды и её внутренний радиус.
У прямоугольника в **Roundness (%)** четыре поля вокруг квадрата — по одному на каждый угол.
Цепочка связывает изменения пропорционально, перечёркнутая цепочка позволяет менять углы независимо.
Включение связи сохраняет значения. Связанное изменение останавливается, если угол достигает 100%;
при изменении нулевого угла ко всем четырём прибавляется одинаковая величина.
Схема показывает фигуру до поворота через Transform.
Обводка располагается внутри края, её ширина задаётся в пикселях холста.
**Feather (px)** растушёвывает контур без размытия всего изображения. **Feather Position**
задаёт направление: Inside — внутрь, Outside — наружу, Centered — по обе стороны.
Для полой обводки растушёвываются обе границы. Значение — полная ширина перехода в пикселях холста;
0 сохраняет исходный край. Большая растушёвка Inside/Centered может погасить тонкие детали,
а Outside — заполнить узкие зазоры.
Длина и толщина линии регулируются через Transform.
Создать фигуру по центру также можно через **+ → Shape**.

Фигура остаётся редактируемой и поддерживает обтравочные маски, смешивание и FX.
Например, положи сверху Gradient и включи у него обтравочную маску, чтобы залить фигуру градиентом.
Преобразовывай её в Drawing только когда нужно рисовать прямо на ней.

## Создание текстур для VFX

Процедурные слои подходят для энергетических колец, вспышек и масок частиц.
В этом примере яркий ободок сочетается с тонкими радиальными полосами.

Задай основную форму слоем **Gradient**, добавь детали через [Noise](noise.md), а искажение и

чтобы менять детали независимо от силуэта. Цвета и затухание настрой в
[редакторе градиента](color.md#настроить-градиент), затем проверь текстуру на фоне, с которым будет работать эффект частиц.

## Восстановить пропавший слой

Если тип слоя недоступен, его имя, положение, видимость и общие настройки сохраняются.
У группы сохраняются и дочерние слои. Выдели строку: в Layer Settings появится предупреждение.

Чтобы вернуть исходный слой, восстанови его пакет или скрипт и заново открой оригинальный документ до замены типа.

Выбери новый тип в **Replace with** и нажми **Replace Behaviour**. Опция **Transfer saved settings**
переносит совместимые настройки прежнего типа слоя. Панель перечислит то, что перенести
не удалось; проверь результат перед сохранением. Группу с дочерними слоями можно восстановить только как группу.

Недоступный слой по-прежнему можно перемещать, скрывать и удалять. До восстановления он не отображается на холсте.

{: .warning }
**Replace Behaviour** подставляет другой тип; настройки, которые не удалось перенести, могут потеряться при сохранении.
См. [защиту документа](saving.md#сохранить-возможность-редактирования). О старых неподдерживаемых форматах читай в [TIFF-документах](tiff-format.md).
