# Слои через браузерный ИИ

Попросите браузерный ИИ создать редактируемую текстуру, скопируйте JSON и вставьте его в WhimTex.
Подключение к Unity не нужно. Функция доступна в WhimTex 0.9.6 и новее.

1. Дайте ИИ [инструкцию по формату](../AI/README.md) и опишите текстуру. Попросите **WhimTex clipboard JSON**, с нужными частями на отдельных именованных слоях.
2. Скопируйте полученный блок JSON.
3. Перейдите в превью или панель Layers, выйдите из ввода текста и нажмите **Ctrl+V** (Cmd+V на macOS).
4. Редактируйте новые слои как обычно. **Ctrl+Z** отменяет всю вставку.

Например: «Создай голубое магическое кольцо на прозрачном фоне, с редактируемым ободком и отдельным
свечением. Холст 512 × 512. Верни WhimTex clipboard JSON».

Результат может содержать фигуры, градиенты, шум, группы, обводки, размытие, карты нормалей,
собственные Shader FX и рисовальный слой, который скачивает картинку по прямой HTTP(S)-ссылке.
Локальные файлы, Base64 и нарисованные пиксели этот формат не переносит: для них остаются обычная
вставка изображения, перетаскивание и [подключённый агент](automation.md).

Слои добавляются над существующей композицией. Выделение на холсте их не обрезает.
Если JSON задаёт размер, пустой документ принимает его сразу. В непустом документе выберите
**Apply Size** или **Keep Current**: во втором случае слои всё равно вставятся, но размер не изменится.
Для собственного HLSL появится подтверждение перед компиляцией: вставляйте только код, которому
доверяете, поскольку тяжёлый шейдер может остановить отрисовку.
Для картинок по ссылкам подтверждение тоже есть, и в нём перечислены хосты, с которых пойдёт загрузка.
Сначала скачиваются все картинки, и только потом дерево вставляется одним Undo: если загрузка не удалась,
не добавится ничего. Каждая картинка сохраняет своё разрешение, а в холст вписывается трансформом слоя.

Если JSON или шейдер некорректен, ничего не вставится. Передайте ошибку ИИ и попросите исправленный
JSON. Повторная вставка создаёт новые слои, а не обновляет предыдущий результат.

Для отдельного шейдера попросите HLSL и вставьте его в **FX → + Shader FX**, затем нажмите **Apply**.
Та же [инструкция для ИИ](../AI/README.md) объясняет синтаксис и настраиваемые параметры.
