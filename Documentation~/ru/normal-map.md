# Normal Map

Карта нормалей создаёт видимость выпуклостей и впадин при освещении поверхности в материале.
Начни с **Simple**: там собраны основные настройки. Для тонкой правки открой **Advanced**.
Возврат в Simple сохраняет дополнительные настройки.

## Из карты высот

1. Добавь Normal Map над File, Drawing или Noise.
2. Оставь **Input → Previous** или назначь другой Target.
3. Выбери **Generation → Height Map** и канал, в котором хранится высота.
4. Начни со **Strength** 4 и **Smoothing** 1 px, затем подбери рельеф.
5. Скрой источник, если хочешь видеть только карту нормалей.

Светлое — высоко, тёмное — низко. **Invert Height** меняет их местами.
**Strength** усиливает рельеф, **Smoothing** смягчает мелкие неровности.
Для Noise с кодировкой Linear Data выбери **Input Space → Linear** в Advanced.

## Из цветной текстуры

**Generation → Texture** оценивает рельеф по обычному изображению.
Это отправная точка, а не точное восстановление поверхности: тени и нарисованные перепады цвета могут стать впадинами.

В Advanced выбери **Output → Height**, чтобы проверить полученную высоту.
Настрой **Fine / Medium / Large Detail** для мелкой фактуры, средних деталей и крупных форм.
Попробуй **Light Removal**, если освещение исходника создаёт лишние склоны.
Когда результат устроит, верни **Output → Normal**.

## Полезные завершающие настройки

- **Height Levels:** подбери Black/White Level и Gamma, если рельеф слишком плоский или резкий.
- **Edges → Repeat:** используй для бесшовного источника.
- **Alpha → Opaque:** получить сплошную карту; **Source** сохраняет прозрачность источника.
- **Flip Y:** попробуй, если материал показывает выпуклости как впадины.

## Сохранить для материала

Для отдельной карты нормалей оставь наложение **Normal**, полную непрозрачность и исходный Swizzle.
Избегай цветовых эффектов: они могут исказить рельеф.

Для PNG/TGA/PSD выбери **Packed Color**. Импортируй полученный PNG или TGA в Unity как
**Normal Map**, без преобразования из grayscale.
**Linear Data** нужен, если твой рабочий процесс предполагает линейный EXR или Texture2D.

Поворот готового слоя Normal Map вращает картинку, но не направление её освещения.
Чтобы рельеф был ориентирован правильно, трансформируй источник до генерации карты.
