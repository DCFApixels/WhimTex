# Горячие клавиши

## Выпадающие поля с двумя вариантами

В настройках с двумя вариантами короткий клик левой кнопкой переключает значение. Удержание 300 мс или движение вниз на 4 UI-пикселя открывает меню для выбора отпусканием кнопки. Это работает и в параметрах Shader FX, включая заголовки групп. Списки с другим числом вариантов, смешанные значения и произвольные значения вне списка раскрываются как обычно. Управление с клавиатуры не меняется.

## Документ, слои и прозрачность

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl+S` | Save / Save As. |
| `Ctrl+Z` · `Ctrl+Y` / `Ctrl+Shift+Z` | Undo · Redo. |
| `↑` / `↓` после действий в Layers | Предыдущий / следующий видимый слой. |
| Стрелки после клика по холсту | Сдвинуть выделенные слои по осям холста на один его пиксель. Удержание постепенно ускоряет повтор; один Undo отменяет всё удержание. Выбранная направляющая имеет приоритет. |
| `Ctrl`-клик / `Shift`-клик вне миниатюр | Переключить слой / выбрать диапазон. |
| `Ctrl+Shift`-клик | Добавить диапазон. |
| `Ctrl+E` / `Ctrl+Alt+E` | Слить выделение / создать объединённую копию. |
| `0`–`9` или numpad | Прозрачность выбранных слоёв. |

`5` — 50%, сразу после него `7` — 57%. После паузы `7` означает 70%.
`0` — 100%, быстрое `00` — 0%, `05` — 5%.

## Рисование, выделение и навигация

| Сочетание | Действие |
| :--- | :--- |
| `[` / `]` · `X` | Размер кисти/карандаша · смена цветов. |
| Зажатый `Alt` + клик/перетаскивание с Brush, Pencil или Fill | Взять видимый цвет в любой части экрана; отпускание `Alt` возвращает инструмент. |
| `ПКМ` с Brush/Pencil | Временно стирать. |
| `U` · `Shift` при протягивании фигуры | Shape · равные пропорции / угол линии с шагом 45°. |
| `Shift` при перетаскивании / `Shift`-клик при рисовании | Линия по оси / соединение точек. |
| `Ctrl`-клик по миниатюре/стрелке группы | Выделить альфу. |
| `Ctrl+C` / `Ctrl+Shift+C` / `Ctrl+V` | Копировать выбранные слои (или пиксели области) / видимые пиксели композиции / вставить, в том числе в другом окне. |
| `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` | Выделить всё / снять / инвертировать область. |
| `Shift` / `Alt` / `Shift+Alt` при выделении | Добавить / вычесть / пересечь. |
| `Enter` / `Backspace` / `Escape` с лассо | Замкнуть / убрать вершину / отменить. |
| Перетаскивание с `СКМ` / колёсико | Сдвинуть вид / изменить масштаб при любом инструменте. |
| Перетаскивание с `Shift+СКМ` | Вращать вид при любом инструменте; `Ctrl` отключает привязку угла. |
| `Alt`-клик с лупой | Отдалить. |
| `Ctrl` при привязке | Отключить примагничивание. |
| `Enter` в Transform · `Escape` во время действия | Выйти из инструмента · отменить действие. |

На macOS для сохранения, выделения и Undo/Redo также работает `Cmd`.
Используй эти сочетания, когда активно окно WhimTex.
