# Симметрия и бесшовное рисование

Симметрия помогает рисовать парные детали, орнаменты и повторяющиеся формы.
Tiled нужен для текстуры, которая стыкуется по краям.

## Повторять мазки

Выбери рисовальный слой и открой **Symmetry & Repeat** в Layer Settings.
У каждого рисовального слоя может быть своя настройка.

| Режим | Для чего |
| :--- | :--- |
| Mirror | Отражение по X, Y или обеим осям. Center перемещает оси, Angle поворачивает их. |
| Horizontal / Vertical | Ряд или столбец копий. |
| Grid | Копии в строках и столбцах. |
| Radial | Копии вокруг Center. Выбери число секторов и поверни Start Angle для их расположения. |
| None | Обычное рисование без копий. |

В режимах повторения **Copy** делает одинаковые копии,
**Alternate Mirror** отражает каждую вторую.

## Не выходить за сегмент

**Edges → Clip** удерживает каждый мазок внутри сегмента, в котором ты начал рисовать.
Выбери **Continue**, если линия должна переходить в соседние сегменты.

У Mirror при 0° X отражает относительно вертикальной линии, Y — горизонтальной.
Поверни Angle, если нужна диагональная ось.

## Рисовать бесшовные края

1. Включи **Tiled** над превью.
2. Выбери кисть или карандаш и рисуй на любой видимой копии.
3. Проведи через границу: отсечённая часть продолжится с противоположного края.
4. Отдали вид, чтобы проверить повторяющийся узор.

Tiled не увеличивает сохранённое изображение.
У эффектов вроде размытия также выбери **Edges → Repeat**, чтобы избежать швов на границах.

## Какое повторение мне нужно?

- **Symmetry & Repeat** копирует новые мазки.
- **Transform → Tiling** повторяет готовое изображение слоя.
- **Tiled в превью** показывает копии всего холста и позволяет рисовать через его края.
