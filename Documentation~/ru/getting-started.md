# Начало работы

## Установка

Нужна **Unity 6 или новее**. Открой **Window → Package Management → Package Manager**,
выбери **Install package from git URL** и вставь:

```text
https://github.com/DCFApixels/WhimTex.git
```

## Первое изображение

1. Открой **Window → WhimTex** и задай размер холста в полях **W / H**. **New** создаёт ещё один пустой документ в отдельной вкладке, оставляя текущий открытым.
2. Нажми **+** внизу списка Layers и выбери **Drawing Layer** — появится рисовальный слой. Если готовая текстура уже есть, её можно вместо этого перетащить из Project прямо в панель холста.
3. Выбери **Transform** (`T`), чтобы расположить изображение, или **Brush** (`B`), чтобы рисовать.
4. Нажми `Ctrl+S` и выбери, куда сохранить документ.
5. Документ сохраняется в TIFF и может использоваться в Unity как обычная текстура — в материале или как спрайт.

Чтобы продолжить редактирование, дважды кликни по сохранённому TIFF. Предварительный экспорт не нужен.
Он откроется в отдельном окне WhimTex, не заменяя текущий документ.
Если документ уже открыт, Unity переключится на его окно, не создавая дубликат.

На вкладке WhimTex показано имя документа. Новый документ называется **Untitled** («Без имени»); после сохранения вкладка получает имя файла. Звёздочка отмечает несохранённые изменения.

Если перетащить текстуру в пустой документ, холст получит её размер в Unity.
То же произойдёт, если добавить **File** единственным слоем и впервые назначить **Source Texture**.
Последующие замены текстуры размер холста не меняют. Если перетащить сразу несколько текстур,
размер задаст первая.

## Что где находится

Слева — холст, справа — список **Layers**. Над списком находится **Layer Settings**
с настройками выбранного слоя. Перетаскивай разделители, чтобы освободить место для нужной части окна.

Инструменты находятся слева, а их настройки — над холстом.
Для перемещения вида зажми колёсико мыши и тяни. Прокрутка меняет масштаб; **Fit** показывает холст целиком.

| Инструмент | Клавиша | Для чего |
| :--- | :---: | :--- |
| Layer Select | `V` | Выбирать слой кликом по видимым пикселям. |
| Transform | `T` | Перемещать, масштабировать и вращать слой. |
| Area Select | `M` | Выделять прямоугольник или овал. Зажми кнопку инструмента для выбора формы. |
| Polygonal Lasso | `L` | Выделять область кликами по её контуру. |
| Brush / Pencil | `B` / `P` | Рисовать мягкие мазки или чёткие пиксели. |
| Fill | `G` | Заливать область цветом. |
| Zoom | `Z` | Приближать изображение или выбранную область. |

## Настроить окно под себя

**Шестерёнка справа от Export** открывает User Settings. Здесь можно поменять цвета и размер
шахматки прозрачности или включить **Clean Canvas View Background**, чтобы скрыть логотип и тень на фоне панели холста.
Кнопка **Reset WhimTex Settings…** внизу окна после подтверждения возвращает настройки
рабочего пространства к исходным, не удаляя документы и файлы пресетов.

Чтобы держать настройки слоя в отдельном окне, выбери **меню слоя ⋮ → Properties**.

## Открыть готовое изображение

В **User Settings → Open Images** выбери, что открывается двойным кликом в Project:

- **Tiff Documents Only:** документы TIFF WhimTex.
- **All Supported Images** (по умолчанию): также PNG, JPEG, BMP, TGA, EXR, обычные TIFF и Texture2D `.asset`, но не PSD.

Документ TIFF WhimTex открывается со своими слоями. Для обычных изображений **Open As** выбирает тип источника:

| Режим | Когда использовать |
| --- | --- |
| **Drawing** | Нужна редактируемая копия, на которой можно рисовать. |
| **File** | Нужен слой со ссылкой на исходную текстуру. |

**Сохранение поверх исходника.** Обычное изображение открывается как новый документ. Пока в нём один слой, **Save** обновляет исходный PNG, JPEG, TGA, EXR или Texture2D `.asset`.
**Save As** создаёт многослойный TIFF, не меняя исходник и его настройки импорта. Для остальных форматов нужен Save As.

**Разрешение источника.** PNG, JPEG, BMP, TGA и EXR используют размеры и пиксели исходного файла, даже если Unity импортирует уменьшенную или сжатую текстуру.
Это относится к рендеру File, открытию как Drawing и конвертации File в Drawing. Другие форматы используют импортированную текстуру.
Декодирование EXR поддерживается в Editor на Windows, macOS и Linux.
