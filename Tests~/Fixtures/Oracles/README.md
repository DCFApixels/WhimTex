# Эталонные входы и снимки

Это данные действующих тестов, не результаты новых запусков. В `manifest.json`
записаны относительные пути и SHA-256; `provenance.json` сохраняет происхождение,
исходные пути и ограничения достоверности. Проверка всех файлов без Unity:
`--id reference-fixtures` через [общий запускатель](../../RUNNING_TESTS.md).

| Данные | Назначение |
| --- | --- |
| `seamless/` — 252 `.bin` | Дорефакторинговые результаты для сравнения алгоритмов бесшовности |
| `live_4.bin` | Исходная текстура 512 × 512 для quilting, не эталон результата |
| `images/` — два PNG | Исходные изображения 600 × 600 для preview, не эталоны результата |

Снимки `seamless` — RGBA float32 little-endian без заголовка; размер задан именем.
`live_4.bin` начинается с двух int32 (ширина, высота), затем содержит RGBA float32.
Все 255 файлов скопированы из ранее зарегистрированных входов без изменения байтов.
Тесты читают только эти пакетные копии, а не старые абсолютные пути из provenance.

Оригиналы датированы 2026-09-28. Исторические материалы подтверждают назначение и
сравнения, но прежних криптографических хешей на дату создания нет: текущие хеши
фиксируют сохранённые байты, не доказывают их непрерывность с той даты. Старый PASS
не подтверждает нынешний код; исходное изображение не доказывает визуальное равенство.

Не перегенерировать снимки текущим алгоритмом ради зелёного теста и не заменять
отсутствующие файлы похожими. Намеренное изменение требует нового образца и отдельного
решения о том, какое поведение должно измениться. Диагностические PNG/CSV и новые
отчёты сохраняются в проектный `Temp/WhimTex`, не здесь.
