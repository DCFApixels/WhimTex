# Исходники FX-пресетов 0.12.5

Пять HLSL-файлов скопированы без изменений из тега `v0.12.5`,
коммит `a72cc9544d39f93555ca6e9f39c137340e3028f0`. Git blob ID каждого
исходника зафиксирован в manifest.json. Это отдельное дополнение: исходная
TIFF/JSON база Compatibility0125 не изменена и не пересоздана.

Это эталоны исходного кода пресетов, не захват старого GPU-рендера или отдельного
ShaderFX `.asset`. Все пять уже объявляют `_Opacity`; прежние имена представлены
только директивами metadata.

Это исторические исходники, а не входы текущего сценария `shader-fx0125-preset-v2`.
Синтаксис `@param bool`, параметры Mask и другие контракты с тех пор изменились;
поддержка их чтения современным парсером не требуется.

`ShaderFX0125PresetTests.Run` сохраняет прежнее имя для runner, но использует текущие
пресеты из `src/FXPresets`. Он проверяет значения/ID, group header, подключение каталога,
сохранение пикселей при TIFF save/reopen и native-сериализацию текущей модели FX.
Сравнение рендера до и после этих операций не является проверкой совместимости
с версией 0.12.5 или восстановлением старого GPU-эталона.

Не перегенерировать эталоны для исправления тестов.
