# Файловые образцы WhimTex

Обязательные входные данные активных тестов, не отчёты запусков и не резервные копии Legacy.
Тесты читают пакетные файлы; пользовательские копии в Assets не являются их зависимостями.
Запуск — через [общий runner](../RUNNING_TESTS.md), актуальные вызовы принадлежат каталогу.

## Изменения образцов

Другие входные данные также находятся здесь: `Noise/` — замороженные CSV для
периодического шума; `ShaderFXVSCodeMetadata*.cases.json` — входы валидаторов метаданных;
`UssCascadeBaseline.json` — эталон каскада стилей. Это данные проверок, не общие помощники.

Не перегенерировать старый эталон и не менять ожидаемый хеш ради зелёного теста.
Намеренное изменение требует причины, отдельного нового образца и решения о совместимости
формата/рендера. Данные Drawing и итоговую композицию проверять раздельно, включая Save/reopen.
Замороженные базы сохранять согласно их manifest и README; новые образцы добавлять рядом.
