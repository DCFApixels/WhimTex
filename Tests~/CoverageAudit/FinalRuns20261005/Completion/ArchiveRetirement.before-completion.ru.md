# Legacy отвязан от активных тестов

5 октября 2026 года. Работа выполнена локально в `dev`; commit/push и физическое удаление не выполнялись.

> Уточнение по свежему финальному прогону: в одном историческом помощнике аудита обнаружено чтение физической Legacy при импорте. Прежний вывод о полной отвязке ниже был слишком широким. До исправления этого помощника окончательное удаление архива не рекомендовано. Код продукта и Legacy в этом прогоне не изменялись.

## Как понимать 3/402 и 10/56

Все **402 новых регрессионных сценария** уже существуют и зарегистрированы в общей архитектуре. Внутри сценария может быть несколько случаев и много assertions; 402 — число запускаемых сценариев, а не число файлов или отдельных assertions.

Прежнее **3/402** означало: после последнего изменения общего runner заново были выполнены только три сценария. Это не число написанных новых тестов и не число оставшихся зелёных тестов. Аналогично **10/56** означало десять повторно выполненных source guards — проверок структуры и контрактов исходников. Они считаются отдельно от 402 регрессий.

Свежий финальный прогон выполняется по отдельным наборам, без повторного запуска Legacy и без выдачи исторических PASS за новые результаты.

### Player: таймаут → блокирующий диалог → безопасная отмена и recovery

Native установка тестового probe прошла один реальный compile/reload без ошибок. Дальше Unity открыла **Scene(s) Have Been Modified** для пользовательской **SampleScene**. Проверка ждала завершения build десять минут и завершилась с `recoveryRequired:true`. Последний read-only `editor_status` — `blocked_by_dialog`; `build_status` — `building`. Это **не подтверждённый дефект сборки WhimTex и не успешная Player-проверка**. Player не был проверен.

Save и Don't Save не выбирались, сцена не сохранялась и не закрывалась. Штатная Pipeline-команда ответа на этот диалог не обнаружена. Нужен **Cancel в самом Unity**, затем подтверждение native `completed` и отдельное завершение owned cleanup/reload. Нельзя вручную подменять build_status, удалять lock или запускать новую компиляцию, пока build остаётся queued/building. Для нового полноценного Player-прогона нужно согласовать, как сохранить пользовательские изменения сцены.

До recovery сохранены только собственная папка `Assets/WhimTexTestMigration/4817f7407dac483b94141d9e81bb6b17`, её probe-сцена/скрипт/документ, GUID evidence в `Temp/WhimTex/player-release/4817f7407dac483b94141d9e81bb6b17` и `Temp/WhimTex/test-runs/runner.lock`. Существующие пользовательские файлы не удалялись.

Четыре не запущенные регрессии:

- `fault-release-workflow-v2` — ждёт завершения Player recovery.
- `gradient-clipboard-cleanup-smoke-v2`, `gradient-presets-smoke-v2` — ждут отдельного разрешения на собственные GUID-папки в системном Temp.
- `file-navigation-smoke-v2` — ждёт разрешения на read-only dock-host reflection двух уже открытых пользовательских окон; тесту разрешено закрывать только собственные вкладки.

Инфраструктурные `reload-transport-b`, `reload-transport-d`, `unity-b-async-skip-protocol-v2` отложены: единый runner не запускается поверх удержанной Player-блокировки.

### Аудит: eager import читает Legacy → перенаправить IO и добавить отрицательную проверку

`Framework/NodeSupportA/AuditSources.mjs` импортирует `Cases/NodeA/AuditSources.mjs`. Его eager `auditSources()` обходит все `Tests~` и пытается прочитать физический `Legacy/AgentApiSmoke.cs` до входа в тело `final-legacy-audit-v2`. Read-only проба перехватила попытку и остановила её **до чтения архивных байтов**. Это граница, не охваченная прежним ограниченным mirror-прогоном.

Нужна узкая правка IO помощника, адаптация его изолированной CLI-проверки и перепроверка source-review/guard. Исходные assertions, frozen manifest и Legacy менять не нужно. Исправление в этом финальном прогоне не выполнялось: запрошено разрешение. До исправления и завершения оставшихся запусков **окончательное удаление Legacy не рекомендовано**.

Проверенные **31 файл ProjectSettings/manifest/lock** совпадают с baseline, снятым до больших native-наборов. 360 source-review записей имеют актуальные хеши; это не подмена отсутствующего runtime PASS. Commit/push и удаление Legacy не выполнялись.

## Исходный результат ограниченного этапа

Новые тесты и аудит больше не требуют папку `Tests~/Legacy`. Архивные сценарии нельзя запустить через активный каталог — ни напрямую, ни через support/review dependencies. В каталоге **520 независимых сценариев**: 402 регрессии, 56 source guards, 12 инфраструктурных и 50 диагностических. 24 старых запуска и восемь их профилей сняты с регистрации; исходные метаданные сохранены в `retired-catalog.json`.

## Проблема → решение

| Проблема | Решение и проверка |
| --- | --- |
| Runner проверял физический архив перед каждым случаем | Обычный запуск проверяет только неизменяемые descriptor/manifest. Полная проверка байтов вынесена в `archive-integrity` |
| Аудиторам были нужны старые исходники | Read-only Git-reader читает commit `ca8603c0961ce36064280f952259f8a6142d46cc`, сверяет точный инвентарь, размер и SHA-256 всех 466 файлов; физического fallback нет |
| Framework брал protocol fixtures из Legacy-каталога | Собственные синтетические данные сохраняют отрицательные regex/verdict, timeout, async, cancel и cleanup проверки. Активный каталог допускает только structured results |
| После изменения runner старые PASS можно было принять за свежие | Native и Node evidence требуют актуальный общий fingerprint. Старые результаты, каталоги и хеши сохранены как история без переподписывания |
| Инструкции предлагали запускать архивные файлы | Актуальные инструкции используют независимые ID; исторические ссылки закреплены на recovery commit |

Git-reader запрещает неожиданные типы/пути, некорректную длину, усечённые и лишние байты. Возвращает копии буферов, не позволяя изменять кеш. Недоступный repository/commit, изменённый manifest или descriptor — ошибка, не SKIP/PASS.

## Фактическая проверка

- GUID-копия в project `Temp/WhimTex` создана **без физической папки Legacy**. В ней прошли `quick`, gate и все шесть audit/migration-инструментов; подтверждены 466 архивных файлов и 360 актуальных source-review записей.
- `archive-detachment`: **3 случая / 986 assertions — PASS**, включая отсутствие repository/commit, подмену descriptor/manifest и строгий бинарный Git-протокол. Копии и raw отчёты сохранены; настоящий архив не переименовывался.
- Framework: **53 случая / 223 assertions — PASS**. Аудитор и source guards: **81/81 PASS**.
- Через `unity-cli` в подключённом Test6.6: `core` **3/3 PASS** — display channels, canonical reader и frozen 0.12.5 files. Никакой отдельной сборки Player.
- Независимый CI-профиль документации: **11/11 PASS**; source-check документации: **84 страницы PASS**. Это не новая сборка/публикация GitHub Pages.
- Неизменны `src/`, все 466 физических Legacy-файлов и manifest. Editor ready/stopped, без компиляции/reload; runner lock отсутствует.

Расширенная проверка сначала выявила ошибку нового помощника: JSON-lines вывод аудитора принимался за один JSON. Исправлены только явные флаги `--schema` / `--json`; неуспешный raw отчёт сохранён, assertions не ослаблялись.

## Что означают прежние 402 PASS

[Неизменённый снимок до retirement](CoverageAudit/pre-retirement.results.json) содержит итог прежнего этапа: **402 PASS и 0 SKIP**. После изменения dispatcher он является историческим evidence. Текущий gate подтверждает заново только **3 регрессии и 10 source guards**; остальные 399 регрессий на новом общем fingerprint не перепрогонялись. Это отсутствие свежего полного прогона, а не 399 красных тестов.

PSD был закрыт настоящим writer/decoder PASS до retirement. Его условия не менялись, [receipt](CoverageAudit/psd-reader-final-runtime-review.json) сохранён; свежий PSD запуск в этом этапе не заявляется. Пилотный сравниватель аутентифицирует только три исторические пары по фиксированным SHA и явно возвращает `currentRuntimeEquivalence:false`.

## Решение об удалении

**Прежний вывод требует уточнения.** Основной runner и архивный Git-reader отвязаны, но импорт `Cases/NodeA/AuditSources.mjs` через `Framework/NodeSupportA/AuditSources.mjs` всё ещё запускает обход физических файлов Legacy. Эта граница не входила в прежний ограниченный mirror-прогон. До её исправления окончательное удаление архива не рекомендовано. В этом изменении Legacy не удалялся, commit/push не выполнялись.

После удаления должны остаться descriptor, замороженный manifest, активные `Fixtures/Compatibility0125` и `Fixtures/ShaderFX0125`, Cases/Framework, migration mappings, исторические каталоги и receipts. Git recovery commit должен быть доступен; zip без его объектов не подходит для архивного аудита. Машинное `archiveRemovalAllowed:false` намеренно не заменяет решение и разрешение человека.
