## Что актуализировано

Изменены 73 существующих тестовых скрипта: 63 C# и 10 Node. Дополнительно обновлены USS-эталон и примечание в [GradientGpu.md](GradientGpu.md).

Основные группы изменений:

- Отражение текущих API: сигнатуры `CreateAgentDraft`, `LayerRenderContext`, Deserialize, brush/API-операций; явные преобразования `Double2`; актуальные методы Canvas-рендера и поля модели.
- Замена тестового `UnityEngine.Gradient` на `WhimTexGradient` там, где изменился тип. Явный выбор режима для сценариев, которые проверяют Classic или Linear, а не новые Perceptual defaults.
- Разделение полного JSON и оптимизированного clipboard. Полный JSON проверяет сохранение **неактивных** параметров; clipboard — активных. GPU-проверки продолжают использовать исходные текстурные fixtures. В отдельных проверках параметров после GPU-части источник заменяется процедурным с сохранением ID, чтобы не сериализовать несохранённую Texture2D как asset reference.
- Для All Below добавлен отказ от неполного переносимого фрагмента; полноценный fragment round-trip и нативное stack-relative копирование продолжают проверяться.
- Обновлены ожидания общих скрытых `_Opacity` вместо удалённых отдельных Amount-контролов, подписи и группировки встроенных FX.
- Устранено неоднозначное подключение Json.NET в ShaderFXVectors; выбран публичный assembly, без нового обращения к внутренним API Unity.
- UI-тесты учитывают скрытых предков и завершение attach/layout. Проверки HDR-ключей после reload сравнивают сохранённые данные, а не требуют точного совпадения Perceptual-вычисления с исходным RGB.
- LayerPersistenceVerify ищет своё окно по ID принадлежащего fixture слоя, а не по заголовку, который Unity пересоздаёт после reload.
- Для LayerTransfer каждый вариант запускается на свежем setup. Добавлен отказ от повторного setup поверх существующего fixture. Все шесть вариантов top/before/after/group/end/footer повторно прошли в изоляции.
- ModelSerializationBenchmark использует текущий `Hash128` fingerprint вместо удалённого `Writer.Hash64`; добавлено освобождение документа, контейнера и native-массивов.
- NoiseSmallScaleExperiment больше не пытается загрузить отсутствующий periodic lattice для обычного непериодического пути. Оба типа шума повторно прошли, по 144 конфигурации, расхождение с эталоном равно нулю.
- Изолировано имя временных TIFF fixtures; отмена операции признаётся допустимым исходом fault-injection проверки.

USS baseline взят из зафиксированного состояния `e8070f0`, с нормализацией согласованного переименования терминов. Проверки значений, специфичности и конфликтующего порядка каскада сохранены; отрицательные проверки изменения цвета и высоты продолжают работать. Эталон не снимался автоматически с произвольного текущего UI.

Полный список изменённых скриптов — в JSON, поле `updatedScripts`.

## Регрессионные проверки, которые прошли

- Все 252 сохранённых GPU fixtures бесшовных эффектов: максимальное расхождение **0**. Capture не запускался; существующие эталоны не перезаписывались.
- GradientGpuRunSmoke: 2 858 482 проверки; все режимы, формы, HDR и альфа. Этот успех **не отменяет** отдельный сбой Fixed/Mirror выше.
- WhimTexGradientContractSmoke: 526 285 проверок. Поля продукта, независимые копии, Undo/Redo после закрытия окна, история и освобождение LUT также прошли.
- LayerPreviewReuseSmoke: 2 752 550 проверок; LayerPreviewPanelSmoke: 3 145 986. Проверены кэш, каналы, управление указателем, состояние рендера и освобождение ресурсов.
- SeamlessChannelsSmoke: 2 362 650 проверок; Mirror Transition: 3 564 410; Mirror Integration: 621 162.
- PatchQuilting: три integration-варианта по 294 954; stage cache 147 487; workspace 36 933; candidates 370 944. Отдельно проверены бюджеты и освобождение ресурсов.
- SeamlessRelease workflow: 393 608 проверок сохранения/закрытия/открытия, Undo/Redo, копирования и экспортной композиции. Preview 768×512 и два окна 1024×768 также прошли; кэши двух окон освобождаются независимо.
- Настоящий Unity domain reload: восстановление документа, направляющих, HDR/альфы/midpoint градиента. Native missing-type сценарий: реальное исчезновение временного типа, два missing managed references, восстановление, Undo/Redo, save/reopen, несохранённые Drawing pixels — 17 проверок.
- DocumentReleaseValidation: 33 fault-injection проверки, затем deferred import failure и успешный retry. Player build не выполнялся.
- Burst SHA-256: 808 проверок на vectors, границах блоков и параллельных вызовах, тестовый крупный буфер 8 MiB; все вызовы использовали Burst.
- TIFF-эталоны Gradient/Drawing сохраняют исходные хеши и результаты рендера; PSD проверяет и raster fallback вложенного градиента, и отдельный поддерживаемый native путь.
- Реальная HLSL TextMate grammar, а не только поиск строк: тест прошёл на установленной grammar runtime.

## Что не проверялось

- Player build и Player runtime, включая PreparePlayer/InspectBuild: правила проекта требуют отдельного запроса на билд.
- Необязательные screenshot helpers `ContentFillUiCapture.cs` и `UvUiCapture.cs`, ручная визуальная оценка и варианты Capture/Visuals/Preview, назначение которых — генерация диагностических изображений, а не автоматическая проверка утверждений.
- Все возможные аргументы каждого benchmark и все максимальные размеры. Performance correctness проверена на ограниченных конфигурациях: LDR/HDR документы 512×512, TIFF cost 2048, контейнер 64 MiB, stress четыре режима 1024×768. Время и память — локальные наблюдения, не гарантии производительности.

Опциональные помощники не удалены: отсутствие запуска не делает их устаревшими. Успешная компиляция также не приравнивается к проверке Player или всех параметрических комбинаций.

## Состояние проекта после первичного аудита

Постоянные изменения этой работы ограничены `Tests~`. Временный `CompositionMissingTestBehaviour.cs`, его meta и созданные этим сценарием assets удалены; fault-injection folder также удалён. Посторонние диагностические папки не очищались. Результаты некоторых замеров и экспортов остаются в `Temp/WhimTex`.

Unity Editor готов, не компилируется и не находится в Play Mode. Последние штатные перекомпиляции завершились без ошибок; финальная dry-run компиляция всех 184 тестовых классов успешна. `git diff --check -- Tests~` проходит.

Код реализации не исправлялся, версия не менялась, commit и player build не выполнялись. Отчёт разделяет подтверждённые результаты, сохранённые ошибки и непроверенные варианты.
