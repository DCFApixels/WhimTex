# Legacy удалён после финальной проверки

5 октября 2026 года. Работа выполнена локально в `dev`; commit/push не выполнялись.

## Результат

Все обязательные независимые тесты прошли на актуальных fingerprints. Удалена только физическая папка `Tests~/Legacy` — **466 замороженных файлов**. Новые Cases/Framework, активные Fixtures, манифест, descriptor, migration mappings и исторические результаты сохранены.

| Набор | Результат |
| --- | --- |
| Регрессионные сценарии | **402/402 PASS**, 0 SKIP |
| Проверки структуры и контрактов исходников | **56/56 PASS**, 0 SKIP |
| Инфраструктурные сценарии | **12/12 PASS**, 0 SKIP |
| Unit-проверки аудитора и image/source guards | **81/81 PASS** |
| Актуальные source-review записи | **360/360**, нет пропущенных или устаревших записей |

50 самостоятельных диагностик не входят в этот обязательный прогон; им не приписаны PASS или SKIP. Source-review, runtime PASS и историческая визуальная эквивалентность — разные утверждения. Два парных gradient lifecycle helper проверены фазами единого реального reload, а не объявлены самостоятельными PASS.

Прежние **3/402** и **10/56** означали число повторно выполненных сценариев после изменения runner, а не число написанных новых тестов. Ограничение свежего прогона теперь закрыто; повторения одних ID в разных профилях посчитаны один раз.

## Проблема → решение

| Проблема | Решение и проверка |
| --- | --- |
| Импорт помощника аудита обходил физическую Legacy до входа в тест | IO реального пакета направлен в аутентифицированный pinned Git-reader. Отрицательный тест запрещает чтение и перечисление физической папки до первого импорта; прежние assertions сохранены. Final Legacy Audit: 16 случаев / 343 assertions |
| Две gradient-проверки создавали временные данные вне разрешённой папки проекта | Общий тестовый helper использует GUID-папки только в `Temp/WhimTex`; проверяет принадлежность и отсутствие перенаправлений. Исходные assertions не изменены; UnityB заново прошёл 75/75 |
| Player-сборку блокировала несохранённая пользовательская сцена | По явному разрешению сохранена и временно закрыта SampleScene. Сборка выполнена с собственной тестовой сценой; затем SampleScene открыта и стала активной, временная сцена удалена |
| Сбой связи во время native reload оставил блокировку запуска | Проверены реальные маркеры того же GUID, выполнен его публичный Cleanup, подтверждено отсутствие собственных объектов/ассетов. Новый полноценный reload прошёл по ветке `surviving-window` |
| Старые PASS могли бы скрыть более свежий сбой | Итог выбирает последний результат каждого ID на текущих fingerprints. Сбои, отменённые сборки и recovery-only evidence сохранены без переименования в PASS |

Player действительно собран и запущен: проверены сохранённые зелёные пиксели вместо несохранённых красных, три TIFF-текстуры, Standalone overrides, размеры/mips/DXT5, packed data, отсутствие WhimTex assemblies и сохранность document/meta. В native Player выполнено 340 assertions. Установка и удаление probe завершили реальные compile/reload без ошибок. PSD заново прошёл независимый writer/decoder roundtrip. Fault workflow, document/guides/gradient reload и остальные регрессии завершены.

## Проверка после удаления

Заново прошли все **83 сценария `new-node`**, включая quick/frozen files, archive integrity и отрицательный first-import guard. Отдельный `archive-retirement` запускает quick, аудит и шесть audit/migration-инструментов в новой GUID-копии без Legacy. Исходный архив не запускается: его 466 pinned Git blobs используются только для проверки и восстановления.

## Сохранность и согласованное отличие настроек

Код продукта `src/` не менялся в этом финальном этапе; production fingerprint сохранён. Frozen manifest не пересоздавался. Перед удалением точный набор, размеры и SHA-256 всех 466 файлов повторно сверены и с манифестом, и с резервной копией; копия проверена также после удаления.

Из 31 файла исходного baseline **30 совпали**. `ProjectSettings/ProjectSettings.asset` отличается; исходных байтов для точного сравнения нет, причина и точный content diff не установлены. Это не скрыто и не объявлено неизменностью настроек. Пользователь явно разрешил: «Да, оставь настройки и удаляй Legacy». Принят только раскрытый текущий SHA-256; другие отличия или новые изменения настроек этим не разрешены. [Запись разрешения и точные хеши](CoverageAudit/project-settings-deviation-20261005.json). Настройки не откатывались наугад; baseline остался исходным.

SampleScene сохранена, возвращена и активна. Тестовые GUID-ассеты удалены; Temp-артефакты и результаты сохранены. Блокировка runner отсутствует.
