# Pressure Opacity и Stamp Blend: последовательный Raster

Статус: эксперимент полностью отменён 2026-11-17. Производственный код вернулся к
обработке каждого штампа с прежней геометрией, без объединения парами и порога в
64 тайла. Выигрыш оказался небольшим и неустойчивым на 4096; сложность не оправдана.
Предыдущие улучшения Undo, полезные проверки и исходные результаты сохранены.

Ниже — историческое сравнение отменённого варианта, а не характеристики текущего
кода. Среда замеров: Unity 6000.7.0a6, RTX 5060, Direct3D12, Linear.

## Отменённое изменение

Один raw/clipped quad submesh используется для всех тайлов штампа. При площади первого штампа не менее 64 тайлов загрузка геометрии объединяется максимум для двух штампов. Append/Execute и копирование backdrop по-прежнему идут отдельно для каждого штампа; snapshot основы удерживается на пару. Меньшие следы остаются одиночными. Новых текстур, увеличенных пулов или очередей истории нет.

## До → после на 8192 × 8192

Миллисекунды. Основная таблица использует первый полный парный прогон; повторные проверки приведены отдельно, без подмены худших чисел. Каждый случай: 32 PaintSegment (два перекрывающихся мазка по 16 сегментов), Spacing 0.005, меняющееся давление, непустая HDR-основа и R8-маска. Начальные PaintPoint исключены из percentiles и сохранены в JSON.

CPU — время вызова нанесения, включая подготовку и отправку команд. До готовности — CPU плюс синхронное получение одного пикселя pending-результата; этот показатель также включает CopyRegion/проверки источника и readback. Это не чистое время GPU, не задержка мыши и не FPS.

## Память

У всех 12 пар максимумы выборок GPU-пула, readback staging и scratch-текстур совпали. GPU-пул: 328 MiB для 2048 и 744–752 MiB для 4096; staging: 139/395 MiB соответственно; native history buffers: 32 MiB. Существующая исходная RGBAHalf-текстура 8192² занимает 512 MiB CPU, R8-маска — 64 MiB. Эти отдельные максимумы нельзя складывать как одновременный пик процесса.

| Кисть | Mesh до, KiB | Mesh после, KiB |
|---|---:|---:|
| 2048 | 14.91–31.52 | 3.31–3.48 |
| 4096 | 45.28–46.06 | 3.31–5.16 |

Mesh измерен публичным Profiler.GetRuntimeMemorySizeLong; его максимум зависит и от предыдущих случаев. Часть малых служебных списков выросла с 4 до 8 элементов, а общий список submesh сократился. Общие managed/driver-счётчики относятся ко всему Editor и не используются как доказательство памяти одного мазка.

Ограничение геометрии: максимум 8 дополнительных вершин × 116 байт + 64 байта общих индексов = 992 байта. Прежние индексы первого штампа на 64 тайлах требовали минимум 1024 байта; исходные вершины первого штампа одинаковы. Порог по реальным source bounds сохраняет этот запас и при Transform. Это оценка запрошенных данных, не внутренних округлений аллокатора Unity.

CommandBuffer содержит прежние команды одного штампа; накопления команд пары нет. Замер после Paint возвращает 0, поскольку буфер уже очищен. Мгновенный внутренний пик команд и общий пик процесса не измерены. Не следует трактовать 0 как отсутствие затрат памяти.

## Точность

13/13 baseline и 13/13 verify: SHA256 каждого raw RGBAHalf-тайла в начальном состоянии и после обоих мазков, два native Undo и два Redo, pending sample после каждого ввода, восстановленный GPU-тайл и неизменный размер исходного UV. Для 2048 — 240 тайлов на состояние; для 4096 — 552. Дополнительно 257×513 с кистью 81, обоими неполными краями и каналами R/B. Outside сдвигает source UV на +0.75 и компенсирует Transform: видимое положение и диаметр совпадают с inside.

Native suite прошёл 142 проверки против сохранённого bounded renderer, включая большие динамические HLSL-наконечники с sequence/motion, projective Transform, маску, неполные края и побитовые pending/commit/Undo/Redo. Buffered suite прошёл 460432 проверки всех режимов смешивания, HDR, масок 0..1, защиты каналов и состояния рендера. Ещё 64 проверки: composite, группы, Target/Layer input, clipping, thumbnails, export, CPU/live-image consumers и фильтрация sparse view. Допуски существующих тестов не расширялись.

Frozen fixture сохраняет поведение исходного варианта, но сам по себе не является независимым доказательством математики смешивания: это покрывает дополнительный buffered/native набор. Setup, хеширование, commit, drain и Undo исключены из времён нанесения. HashMs пересекается с UndoRedoMs; их нельзя складывать.

## Воспроизведение и исходные данные

Диагностики зарегистрированы как sequential-raster-capture и sequential-raster-verify. Capture никогда не перезаписывает существующий baseline; новый замер требует отдельного runId в каталоге. Verify требует тех же конфигурации, GPU/backend/Unity и неизменных исходников fixture. История теста размещается в собственном Temp-журнале на томе проекта; существующая пользовательская история или активный мазок блокируют запуск. Для 8К требуется 4 GiB свободного места.

Тест: [SequentialRasterTests.cs](SequentialRasterTests.cs). Итоговые JSON и SHA источников: проект Temp/WhimTex/sequential-raster/seq-frozen. Первые файлы seq-before исключены: Unity JsonUtility пропустил вложенные списки. Исправленный Newtonsoft serializer проверяет полный roundtrip до записи. Production не менялся до завершения правильного capture.

- Temp/WhimTex/test-runs/sequential-capture-frozen.json: 13 сценариев, 105180 проверок, PASS.
- Temp/WhimTex/test-runs/sequential-smoke-after.json: 2 сценариев, 720 проверок, PASS.
- Temp/WhimTex/test-runs/sequential-verify-8k.json: 13 сценариев, 148634 проверок, PASS.
- Temp/WhimTex/test-runs/sequential-regressions.json: 3 сценариев, 460496 проверок, PASS.
- Temp/WhimTex/test-runs/sequential-verify-repeat.json: 3 сценариев, 51054 проверок, PASS.

## Проверка после отката

2026-11-17 три производственных файла восстановлены побитово из исходного снимка,
проверенного по SHA256 первоначального capture. Git reset/restore не использовались.
Контрольные суммы остальных 3301 файлов пакета, включая код Undo и изменения
другого чата, совпали. Все 40 ранее сохранённых файлов эталонов и результатов
также остались неизменными. Из changelog удалена только запись об этой оптимизации.

Компиляция через Unity Editor завершилась без ошибок. Все 9 сценариев после отката
прошли: native Raster, полный buffered brush, consumers/view, малый случай с
неполными краями и четыре 8К случая совместного Pressure Opacity + Stamp Multiply
для 2048/4096 внутри/снаружи Transform. Проверены исходные Half-тайлы, HDR, маски,
UV и точный native Undo/Redo; новые эталоны не создавались.

Результаты отката: `Temp/WhimTex/test-runs/sequential-rollback-regressions.json`
и `Temp/WhimTex/test-runs/sequential-rollback-8k.json`. Контроль сохранности:
`Temp/WhimTex/sequential-rollback-20261117/verification.json`.
Новые verify-файлы после отката относятся к восстановленной реализации;
они не добавлены в исторические сравнительные таблицы выше.
