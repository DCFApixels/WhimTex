## Численные проверки GPU

[GradientGpuSmoke](GradientGpuSmoke.cs) проходит 1 309 245 проверок.
Максимальная абсолютная разница — 0.0085458755, в пределах существующего допуска для Perceptual.
Для остальных режимов прежний допуск 0.002 сохранён.

Кроме ошибки Mirror, обнаружена отдельная неоднозначность: вычисление radial/square-координаты
на CPU и GPU может оказаться по разные стороны одного Fixed-скачка при минимальном округлении.
Для многоключевого растрового fixture выбран размер 64×34, как в соседнем GradientGpuRunSmoke.
Это не заменяет проверку скачка: добавлен отдельный GPU-путь с точной uniform-координатой,
без интерполяции растра и вычисления радиуса. Он проверяет каждую RGB/alpha-границу,
саму точку, обе стороны ±0.000001 и смещения −2, −1, 0, 1, 2 во всех wrap-режимах
и обоих цветовых пространствах. Он использует прежний допуск 0.002.
