# F26. Настройки всех инструментов между сеансами

- Назначение: сохранять настройки любых инструментов WhimTex между сеансами работы.
- Статус: требование пользователя записано 2026-10-17 в беклог; реализация не начата. Полнота текущего сохранения ещё не проверена.
- Источники истины: запрос пользователя; текущие [user settings](../../src/WhimTexUserSettings.cs), [настройки рисования](../../src/PaintToolSettings.cs), [окно](../../src/WhimTexWindow.cs), [режимы лассо](../../src/WhimTexWindow.LassoPicker.cs).

## Требование пользователя

- Все настройки всех инструментов должны восстанавливаться между сеансами,
  включая закрытие и повторное открытие окна и перезапуск Unity Editor.
- Пользователь предложил хранить их там же, где остальные user settings.
  Основной кандидат — расширить существующий WhimTexUserSettings, использующий
  EditorPrefs, вместо зависимости только от сериализованного состояния окна.
- Это общее требование ко всем инструментам, а не отдельное исправление кисти
  или лассо. При добавлении новых настроек также учитывать их сохранение.

## Предлагаемая работа

1. Проверить настройки каждого инструмента и их текущих владельцев: что уже
   сохраняется, что восстанавливается только после reload, что сбрасывается
   при создании нового окна или перезапуске Editor.
2. Согласовать общий путь загрузки и сохранения через user settings. Охватить
   числовые параметры, переключатели, режимы, цвета и применимые ссылки на
   пресеты/ассеты. Ссылки сохранять устойчиво, без сеансовых Unity object ID.
3. Сохранять подтверждённые изменения и восстанавливать их до первого
   использования инструмента, с корректными начальными значениями для ещё
   не заданных настроек. Не записывать настройки на каждом движении курсора.
4. Определить синхронизацию нескольких открытых окон и поведение существующего
   сброса user settings; не смешивать пользовательские предпочтения с параметрами
   слоёв и документов.

Настройки инструмента отделены от незавершённого жеста: текущий мазок,
захват указателя, временные вершины лассо и буферы предпросмотра сами по себе
не являются настройками, которые нужно восстанавливать этим механизмом.

## Будущая проверка

После инвентаризации проверить каждый инструмент при смене инструмента,
закрытии/открытии окна, перезагрузке скриптов и полном перезапуске Editor.
Отдельно проверить несколько окон, отсутствующий ассет/пресет и сброс настроек.
