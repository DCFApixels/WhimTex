# F26. Настройки всех инструментов между сеансами

- Назначение: сохранять настройки любых инструментов WhimTex между сеансами работы.
- Статус: выполнено и закрыто 2026-10-20. Подтверждено восстановление после настоящего перезапуска Unity пользователем; пройдены проверки всех секций, собственных окон и нескольких окон. Границы ручного UI/reload-покрытия перечислены отдельно в D02.
- Источники истины: [контракт](../../Documentation~/ToolSettings.md), [реестр окна](../../src/WhimTexWindow.ToolPreferences.cs), [хранилище user settings](../../src/WhimTexUserSettings.Tools.cs), [настройки рисования](../../src/PaintToolSettings.cs), проверки `tool-preferences-v1` и `user-settings-cleanup-v2` / `user-settings-cleanup-unity-v2`.

## Требование пользователя

- Все настройки всех инструментов должны восстанавливаться между сеансами,
  включая закрытие и повторное открытие окна и перезапуск Unity Editor.
- Пользователь предложил хранить их там же, где остальные user settings.
  Основной кандидат — расширить существующий WhimTexUserSettings, использующий
  EditorPrefs, вместо зависимости только от сериализованного состояния окна.
- Это общее требование ко всем инструментам, а не отдельное исправление кисти
  или лассо. При добавлении новых настроек также учитывать их сохранение.

## Инвентаризация до изменения

| Настройки | Прежнее хранение | Решение |
| --- | --- | --- |
| Brush/Pencil/Fill/Blur/Smudge/Healing, dynamics, smoothing и цвета | PaintToolSettings в EditorPrefs | Прежний ключ и модель сохранены, запись переведена в общий реестр. |
| Основной инструмент и возврат из Transform | Два ключа EditorPrefs | Те же ключи; стартовый выбор нового окна, без переключения уже открытого окна при смене фокуса. |
| Shape, Text, Gradient creation | Сериализованное состояние окна | Подключены к общим user settings. Не меняют свойства существующих слоёв. |
| Selection mode/edges, Marquee, Lasso/Smooth | Состояние окна | Подключены к общим user settings; вершины/маска выделения не сохраняются здесь. |
| Vector Brush: размер, форма, цвет, точность | Сериализованное состояние окна | Подключены к общим user settings; активная фигура и Edit Mask не переносятся. |
| Crop: режим и Auto Pixel Scale | Сериализованное состояние окна | Подключены к общим user settings; рамка и размеры документа исключены. |
| Выбор пресета кисти, масштаб образца | Состояние окна | Подключены к общим user settings; существующие GUID/local ID, пути и image cache переиспользованы. |
| Guide switches и внешний вид UV-линий | Состояние окна | Подключены к общим user settings; геометрия направляющих и UV Mesh/Channel остаются вне предпочтений. |
| Фильтр статуса инструмента Comment | Состояние окна | Подключён к общим user settings; поиск, запрос автора/дат, черновики и обсуждения не являются defaults инструмента. |
| Layer Select threshold, pressure curve, автор комментариев, радиус/цвета привязок | Уже WhimTexUserSettings | Переиспользованы без второго хранилища. |
| Transform, Zoom, Gradient Handles, узлы/перо и Comment placement | Данные документа, вида или жеста | Дополнительных сохраняемых defaults нет; не копируются в user settings. |

## Выполнено

- `ToolPreferenceSession` регистрирует типизированные значения, defaults и codec; окно
  восстанавливает их до построения инструментов. Добавлено правило в AGENTS.md.
- Общий observer контролов и явный путь для кнопок/горячих клавиш ставят отложенную
  запись. Закрытие окна, beforeAssemblyReload и quitting сбрасывают очередь на диск;
  холостой кадр и движение курсора не сериализуют настройки.
- Несколько окон сливают только изменённые JSON-поля, не перетирая чужие изменения;
  возвращающееся незанятое окно обновляет общие параметры. Один и тот же параметр
  получает последнее подтверждённое изменение. Массив ключей — единое значение.
- Reset очищает общие ключи и восстанавливает defaults без удаления пресетов или
  изменения документов. Некорректная секция не сбрасывает остальные настройки.
- В payload нет сеансовых Unity object references. Отсутствующий asset сохраняет
  GUID/local ID; числовые параметры и другие секции остаются доступными.
- Проверены destroy/recreate, независимые холодные чтения GUID-изолированных
  EditorPrefs, типы/режимы, градиент/HDR/alpha, asset tip, очередь, слияние двух окон,
  клавиатурный путь размера, отсутствие документа/жеста в payload и defaults.
  Пройдены также source- и Unity-регрессии существующих user settings.
- После перезапуска Test6.6 пользователем подтверждён новый процесс Unity. До запуска
  проверок прочитаны восстановленные окна: все 26 зарегистрированных секций согласованы
  с user settings; сохранённые значения восстановились, отсутствующие секции имеют defaults.
  Настройки пользователя не переназначались ради этой проверки.
- В новом сеансе повторно пройдены `tool-preferences-v1`, `user-settings-cleanup-v2`
  и `user-settings-cleanup-unity-v2`. Первая проверка дополнена точным сравнением
  всех 26 секций при закрытии/создании окна, включая preset selection/snapshot,
  Guide switches, UV color и масштаб образца. Исчезнувшие внешние preset/cache
  проверены с уникальными отсутствующими путями/ID: fallback не создаёт файлов
  и сохраняет ссылки и остальные параметры.

Настройки инструмента отделены от незавершённого жеста: текущий мазок,
захват указателя, временные вершины лассо и буферы предпросмотра сами по себе
не являются настройками, которые нужно восстанавливать этим механизмом.

## Границы проверки

- Физический ввод в поля/пикеры, полный Reset через диалог и планшет не проверялись.
  Reset механизма, defaults и сохранность документа проверены на собственных окнах;
  настройки пользователя через диалог не сбрасывались.
- Реальная reload-матрица с активными пользовательскими жестами не выполнялась.
  Обычная компиляция и пользовательский перезапуск проверены; пересоздание окна
  не подменяет проверку процесса. Расширенная ручная матрица остаётся в
  [D02](VERIFICATION.md#настройки-инструментов-f26), не открытым объёмом реализации F26.
