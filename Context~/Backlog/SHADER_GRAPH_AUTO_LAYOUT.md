# F31. Автоматическое расположение нод Shader Graph

- Статус: согласованный первый этап выполнен 2026-11-17.
- Область: Shader Graph у Shader-слоя и FX, включая Sub Graph. Граф документа F18 остаётся отдельной задачей.

## Выполнено

- **Arrange Selected** размещает выделенные ноды по связям с учётом измеренных размеров корпуса, полей и портов. Остальные ноды и заметки служат препятствиями. Для всей команды используется одна запись Undo.
- Агентские правки `draftGraph` и `program.draftGraph` автоматически размещают новые ноды с пропущенным `position`. Явные координаты и позиции прежних ID сохраняются. Размеры для API оцениваются по данным графа без открытия окна.
- Общий расчёт упорядочивает колонки по связям и портам. На умеренных графах дополнительно уменьшает пересечения по приближённой оценке проводов. На сложных графах часть пересечений остаётся.
- В Unity прошли 16 проверок `shader-graph-arrangement`, включая пункт меню, Undo/Redo и JSON. На временной копии полигона из 37 нод и 42 связей корпус и боковые поля нигде не наложились. Основной HLSL и код промежуточных проходов совпали, новых компиляций не было.

Контракт: [Shader Graph](../../Documentation~/ShaderLayer.md#node-movement-and-deletion). Полная раскладка отдельной командой и изменение трассировки проводов могут обсуждаться отдельно.


## Прототип

Проверка с измеренными размерами на тестовом графе показала, что одной
топологической сортировки недостаточно для хорошей раскладки проводов. В первой
версии выбран общий алгоритм на C# без зависимости от внешнего движка. Сравнение
подходов с выделением дорожек для дальних связей уместно при следующей итерации.
