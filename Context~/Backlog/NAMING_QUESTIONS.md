# Q01. Неподтверждённые переименования

- Назначение: сохранить вопросы, которые аудит не подтвердил как незавершённые переименования или легаси.
- Статус: требует решения; пользователь поручил оставлять неоднозначные места неизменными до согласования.
- Источники истины: [исходный аудит](../RENAME_CLEANUP_AUDIT.ru.md), текущий код и [глоссарий](../DECISIONS.md#глоссарий).

## Восемь групп вопросов

| Место | Почему оставлено / вариант для обсуждения |
| --- | --- |
| `CanvasViewport` | Геометрическое преобразование координат и видимой области. Viewport может быть самостоятельным техническим термином, не старым именем Canvas View. |
| `EffectRenderCache` и общая инфраструктура рендера | Кеш может обслуживать разные сущности. Проверить область ответственности сервиса; различие Effect Layers/FX не требует механической замены Effect на FX. |
| `Inspector` во внутренних UI-методах/partial | UI называется Layer Settings, но Inspector может описывать способ отображения свойств. Незавершённый rename не доказан. |
| Bevel `_Smoothing` / Normal Radius; `_Amount` / Channel Offset или Dither Strength; `_Smooth` / Transition Width | Лейблы могут намеренно пояснять uniform. Варианты `_NormalRadius`, `_ChannelOffset`, `_DitherStrength`, `_TransitionWidth` требуют согласования. |
| Shape `kind` / Shape; SDF/Outline `metric` / Distance Algorithm; Noise/SDF `encoding` / Output; Make Seamless `histogramContrast`/`quiltingChannels` / Contrast/Channel Matching | Общий UI-термин не доказывает устаревшее поле. Унификация затронет модель, TIFF/JSON и API; без вкусовых правок. |
| Shape property/API `roundness` рядом с `cornerRoundness` | Helper задаёт все четыре угла, snapshot API показывает первый. При разных углах смысл неоднозначен. Обсудить удаление helper или имя `uniformCornerRoundness`; это не снятое сериализованное поле. |
| `ShaderFXParameterType.Vector` для float4 и Vector → Vector3 при редактировании кода | Обсудить Vector4 и строгие переходы. Текущая редакторская операция не равна reader старых файлов; удаление по имени не обосновано. |
| Числовой fallback бинарного enum при неизвестном имени | Может скрыть rename enum, но нужен также для flags и значений без имени. Сначала выбрать политику допустимых enum. |

## Правило принятия решения

Приоритет имеет UI-термин; сокращённое имя в UI и более полное техническое имя
допустимы. Подтверждённый rename менять согласованно в коде, данных, API, схеме
и документации. Не переименовывать все Preview, Effect или Vector по одному
совпадению слова. Завершённые Document/Window, Mapping/Rendering и FX-диагностика
не являются оставшимися пунктами этой карточки.
