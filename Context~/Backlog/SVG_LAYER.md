# F08. Полноценный SVG-слой

- Назначение: сохранить отдельно обсуждавшуюся возможность SVG, не приравнивая её к существующим простым фигурам.
- Статус: идея; объём, параметры и обязательство реализации не согласованы.
- Источники истины: [исходная запись обсуждения](https://github.com/DCFApixels/WhimTex/blob/443112f409559432fa99292657227de17d7df9cc/Context~/DECISIONS.md#отложено-не-начинать-автоматически); текущий [Shape](../../src/Layers/ShapeLayerBehaviour.cs).

## Перед продолжением

Нужно определить пользовательскую задачу: импорт готового SVG, редактирование
векторных элементов или только растеризация файла. Затем выбрать необходимый
набор SVG-возможностей, библиотеку/собственную реализацию и правила обновления
источника. Эти варианты перечислены для уточнения, ни один не утверждён.

Простые Shape-слои не создают обязательства реализовать полный SVG. Не расширять
их в SVG-систему автоматически при локальном улучшении фигур.
