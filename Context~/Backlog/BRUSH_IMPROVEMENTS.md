### Границы выполненных пунктов

- Сглаживание по умолчанию выключено. Стабилизатор должен иметь понятный размер задержки и правило завершения хвоста; Shift-линии и привязки не должны терять точность.
- Защита записи по умолчанию выключена, все RGBA доступны. Она должна учитывать полупрозрачность, ластик, HDR и premultiplied рабочую поверхность.
- Проверять реальный результат кисти и защищённых каналов, не только наличие полей в UI. Не изменять пользовательские документы ради тестов.
- Разрешение на пункты 2 и 3 не распространяется на остальные пункты.

### Реализация и проверки

- Smoothing: None/Smooth/Stabilizer, Distance 1–256 пикселей холста, независимый Smooth Pressure и опциональное завершение хвоста при отпускании. Работает для Brush/Pencil/Blur/Smudge; Pencil не использует нажим. Shift-линии и привязки обходят фильтр. Отдельного отображения «верёвки» стабилизатора пока нет.
- Lock Alpha и Write RGBA защищают значения при Brush/Pencil/Blur/Smudge/Fill/Healing. Маска записи независима от просмотра каналов в футере; Lock Alpha имеет приоритет над записью A. Нулевые маски не запускают рисование. Учитываются HDR, полупрозрачность и скрытый RGB прозрачных пикселей.
- Все общие настройки встроены в существующую строку выбранного инструмента в шапке Canvas View. Используются общие стили и адаптивное скрытие дорожек слайдеров; при недостатке места сохраняется штатный перенос полей.
- Сглаживание хранится как настройка ввода пользователя, а Write RGBA/Lock Alpha — в настройках и пресетах кисти. Агентское API принимает маску и Lock Alpha для кисти и восстанавливающих операций; переданные агентом точки не сглаживаются настройкой UI.
- Адресные проверки: математика сглаживания, сериализация маски/defaults, все 16 масок с Lock Alpha и без него на GPU, HDR/прозрачные пиксели, ластик, Pencil, Blur и Smudge с тремя Mixing. Проверены единая строка, общие стили, drag лейблов, компактный режим и отсутствие дрожания на границе ширины. Полный набор тестов не запускался.

## Уже существует

Opacity/Flow, Spacing, Scatter/Scatter Bias, Size/Angle Jitter, Tint, Random/Sobol,
ориентация по движению, Flip X/Y, текстурные и HLSL-наконечники, SDF/Gradient,
Per Stroke/Per Stamp blending, пресеты, симметрия и бесшовное рисование.
Это база для расширения, а не новые задачи.

HLSL-наконечники поддерживают Static и Dynamic, определяемые сигнатурой BrushTip.
Dynamic получает seed, индексы мазка/отпечатка и длину пути; считается прямо в
пакетном GPU-рендере, без запекания каждого отпечатка. Контракт и пример —
в [BRUSHES.md](../../Documentation~/AI/BRUSHES.md#dynamic-context-and-randomization).
Это не реализация динамики нажима из пункта 1 и не вторая текстура из пункта 4.
Параметры HLSL-наконечника используют общий с FX синтаксис и поля, включая группы,
условия, bool/enum, векторы, texture2D (Texture/None), transform2D, градиенты и кривые.
Текстурные параметры сохраняются как ссылки на ассеты, без встраивания изображений.
