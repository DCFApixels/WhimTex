# T02. Чёткость текста при Horizontal Scale

- Назначение: устранить лишнее размытие букв при горизонтальном масштабировании символов.
- Статус: исправлено 2026-10-12; профильные проверки резкости, геометрии и прежние регрессии текста прошли в Unity Test6.6.
- Источники истины: [TextLayerRenderer](../../src/Layers/TextLayerRenderer.cs), [TextLayout](../../src/Layers/TextLayout.cs), [текстовый шейдер](../../src/Shaders/Text.shader), [ввод на Canvas](../../src/WhimTexWindow.Text.cs), [тесты слоя](../../Tests~/Cases/Layers/TextLayerTests.cs).

## Проблема → действие

Глифы растеризовались для обычного Font Size, после чего их растровая альфа растягивалась
по горизонтали. Теперь размер растеризации умножается на `max(1, Horizontal Scale)`;
геометрия возвращается в логические единицы шрифта до применения масштаба. Выходная
маска остаётся прежнего размера; sharpening и компенсация контраста не добавлены.

## Критерии исправления

- Сравнить `Horizontal Scale = 0.5`, `1`, `2` и дробные значения при одинаковых Font Size и масштабе Canvas View; исключить лишнее размытие сверх необходимого сглаживания пиксельной сетки.
- Сохранить смысл множителя: меняется ширина символов, не их высота; `1` остаётся нейтральным значением.
- Не нарушить Spacing Options, переносы, Auto Size, Ellipsis, рамку и ввод на Canvas.
- Проверить чёткость в композиции, миниатюрах, экспорте и резервном изображении текста; отделить качество итогового рендера от отображения поля ввода.

## Выполнено

- Новый `text-horizontal-scale` сравнивает ширину перехода альфы, ширину и высоту букв
  при 0.5, 1, 1.25, 2 и 4. До исправления проверка резкости падала, после — проходит.
  PNG-сравнения просмотрены; артефакты проверки остаются только в Temp/WhimTex.
- `text-layer` прошёл: Spacing, Small Caps, переносы, Auto Size, Ellipsis, масштабированный
  preview, миниатюры, fallback, JSON и TIFF model payload. UI-интерактивность не менялась.
- Плотность ограничена прежним максимумом размера шрифта 2048 и бюджетом маски;
  экстремальные масштабы/шрифты не получают неограниченную память. Дополнительной RT нет.

Большая матрица системных шрифтов, конечный экспорт и интерактивный Canvas View на
разных DPI не проверялись; это границы итоговой сверки D02, не обещание одинакового
растра при любых размерах.
