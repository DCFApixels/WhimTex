# F32. Панель нод Shader Graph

- Назначение — быстро добавлять ноды на холст перетаскиванием из панели редактора Shader Graph.
- Статус — выполнено.
- Источники истины — [панель](../../src/Editor/ShaderGraphWindow.Palette.cs), [общий каталог](../../src/Editor/ShaderGraphWindow.Canvas.cs), [контракт редактора](../../Documentation~/ShaderLayer.md#node-movement-and-deletion).

## Выполнено

- Вкладка **Nodes** рядом с **Parameters** слева. Поиск по имени и категории, дерево категорий и перетаскивание на холст с учётом масштаба и смещения вида.
- Каталог и создание общие с **Create Node** для Shader Layer, FX и Sub Graph. Доступны параметры, HLSL-функции и допустимые Sub Graph. Фильтр **SVM Nodes Only** учитывается.
- Выбранная вкладка, поиск и раскрытые категории сохраняются с окном. Неизменившийся каталог не сбрасывает список и прокрутку. Строки виртуализированы, просмотр списка не запускает компиляцию шейдеров.
- Обычное создание и Undo/Redo, проверка актуальности источника перетаскивания, защита от рекурсии и изменений read-only графа.

## Проверки

Штатная компиляция Unity и временный in-memory probe прошли. Проверены соответствие
каталогу, поиск и DDXY, захват/освобождение указателя без создания по клику, сброс на холст
при 35%/160%, Undo/Redo, FX, фильтр SVM, смена области графа, удалённые параметры,
рекурсия, read-only, восстановление состояния при пересоздании UI и узкая панель.
Скриншот узкой панели просмотрен. Сквозной системный жест мышью отдельно не подтверждён
автоматизацией — его проверка потребовала отмены через Esc; обработчик сброса проверен
событиями UI Toolkit. Отчёт и probe находятся в проектном `Temp/WhimTex/NodePalette`.
