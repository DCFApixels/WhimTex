# Скриншоты для руководства WhimTex

- Назначение: план иллюстраций, объясняющих художнику результат настройки.
- Статус: предложения для съёмки пользователем; не разрешение агенту менять документы/ассеты.
- Источники истины: действующие руководства по ссылкам ниже и фактический UI.

План составлен после редакторской правки 2026-10-03; перед съёмкой сверить подписи с текущим UI.
Место указано для RU; те же изображения можно использовать в EN/ZH с локализованными подписями.

## Как снимать

- PNG, без масштабирования исходного снимка. Оставить читаемыми нужные поля и результат; лишние окна обрезать.
- Для сравнений сохранить одинаковые холст, масштаб просмотра, EV, каналы и фон. Менять только демонстрируемую настройку.
- Обычно: EV 0, RGBA включены, Post FX выключен. Исключения отметить в имени/описании кадра.
- Для прозрачности использовать один нейтральный шахматный фон. Для проверки швов — Tiled и полноразмерный просмотр через Pencil без рисования.
- Можно прислать отдельные исходные кадры. Подписи и компоновку сравнения добавим при вставке; не нужно встраивать длинный текст в изображение.
- По возможности один кадр показывает одну мысль. Имя файла ниже — ориентир, не требование переименовать рабочие документы.

## Первая очередь: объясняют принцип

### 01. Effect layer, FX и Processor

Место: [Shader FX → выбор области действия](../Documentation~/ru/shader-fx.md#обработать-слой-или-изображение-под-ним), [Effects → источник](../Documentation~/ru/effects.md#выбрать-источник).

Три кадра одной простой композиции из двух перекрывающихся цветных фигур:
1. FX на одной фигуре меняет только её.
2. Processor над обеими меняет их совокупность.
3. Effect layer с раскрытым Input/Target использует явно выбранную фигуру.

Показать Layers и соответствующий блок настроек. Не использовать сложный шум: важна область влияния.
Имена: `effect-scope-layer.png`, `effect-scope-processor.png`, `effect-input-specific.png`.

### 02. SDF как расстояние

Место: [Effects → Outline и SDF](../Documentation~/ru/effects.md#outline-и-sdf).

Один несимметричный силуэт с отверстием. Кадры: исходная альфа; Signed + Linear Data; тот же SDF + Gradient с цветом и прозрачностью.
Показать Source Channel, Threshold, Position, Max Distance, Profile и Output. Дополнительная пара с двумя Max Distance объяснит ширину перехода.
Важно видеть, что Gradient задаёт собственную альфу, а не сохраняет мягкую альфу исходника.
Имена: `sdf-source.png`, `sdf-distance.png`, `sdf-gradient.png`.

### 03. Четыре метода Make Seamless

Место: [Effects → Make Seamless](../Documentation~/ru/effects.md#make-seamless), сразу после таблицы методов.

Пять кадров одной непериодической текстуры: исходник, Offset Blend, Mirror, Screened Poisson, Patch Quilting.
Для каждого — одинаковое Tiled-превью с видимыми стыками и кроп настроек Method/граней/основных параметров.
Для сравнения принципов отключить дополнительную Poisson Correction у остальных методов и явно подписать это.
Отдельно можно снять практический Offset Blend: Transition Start −25%, Poisson Correction включена.
Не выдавать разные исходники/масштабы или оптимальный случай одного метода за универсальное сравнение качества.
Имена: `seamless-source.png`, `seamless-offset.png`, `seamless-mirror.png`, `seamless-poisson.png`, `seamless-quilting.png`.

### 04. Тип, Fractal и Warp у Noise

Место: [Noise → Начать с узора](../Documentation~/ru/noise.md#начать-с-узора).

Небольшая серия на одном масштабе: OpenSimplex2, Cellular, Perlin, ValueCubic; затем один тип без Fractal, с FBm, с FBm + Warp.
Показать Noise Type, Scale, Fractal, Warp Strength и Warp Scale. Не нужны скриншоты всех возможных комбинаций.
Имена: `noise-types-*.png`, `noise-fractal-warp-*.png`.

### 05. Seamless и 3D-срез Noise

Место: [Noise → Масштаб, 3D-срезы и бесшовность](../Documentation~/ru/noise.md#масштаб-3d-срезы-и-бесшовность).

Пара Tiled off/on для Seamless при неизменных остальных настройках; оставить видимым квадрат граней.
Две дополнительные картинки одного 3D Cellular с разным Offset Z, одинаковыми Seed и Scale.
Это объяснит «срез объёма», а не обещание точного совпадения с 2D Cellular.
Имена: `noise-seamless-off.png`, `noise-seamless-on.png`, `noise-3d-z-*.png`.

### 06. Интерполяция и Smoothness градиента

Место: [Color → Настроить градиент](../Documentation~/ru/color.md#настроить-градиент).

Сначала актуальное окно: цветовые/альфа-ключи, midpoint, Mode, Smoothness, Wrap, History и Presets.
Затем одинаковые ключи в Classic, Linear, Perceptual и Fixed. Отдельная пара Smoothness 0/100 на градиенте с постоянным крайним участком.
Не менять цвета или положения ключей между кадрами. Не нужен график внутренних формул Rounded.
Имена: `gradient-editor.png`, `gradient-modes-*.png`, `gradient-smoothness-*.png`.

### 07. HDR и Preview EV

Место: [Color → HDR и экспозиция просмотра](../Documentation~/ru/color.md#hdr-и-экспозиция-просмотра).

Два кадра колорпикера с одним HDR-цветом: Preview EV 0 и отрицательное значение.
RGB/Exposure должны оставаться одинаковыми и читаемыми. History раскрыта; показать один HDR и один обычный образец.
Подпись объяснит, что меняется просмотр, а не сохранённый цвет; это не пример физического HDR-вывода монитора.
Имена: `color-hdr-ev0.png`, `color-hdr-ev-minus.png`.

### 08. Сохранение и JSON

Место: [Saving → Выбрать формат экспорта](../Documentation~/ru/saving.md#выбрать-формат-экспорта), [JSON-документы](../Documentation~/ru/saving.md#json-документы).

Актуальное окно Export: Format = WhimTex JSON, раскрытый Mode со всеми тремя вариантами.
Отдельный кадр предупреждения о Drawing на временном демонстрационном документе; не подтверждать потерю нужного рисунка ради снимка.
Имена: `export-json-modes.png`, `export-json-drawing-warning.png`.

## Вторая очередь: частые ошибки и полезные сравнения

| Место | Кадр | Что должно быть видно |
| --- | --- | --- |
| [Painting → Форма мазка](../Documentation~/ru/painting.md) | Opacity против Flow | Два пересекающихся мазка: низкая Opacity / высокий Flow и наоборот. Одинаковые цвет, размер, фон; показать оба значения. |
| [Painting → Своя кисть](../Documentation~/ru/painting.md#своя-кисть) | Spacing и Scatter | Три коротких мазка с возрастающим Spacing, затем Scatter. Нужны различимые отдельные отпечатки, не только светящаяся линия. |
| [Preview → Направляющие](../Documentation~/ru/preview.md#направляющие) | Привязка на холсте | Две пересекающиеся направляющие, выбранная фигура и привязанный угол/пивот. Второй кадр — мазок вдоль наклонной направляющей. |
| [Preview → Минипревью](../Documentation~/ru/preview.md#минипревью-слоя) | Изолированный результат слоя | Layers, Layer Settings с раскрытым Preview и основная композиция. Выбрать слой, чей отдельный результат явно отличается от композиции. |
| [Color → Каналы](../Documentation~/ru/color.md#посмотреть-отдельный-канал) | RGB / R / Alpha и Channels в колорпикере | Одна текстура с разными масками в каналах. Кнопки футера видимы; отдельно поле цвета с диагональным сравнением. Числа цвета не менять. |
| [Shader FX → Запекание](../Documentation~/ru/shader-fx.md#запечь-эффекты-в-слой) | Два Apply | Отдельные кропы Code → Apply и меню строки FX → Apply. В стеке три эффекта, выбран средний. Подпись укажет, какие два запекутся. |
| [Shader FX → Предупреждения](../Documentation~/ru/shader-fx.md) | Нерабочий эффект | Жёлтая отметка в Layers, свёрнутом FX и конкретном блоке. Брать демонстрационную ошибку в отдельном документе, не портить рабочий. |
| [Layers → Группы](../Documentation~/ru/layers.md#собрать-связанные-части-в-группу) | Pass Through против изоляции | Та же группа с эффектом смешивания на цветном фоне. Видны Layers, режим группы и разница влияния на фон. |
| [Layers → Геометрическая заливка](../Documentation~/ru/layers.md#геометрическая-заливка) | Pattern: геометрия и палитра | Сетка фигур; Gap/Roundness/Gradient и Cell Color/Palette. Отдельный Repeat-кроп при Seamless. |
| [Getting started → Готовое изображение](../Documentation~/ru/getting-started.md) | Drawing против File | Меню Open Images и выбранный тип слоя с одним исходником. Не менять импорт исходной текстуры. |

## Что уже есть

- `whimtex-heart.png` — хорошая общая композиция со слоями; не объясняет по шагам современный SDF/Output.
- `brush-settings.png` — общий вид Brushes и пробного мазка. Оставить; для объяснения Opacity/Flow нужны отдельные сравнения.
- `shader-processor-transform.png` — показывает зелёную рамку, но панель содержит прежнюю компоновку Code & Parameters. Желательно переснять с текущим интерфейсом, сохранив смысл примера.
- `uv-rubik-cube.png` — уже покрывает UV и Live Update, не требуется ещё один общий кадр той же идеи.
- `vfx-energy-ring.png` — подходит как пример результата; не заменяет сравнения Noise, SDF и Seamless.

Сначала достаточно первой очереди. Скриншот не нужен для каждого поля, числового предела, жеста или JSON-ключа.
