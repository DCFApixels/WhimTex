## Text: системные шрифты и переносимость

- Text — обычный источник слоя: публичные Unity Font/TextGenerator, без TMP-зависимости, нативных OS API и импорта Font-ассетов. Поиск/образец в Font picker, единое начертание, размер в пикселях холста, выравнивание, переносы, межстрочный интервал, цвет; дальше общий Transform/FX/Rendering.
- Выбор Font в инструменте и Properties использует общий `SystemFontField` и один picker. В шапке ширина input — 160 px, в Properties — доступная ширина. Имя в поле и строки виртуализованного списка используют свой системный шрифт; недоступный шрифт или неподдерживаемые символы имени оставляют обычный UI font. Preview-fonts принадлежат контролам и освобождаются при замене, recycling и detach; обновление каталога обновляет и preview. Это не Font-ассеты документа.
- Инструмент Text: клик создаёт Point, протягивание — Frame. Редактирование прямо в Canvas View через публичный TextField, Enter — абзац, Ctrl+Enter/Done/клик вне поля — завершение, Esc/Cancel — восстановление текста до ввода. Пока ввод активен, клик только завершает его, без нового слоя. T остаётся хоткеем Transform; у Text иконка T, без нового хоткея.
- Параметры шапки Text принадлежат инструменту и используются только как копируемые настройки нового слоя. Отдельный TextToolSettings содержит только Font/Size/Style/Casing/Alignment/Justify/Color, без данных LayerBehaviour, Layout/Frame Size/Wrapping/Auto Size/Max Size/Spacing. Режим создаваемого блока задаёт жест; параметры рамки и Layout остаются в Properties слоя. Properties меняет только слой; выделение, редактирование, Undo документа и блокировка выбранного слоя не меняют настройки инструмента. Inline-ввод и handles рамки продолжают редактировать существующий слой.
- Frame: размер в px, Manual/Words/Characters. Кнопка Justify всегда доступна: растягиваются только переносимые строки с пробелами, последняя строка абзаца остаётся слева. Для Point/Manual выбор Justify и переход в эти режимы сбрасывают его до левого края с сохранением вертикального выравнивания. Клик при Justify в defaults создаёт Point с левым выравниванием, не меняя defaults инструмента. Угловые handles меняют рамку/переносы, не fontSize; общий Transform масштабирует весь результат. Point не обрезается до границ холста перед трансформацией. Покрытие ограничено 8192 px на ось и 16 MP; локальные границы сохраняются вместе с резервной маской.
- Auto Size действует только в Frame: подбирает наибольший помещающийся целый размер от fontSize до maxFontSize (default 256), учитывая ширину, высоту, переносы и spacing. В Properties это одна строка Size с компонентами Min/Max, как Vector2; вне Auto Size остаётся одно поле на всю ширину. У инструмента только обычный Size, без Auto Size и пределов. Оба предела слоя 1..2048 px, подбор их не переписывает; при минимальном размере возможна обрезка. Min округляется вверх, Max вниз; диапазон без целого размера отклоняется API. UI общими setters корректирует соседний предел при пересечении. В обычном режиме fontSize — фиксированный размер. B/I независимы; горизонтальное и вертикальное выравнивание — общие icon-поля в стиле Transform с обводкой выбранного состояния.
- Spacing Options (em): struct TextSpacing, character/word/line/paragraph, ноль — стандартный интервал; все значения добавочные в em эффективного размера, -1..10. Компактный общий блок 2×2 в Layer Settings. Paragraph только между явными абзацами, не при авто-переносе. Переносы, Auto Size и mask key учитывают все значения. Старый lineSpacing-множитель удалён без алиаса; unsupported-field диагностика обязательна. Отрицательные интервалы не разворачивают ход текста, baseline step минимум 1 px; inline-ввод поддерживает Character/Word/Paragraph через публичные стили, точный Line/Justify — в итоговом рендере.
- Casing: Normal/Lowercase/Uppercase/SmallCaps, mutually exclusive icon-кнопки; повторное нажатие снимает режим. В Layer Settings начертание и регистр объединены в одну строку Style; горизонтальное и вертикальное выравнивание — в одну строку Alignment, с разделителем между группами. Исходный text не переписывается. SmallCaps синтезирует уменьшенные (75%) прописные вместо строчных с общей базовой линией, без OpenType-feature/native API. Переносы, Auto Size, резервная маска и API учитывают casing; inline-ввод сохраняет исходный регистр.
- Horizontal Scale — поле слоя сразу под Spacing Options, не defaults инструмента; данные/API `characterHorizontalScale`, множитель 0.01..10, default 1. Меняет ширину глифов и их естественный горизонтальный advance, включая обычную ширину пробелов; высоту и добавочные интервалы в em не меняет. Учитывается переносами, Auto Size, Ellipsis, inline-вводом, bounds и ключом резервной маски. Frame и transform не растягиваются вместе с буквами.
- Inline-ввод показывает исходный текст, а не FX-результат; итоговая компоновка/Justify/Overflow отображаются после завершения. Поле следует affine-положению/вращению/масштабу слоя; точное отображение skew/perspective и сложный shaping редактором не обеспечиваются. Изменения текста объединяются в один документный Undo; API считает документ занятым до завершения ввода. Завершение или detach отменяет отложенный focus и освобождает Font; вырожденный transform скрывает поле, не оставляя его на старом месте. Refresh каталога обновляет и inline-Font. Resize фиксирует начальные рамку/Behaviour/transform и отменяется при их изменении, смене документа или выделения.
- Overflow — только настройка Frame в Properties и данных/API (`overflow`, TextOverflowMode), не defaults инструмента: None по умолчанию сохраняет текст за рамкой, Clip обрезает, Ellipsis сокращает отображаемые строки с «…». Сначала переносы и Auto Size, затем ограничение ширины/высоты. Исходный текст не меняется; составные символы не разрываются, последняя сокращённая строка не растягивается Justify. Если не помещается строка или многоточие, эта часть не рисуется. Point игнорирует Overflow. Поле участвует в mask key, TIFF/JSON и схемах; ручная вёрстка и API используют те же правила Justify, что Properties.
- TIFF и JSON сохраняют исходный текст и имя шрифта, не файл шрифта. Резервная PNG-маска: до 2048 px и 768 KiB, ключ включает исходную компоновку и размер холста, не включает Color/Transform/FX. При отсутствии шрифта нет молчаливой подмены: показать предупреждение без спама, сохранить вид через подходящую маску; редактирование компоновки требует выбора шрифта. Новая/изменённая компоновка без маски прозрачна. Перед декодированием проверять размеры PNG.
- Ограничение текущей версии: 8192 символа, без посимвольных стилей и расширенного shaping. Разрешённые системные шрифты — результат публичного каталога Unity, а не обещание поддержки любых форматов шрифтов ОС.

**Effect Layer** и **FX** — разные сущности. Effect Layer — отдельный слой вроде SDF
или Outline; FX — шейдерный эффект в списке FX слоя. Реализация Effect Layer через
шейдер сама по себе не делает его FX-блоком. В именах, относящихся к Effect Layers,
`Effect` сохраняется; не заменять его на `FX` механически.

Для списка шейдерных FX поле модели и TIFF/JSON —
`fx`; методы и локальные имена используют `Fx`, а при недостаточном контексте —

назначению, не смешивая Effect Layers и FX. Keyboard modifiers и модификаторы
объявлений HLSL — другие понятия. Старых имён списка и файлового адаптера нет.

## Noise: Seamless вдоль 1D-оси

- У шести lattice-шумов в OneD отдельная галочка Seamless (`periodic1D`, default false). `periodic` сохраняется независимо для 2D/3D. White/Blue не изменены.
- Проекция aspect-correct Scale X/Y на Direction задаёт скалярную координату. Период равен полному диапазону этой проекции по исходному прямоугольнику; затем используется существующая X-периодическая 2D-решётка, включая все Fractal/Warp. Поперечная координата до Warp фиксирована. Это 1D-срез, а не отдельный тип шума.
- При Direction 0/90 замыкаются соответствующие края; произвольный угол гарантирует повтор только вдоль собственной оси, не прямоугольный тайлинг. Периоды по-прежнему квантуются, минимум одна ячейка. Scale < 1 может менять поздние октавы, но не отменяет минимум.
- Random All сохраняет Direction (в том числе у White/Blue и пока поле скрыто), оба Seamless-параметра и Offset.

## Noise: осевые множители Warp Scale

- Random All сохраняет весь Offset (X/Y/Z), включая White/Blue и неактивные координаты; меняется Seed, но не положение слоя шума.
- Random All основного Scale: при цепочке log-uniform кандидат — среднее M=(X+Y)/2 в 1–64, X/Y восстанавливаются по прежней пропорции. Диапазон M пересекается с допустимым по осям 0.01–1000; если пересечение пусто при крайней пропорции, используется весь допустимый диапазон M. Без цепочки независимые X/Y 1–64. Принять с вероятностью `(1+exp(-0.5*log2(M/8)^2))/2`. Мягкий вес 1–2, без обрезки около 8; Warp Scale и состояния цепочек не менялись. Ограничение 2× относится к перевзвешиванию кандидатов, не абсолютным вероятностям произвольных линейных интервалов. Не генерировать X с последующим пропорциональным Y: это смещает среднее при разных исходных осях.
- По уточнённому запросу Warp Scale — X/Y множители обычного Scale, итог по каждой оси = Scale × Warp Scale. Default [1,1], пределы 0.01–1000, цепочка linkWarpScale=true сохраняет отношение, а не выравнивает значения. UI использует тот же helper, что Scale. Отдельного Warp Scale Z нет.
- Random All выбирает логарифмически 0.25–4: связанные оси пропорционально с ограничением общего коэффициента, несвязанные независимо. API принимает число или [x,y] буквально независимо от цепочки. Сериализация warpScale/warpScaleY: обе оси явные. Отсутствующее поле Compact получает фиксированный default; нулевой Y не означает наследование X. Прежний неопубликованный абсолютный Warp Scale 8 заменён этой семантикой.
- Seamless округляет собственную решётку Warp после умножения; амплитуда компенсирует только подгонку периода. BasicGrid 1×1 всё ещё даёт сдвиг, пользователь может увеличить Warp Scale. White/Blue не используют Warp; 1D/2D/3D поддерживаются.

## Make Seamless: настройки и интерфейс

- Mirror Automatic Radius: `mirrorAutoRadius=true`, max(.005, clamp(blendWidth,.001,.5)/4), единый EffectiveMirrorRadius для UI и рендера. Ручной mirrorCorrectionRadius сохраняется и возвращается при выключении авто. Скрыт без Poisson Correction, неактивен без его граней. API/portable/schema поддерживают флаг. Миграции нет; другие методы не менялись.
- Alignment follow-up: убран отступ Strength, Channels получает стандартную ширину лейбла после создания дочерних элементов, подписи квадратов используют отдельный USS-класс с тем же началом текста. Тест теперь измеряет координаты текста/inputs и вертикальные центры, включая реальные Input/Target, а не только границы полей.
- Copy Edges / Mirror Direction / Patch Edges отделены от Poisson Edges. Quilting: поиск → Feather/Contrast Compensation → Poisson. Компактные разделители без foldouts; Strength (%) внутри компенсации, Radius (%) внутри Poisson. Снятые грани отключают только зависимые поля, не квадраты/независимый проход; Feather=0 отключает компенсацию без сброса значений. Алгоритмы, API-поля и сохранённые данные не менялись, миграции нет. Пользователь разрешает переименование без совместимости с прежней версией, если это потребуется для дальнейшей переработки.

## Make Seamless: просмотр и ограничения

- Обычное preview ограничено 512 px; Live Quality не переключает его в полный размер. Для проверки финального Quilting доступен Pencil без рисования + Tiled. Это ограничение обозначено явно, а не скрыто автоматическим дорогим рендером.
- Исторический прогон 2026-09-28 охватывал TIFF save/reopen, PNG, full-resolution preview, drag/Undo,
  маски/грани, оконные кеши и закрытие; отдельные тяжёлые случаи — до 2048×1536.
  Это не текущий PASS, проверка всех платформ/4K или гарантия отсутствия шва на любом исходнике.

## Patch Quilting: продольный поиск

- Along-Seam Search: `quiltingAlongSearch` 0..0.25, default 0 сохраняет исходный поиск. Ненулевой диапазон делит прежний бюджет кандидатов пополам между прямыми и смещёнными полосами.
- Отображение `row+shift*(rows-5)*16*t²*(1-t)²`, `t=clamp((row-2)/(rows-5),0,1)`; первые/последние три отсчёта неизменны, rows<=5 обходится. Диапазон .25 сохраняет монотонность и границы источника без wrap; это деформация полосы, не rigid translation и не полный 2D synthesis.
- CPU matching/градиенты/covariance и GPU donor sampling учитывают сдвиг; cache/API/portable учитывают параметр. Новых image-sized буферов и кандидатов нет, но fractional sampling дороже; визуальное улучшение не гарантируется.
- Проверки: `quilting-along-search-v2`, `patch-quilting-integration-shifted-v2`, `patch-quilting-cache-v2`.
  Исторический zero-range прогон совпал с 252 fixtures и 324 managed-reference cases (max error 0).

## Кроссплатформенность и оптимизации

- Новые Make Seamless через CreateDefault/registry: OffsetBlend; edgeWidth/blendWidth=.2, offsetTransitionStart/mirrorTransitionStart=-.25, обе Poisson Correction=true, их направления AllEdges; четыре Offset copy edges включены, Mirror LeftToRight+BottomToTop (не двустороннее отражение). UI PopupField задаёт порядок Offset Blend, Mirror, Screened Poisson, Patch Quilting отдельно от числовых ID. Смена режима не сбрасывает настройки. Factory defaults отделены от field initializers для прежней интерпретации отсутствующих полей старых документов; сохранённые значения не переписываются, миграции нет. Это заменяет прежние defaults для новых слоёв.

- Mirror: mirrorTransitionStart -1..0.95 (UI -100..95%); field initializer 0 сохраняет старый fade, factory нового слоя задаёт -.25. Вес q=saturate((1-distance/width)/(1-start)), затем smoothstep/falloff; формула общая обычному и histogram-путям. Отрицательное начало расширяет переход за canvas, донор на грани не имеет полного веса; шов возможен, Poisson включается отдельно. API/clipboard/cache/Undo учитывают параметр.

- Make Seamless: алгоритмы и параметры качества при оптимизации не меняются. HistogramSeamless использует один idle owner с NativeArray/Burst, переиспользуемыми readback/LUT Texture2D и квантилями по числу отсчётов; максимум около 2.2 MiB CPU storage плюс текстуры, expiry 30 s, cleanup reload/quit, nested rent изолирован. Explicit double intermediates сохраняют прежнее округление managed LUT/lookup, в том числе на прозрачных HDR-пикселях. Quilting кеширует свои Burst-квантили в существующем workspace budget; адресация донора без remainder эквивалентна прежней. Screened сохраняет 16 PCG-итераций и прежние FFT-проходы: до 16 планов факторизации, прямой финальный reduction и обмен scratch/z убирают 67 копирований текстур за solve. 252 сохранённых GPU fixtures и 324 quilting equivalence cases совпали точно на проверенном backend. Подробности и честные ограничения замеров: [SeamlessOptimization](https://github.com/DCFApixels/WhimTex/blob/ca8603c0961ce36064280f952259f8a6142d46cc/Tests~/Legacy/SeamlessOptimization.md). Нет миграции.

- Все парные селекторы граней разрешают пустой выбор `PoissonEdges.None=3`: пропуск только своего прохода, независимо от других. Последняя пара остаётся интерактивной, без disabled tint. `AllEdges=0`, `TopAndBottom=1`, `LeftAndRight=2` не изменены; миграции нет. Это заменяет прежнее ограничение «хотя бы одна пара».

- Patch Quilting: опциональная Contrast Compensation для Feather, default off, сила `quiltingContrast` 0..1 (UI проценты). Гистограммное преобразование и ковариация выбранной пары, затухание поправки на чистых отсчётах каждого прохода. Без дополнительного GPU readback; NativeArray/Burst входят в лимит workspace. При выключении/нулевой силе/нулевом Feather дополнительных вычислений нет. Второй проход использует компенсированный первый и может выбрать другой донор. Старые файлы не меняются; миграция не нужна.

- По умолчанию код должен оставаться кроссплатформенным. OS-specific API/библиотеки и аппаратно-специфичные
  реализации/intrinsics можно изучать и предлагать с объяснением ограничений, но реализовывать или использовать
  только с явного разрешения пользователя. Portable fallback и общий запрос на оптимизацию такого разрешения
  не заменяют. Правило также в AGENTS.md, включая новый тестовый и benchmark-код.
- Burst допустим для переносимого алгоритмического C# без ручной привязки к ISA, вендору или ОС;
  автоматическая генерация машинного кода компилятором и штатные Unity graphics backends не запрещаются.
- Windows CNG / `bcrypt.dll` для SHA-256 допустимы как предлагаемая идея, но разрешения на их реализацию
  сейчас нет. Имеющиеся Windows-only диагностические helpers не являются разрешением для нового кода.
- SHA-256 на Burst подключён к integrity-блокам TIFF после проверки совпадения с .NET и замеров.
  Только переносимые uint-операции, без intrinsics/native DLL; scratch до 1 МиБ на вызов.
  Малые блоки (<4 КиБ) и отключённый Burst используют .NET. SHA-256 и формат документов не меняются.
  Замеры и ограничения проверки: [TIFF_SAVE_PERFORMANCE.md](TIFF_SAVE_PERFORMANCE.md).

## Слои, документы, окна

- Восстановление Shader FX при открытии — `RenderResourcesChanged`, не изменение документа. `Changed` остаётся для правок, включая новую ревизию связанного пресета и отсоединение недоступного пресета к fallback. Отложенные уведомления объединяются с приоритетом реальной правки, без сброса dirty после открытия. Файловая десериализация отдельно устанавливает baseline Undo; Unity Undo/Redo сохраняет прежнюю обработку. Проверка: `shader-fx-document-dirty-v2`.
- Общие данные остаются в Layer при замене LayerBehaviour; Missing Reference сохраняет имя и общие настройки.
  Восстановление поведения переносит совместимые параметры, а не заменяет личность слоя.
- GUID слоя: небольшая toolbar-подобная кнопка справа в заголовке настроек; tooltip содержит GUID,
  клик копирует его и показывает неблокирующее подтверждение.
- New создаёт отдельный документ в соседней вкладке; открытие уже открытого документа фокусирует его.
  Название вкладки — имя документа; новое имя короткое: Untitled.
- Выбор активного окна по последнему взаимодействию — только fallback, не замена реальному фокусу.
- File со ссылкой на композитор открывает исходник двойным кликом. Дочерний документ может обновлять
  родительское изображение; не считать все проблемы текстуры следствием Live Update.
- Ctrl+C без выделения на холсте копирует слой для вставки в другом окне, включая Drawing-пиксели.
  Текстовые поля сохраняют обычные текстовые сочетания клавиш.
- При перезагрузке домена не терять несохранённые Drawing-пиксели и направляющие.
- Новая пустая композиция: фон без холста; первый импорт может задать размер холста.
  Не позволять невидимому холсту остаться за экраном после появления слоя.
- В пустом состоянии инструменты можно выбирать и настраивать; они выглядят неактивными и не рисуют.
  Не предлагать сохранять нетронутый новый документ; удаление последнего слоя остаётся сохраняемым изменением.
- Поведение импорта после удаления последнего слоя не приравнено к нетронутому новому документу;
  вопрос и следующий шаг сохранены в [Q02](Backlog/EMPTY_DOCUMENT_IMPORT.md).

## Формат документа

Дополнение: `.json` / `whimtex.document` v2 — единый JSON для файлов, clipboard и агентов; расширение `.whimtex.json` также читается, но не включает поддержку старого формата.
Корневой kind не записывается и не выбирает действие: один JSON можно открыть документом или вставить слоями.
JSON выбранных слоёв тоже открывается как документ. Корневой kind отвергается; действие выбирает вызывающая сторона.
Open/write восстанавливают настройки документа; insert/paste не переносят выходные настройки приёмнику,
replace работает только по явно заданной операции/цели API. Clipboard может отдельно предложить размер холста.
document и каждое поле внутри необязательны; явный null вместо объекта — ошибка. Open/write используют
замороженные defaults v1 (512×512), insert/paste — ось приёмника вместо каждой неуказанной размерности.
Без обеих размерностей clipboard не предлагает resize; API insert/replace не меняют размер приёмника.
Writer всегда сохраняет width/height, даже Compact при совпадении с defaults, чтобы не терять контекст холста.
Режимы Full / FullOptimized (по умолчанию) / Compact; disabled слои/FX остаются, default-значения
зафиксированы по версии. Drawing хранит пустой узел с явным предупреждением; экспорт не меняет TIFF.
GUID → Path с проверкой localId/type; отсутствие ассета не блокирует открытие, идентичность сохраняется.
Старый `whimtex.layers` и прежние версии документов требуют соответствующий старый checkout; миграции в текущий формат нет. Обычная вставка URL картинки и загрузка tip кисти сохраняются.
Открытие и clipboard-вставка единого JSON используют мягкую подготовку FX: ошибки компиляции
дают предупреждение и пропуск FX без потери кода/параметров/enabled; исправление через Apply.
Вставка по-прежнему требует подтверждения доверия к HLSL, затем позволяет отменить предупреждение.
Ошибки структуры и зависимостей не смягчаются. Файловые readers используют текущий формат без адаптера прежних представлений.
Контракт: [JSON_FORMAT](../Documentation~/JSON_FORMAT.md).

TIFF-контейнер, precision/sRGB, атомарная запись, identity/Live Update и правила совместимости:
[DOCUMENT_FORMAT.md](DOCUMENT_FORMAT.md). Независимые модели без окна: [TIFF_AUTHORING.md](TIFF_AUTHORING.md).
Не дублировать здесь эти контракты. Эталоны и правила добавления новых образцов:
[Fixtures/README.md](../Tests~/Fixtures/README.md); старые fixtures не перегенерировать ради PASS.

## Рендер и UI

- Шапка Canvas View (верхние настройки и строка инструмента) использует общий `WhimTexCanvasHeaderRow` и scoped USS: один шрифт/выравнивание, ширина лейбла по тексту, нативная связь лейбла с полем, horizontal layout без перекрытий. Обычные кнопки — по содержимому; выпадающие списки сохраняют заданные контекстом размеры, независимо от выбранного текста. Слайдеры имеют общий минимум ширины; при нехватке места скрывается только дорожка, числовой ввод остаётся. Порог определяется полной шириной контролов с запасом при обратном переключении, чтобы не было дрожания. Новые инструменты используют ту же строку; эти правила не меняют инспекторы и footer.
- FX группы применяются к детям, а не внешнему фону. Изоляция временно переопределяет Pass Through,
  не переписывая сохранённое предпочтение. Проверять также группы внутри групп, Target, clipping и экспорт.
- Миниатюры нужны и процедурным/эффектным слоям; не пересчитывать их без необходимости.
- Tiling: Source первым в списке; порядок отображения не должен менять сериализованные значения.
  Clip, Repeat, Mirror, растяжение края (Clamp), продолжение процедурных UV (Unbounded) различаются.
  Для источников без настоящего Unbounded допустим fallback; не обещать продолжение растра за UV.
- Noise/Gradient создаются с Unbounded; Color Fill по умолчанию цветовой, UV — дополнительный режим.
- Color Fill также имеет Pattern: аналитическое поле расстояний для Triangles/Squares/Hexagons/Circles; Circle Layout Square/Dense. Roundness скругляет контур внутрь, Bulge отдельно меняет внутренний профиль. Seamless подгоняет периоды и суммарный трансформ слоя/группы к холсту (шаг поворота 90°, без скоса/перспективы), не переписывая исходные значения; приоритет над Tiling. FX после генерации могут нарушать бесшовность. Контракт API: fillMode + fillPattern.
- Pattern Cell Color: Uniform/Random/Pattern; отдельная Palette, Seed и Variation для Random. Multiply/ReplaceRGB меняют только RGB, альфа остаётся от SDF. В зазорах цвет ближайшего контура. Seamless повторяет ID случайных ячеек и подгоняет регулярные цветовые периоды: 2×2 для квадратной сетки, 3 по X и пары строк для сот/плотных кругов; треугольники различаются ориентацией. Размер X/Y со связью пропорций; связь влияет только на UI-редактирование, API принимает точные размеры.
- Live Quality по умолчанию 100%. HDR рядом с EV; footer-подсказки скрываются, когда места недостаточно.
  Компактный footer включается по фактической суммарной ширине контролов, а не фиксированному порогу;
  состав и порядок групп сохраняются.
- Clean Canvas View Background отключает декоративного ската и внутреннюю тень.
  Логотип основан на утверждённом SVG; не генерировать новый вариант самовольно.
- DnD слоя не обязан менять выделение. Drop-действия удаления/группировки должны работать и без selected layer.
  Пустая область под списком — валидная точка переноса вниз.

## Градиенты

- Общий режим новых градиентов, включая brush-tip и brush-tint, — Perceptual; явно заданные и сохранённые режимы не заменяются. API кистей и brush clipboard используют тот же default. SDF и Noise также используют Perceptual; Pattern имеет явные Linear defaults.
- SDF: `Output` / `encoding` = Gradient по умолчанию или LinearData; галочки useGradient нет. Gradient по умолчанию имеет black-to-white палитру (0 — чёрный, 1 — белый, Perceptual), одинаковую с Noise, Inverted доступен в обоих режимах и разворачивает расстояние перед Profile и палитрой. LinearData выдаёт нормализованное расстояние после Inverted/Profile как raw RGB 0–1, alpha=1, без гамма-декодирования. Profile работает в обоих режимах, палитра/инверсия сохраняются при переключении; Signed внутри темнее, снаружи светлее. Noise: `Output` / `encoding` = LinearData по умолчанию, палитра black-to-white; Inverted доступен во всех режимах и разворачивает значения шума перед палитрой. Остальные Output — ColorValues/LinearData; галочки useGradient у Noise нет. Цветной White/Blue Noise предлагает только ColorValues/LinearData, сохранённый Gradient временно работает/показывается как ColorValues без сброса палитры или encoding. Random All сохраняет палитру и выбранный Gradient; иначе Output рандомится только между ColorValues и LinearData. Inverted меняется; при Gradient в группе White/Blue сохраняет также Color, чтобы эффективный Output не менялся. Активный градиент даёт RGBA/HDR через Gamma LUT + Decode. Noise API: поля внутри noise; SDF — непосредственно в settings/properties.
- HDR-данные сохраняются, но текущий UI колорпикера/градиента показывает SDR-превью. Preview EV меняет только отображение; физический HDR-вывод на монитор не реализован. Не обещать его по наличию HDR-цветов, градиентов интенсивности или HDR-монитора.

- Rounded (встроенный алгоритм) — развитие эксперимента №68: независимые непостоянные блоки монотонной кубической кривой с крайними наклонами по секущим, коррекция встречной chroma в Perceptual, общий RGB remap на границе постоянного участка. Радиус равен расстоянию до midpoint (0.5 интервала при midpoint 0.5), ограничен половиной промежуточного постоянного участка. Края поддержки ограничены 0..1. Интегрированное плавное начало на 20% поддержки и широкая положительная компенсация скорости снижают пик доменного remap с 1.512 до 1.1875. Для поддержки q=2 остаётся симметричное скругление; между q=1 и q=2 — выпуклая смесь. Формула — в AI/README. При Smoothness 100% карта времени и соединения цвета с константой C2; внутренние/midpoint стыки базовой кубической кривой могут быть только C1. Уже нулевые первая и вторая производные выходного linear RGB не сглаживаются повторно. Alpha имеет отдельную карту. Внешние дубли одинаковых ключей не влияют на результат. Значения ключей на внутренних границах постоянных участков могут быть приближёнными; доменные края 0/1, обычные внутренние ключи и позиции midpoint сохраняются. Не обещает глобальную C2-гладкость или отсутствие любых плато/ободков. Partial Smoothness оставляет линейную составляющую. Rounded применяется всегда, без поля/enum/property Transition и без строки Transition в UI. Модель и writer 0.12.5 уже не содержат transition. Его приём в gradient clipboard/API снят; document reader диагностирует его как неизвестное поле, и сохранение TIFF/экспорт JSON по умолчанию блокируют потерю данных. Интерактивный Save предлагает явное подтверждение потери или запись копии; автоматические вызовы остаются защищёнными. Прежние документы открываются в соответствующем старом checkout, не мигрируют в текущий автоматически. Современные массивы ключей, объекты без обёртки и Markdown fences остаются допустимым вводом. Старый clipboard-префикс, color-объекты и числовые enum не конвертируются. Smoothness и режимы интерполяции сохранены. Текущая формула Rounded не меняется.

- HDR поддерживается данными ключей независимо от текущего режима color picker.
  Обычный выбор цвета должен оставаться удобным; HDR — отдельная toggle-кнопка.
- Цвет/позиция делят строку, между ними разделитель; знак % справа от Location.
  Preview EV — отдельный компактный footer, влияет на показ, не на данные.
- Popup редактирования не блокирует приложение, закрывается при потере фокуса.
  Поля обновляются во время редактирования, не только после hover.
- В редакторе минимум один ключ на каждой дорожке; данные нормализуются минимум до двух.
  Одиночный ключ может стать парой одинаковых при повторном открытии.
- Удаление ключа оттягиванием считается по вертикальному удалению от дорожки, не по горизонтали.
  При перетаскивании ключи могут менять порядок.
- Midpoints полезны для интерполируемых режимов, не создавать фиктивную интерполяцию для Fixed.
- LUT: 512×2 по умолчанию, RGBAHalf; шахматка рисуется отдельно. Копирование градиента — независимые данные.
- Градиент SDF по умолчанию Perceptual; ориентация brush-мягкости: 0 — плотное место, 1 — разреженное.
- Canvas handles: контекстный инструмент Gradient Handles с иконкой руки, автоматически включается при выборе активного градиентного слоя, без Edit on Canvas.
  Линейный — линия; radial/diamond/square — центр и конец через трансформ слоя, с разрешённым вращением.
  Отдельные параметры центра/радиуса не возвращать. Круговой режим обсуждался отдельно.
- Двойной клик по ключу открывает цвет; ключи удаляются оттягиванием и Del.
  Порядок отрисовки: линия → невыбранные ромбики → круги → выбранная ручка.
  Выделение — дополнительный голубоватый слой между белым и чёрным контуром.
- Пользовательские пресеты без ручных имён, GUID-файлы в папке пресетов.
  Новые первыми; прокрутка открывается сверху. New — первая плитка с текущим градиентом и жирной надписью.
  Чтение встроенных пресетов Unity допускается только без хрупких обходов.

## FX/HLSL и кисти

- Unity time uniforms разрешены: это warning, не причина запрета Apply. Предупреждение доступно
  в Diagnostics, агентском API и Console без повторов на каждом действии; reusable result cache для такого FX отключён.
  Политика и границы подавления повторов — в [ShaderFX.md](../Documentation~/ShaderFX.md).
- FX используют общий список диагностик Error/Warning/Info: компилятор, декларации, source/includes, каталог и Unity Time проходят через `ShaderFXDiagnostics`. UI, Console и API используют одинаковые записи; агент не классифицирует отображаемый текст заново. Console подавляет повторы source path + severity/location/message до reload; UI/API ничего не подавляют. Контракт — [ShaderFX.md](../Documentation~/ShaderFX.md), точечные проверки — `shader-fx-diagnostics` и `shader-fx-time-warning`.
- Неисправный/нескомпилированный FX пропускается без изменения Active; ошибка Apply не оставляет старый шейдер в рендере. Жёлтые индикаторы рядом с иконкой слоя, в заголовке секции FX и самого FX показывают также warnings при успешной компиляции, включая свёрнутые блоки. Исчезают, когда не остаётся замечаний; warnings не отключают FX. JSON сохраняет и открывает неисправный FX с параметрами и возвращает общие замечания при подготовке эффектов; структурные ошибки JSON остаются строгими. TIFF save validation пока не меняется.
- Необязательный корневой JSON writeMode: Full / FullOptimized / Compact; без поля FullOptimized. Ctrl+S и SaveJson без options сохраняют выбранный режим. Export не меняет режим исходного документа.

- FX — независимые плагины поверх общего контракта входного изображения и параметров. Новый эффект не должен требовать изменения поведения/генерации слоя, распознавания шейдера в слое или скрытой специальной текстуры от слоя. Исключение — прямое указание пользователя изменить поведение слоя. Общие механизмы применения FX, параметров и кеширования допустимы, но не специальные обходы ограничений для конкретного пресета.

- Unity-маркеры прежних имён удалены, включая `groupToggleParameter` и состояние окон. Во встроенных Color Filter, Negative, Mask, Gradient Map и HSV остаётся только `_Opacity`. HLSL-директива `@formerlyserializedas` и её metadata-поле удалены из FX/кистей, встроенных пресетов, экспорта и VS Code; старые имена не мигрируют.
- Каталог пресетов автоматически собирает подходящие файлы проекта и пользовательской папки.
  Не требовать ручного менеджмента каталога; не компилировать все файлы при открытии списка/после reload.
- Первая строка эффекта содержит `// @whimtex-effect ...`; короткий HLSL вместо обязательного ShaderLab.
  Каноническая функция эффекта `float4 ApplyFX(float2 uv, float4 color)`, чтение через `SampleInput(uv)`.
- `@param`: без `;`; имя поля выводится из имени переменной; комментарий после объявления — tooltip.
- Bool представлен float-uniform с toggle. Enum тоже скаляр; пункты без кавычек, явные значения,
  включая дробные. Имена enum — только для редактора, не HLSL-идентификаторы.
- Допустимы несколько скалярных контролов одной переменной. Последний явный default выигрывает;
  объявление без `=` default не меняет. Не путать число UI-контролов с числом uniform-переменных.
- Диапазоны: `[0 .. 4]` жёсткий; `[~0 .. 4]` мягкий снизу; `[0 .. ~4]` сверху;
  `[~0 .. ~4]` с обеих сторон. `~[...]` отвергнут, не поддерживать как синоним.
  Слайдер остаётся в диапазоне; ввод и перетаскивание label могут выйти за мягкую границу.
  Явный default вне жёсткой границы отвергается при разборе.
- Transform 2D — параметры/uniforms, не регенерация кода при движении.
  Зелёный rect без Pivot. Скрытые имена: узнаваемый префикс/имя параметра + стабильный суффикс против коллизий.
- Gradient-параметр без default начинает с чёрно-белого Perceptual-градиента; выборка через сгенерированную функцию.
  Явный HLSL default из двух крайних цветов сохраняет исходный контракт Classic/Gamma/Clamp,
  Smoothness 1, midpoint .5; неподдерживаемые настройки при экспорте не теряются молча.
  LUT кешировать до изменения; не смешивать стоимость подготовки с покадровой GPU-выборкой.
- Save HLSL Preset записывает текущие значения как defaults. При изменении синтаксиса обновлять экспорт тоже.
  Для связанных скалярных контролов default записывается в контрол, допускающий текущее значение;
  жёсткие/мягкие границы остальных контролов и порядок сохраняются. Если подходящего контрола нет — явный отказ.
- Базовая HLSL noise-библиотека доступна эффектам/кистям; белый и синий шум не включались в этот контракт.
- HLSL-brush генерирует кешируемый отпечаток и далее работает как текстурная кисть.
  Standard объединяет обычную кисть и кисть с текстурой; HLSL — отдельный источник отпечатка.
- Browser brush JSON по вставке меняет текущую кисть. Для текстуры — URL; точные поля в AI/BRUSHES.md.
  Пресеты кистей читаются из проекта/пользовательской папки, выбираются DnD.
- Size/Opacity/Flow/Hardness не сбрасываются кнопками reset секций пресета; режим мягкости сбрасываться может.
- Сглаживание траектории (None/Smooth/Stabilizer) и нажима — общие пользовательские настройки ввода, по умолчанию выключены; Distance в пикселях холста. Shift-линии и привязки точные. Write RGBA/Lock Alpha — отдельная защита записи в настройках/пресетах кисти, по умолчанию доступны все каналы; футер RGBA влияет только на просмотр. Контролы встроены в строку выбранного инструмента, а не в отдельную строку. [Границы и оставшиеся идеи](Backlog/BRUSH_IMPROVEMENTS.md).
- Levels: общая RGB-кривая после Input/Gamma, перед Output; независимые R/G/B-кривые после общих уровней, Alpha отдельно. Выбор в Curves меняет только редактируемое поле — все кривые активны и сохраняются. Нейтральные кривые не обрезают HDR; Alpha ограничена 0–1. Opacity смешивает RGBA. [Точный контракт](../Documentation~/ShaderFX.md#curve-parameters).
- Threshold: Source Channel — Luminance/R/G/B/Alpha вместо `_UseAlpha`; результат меняет RGB между Low/High Color и сохраняет исходную альфу при любом источнике.
- RGB-normalize как цветовой эффект отвергнут; Normalize предназначен карте нормалей.
  Проверять packed-каналы и рабочее цветовое пространство до декодирования [-1,1] и нормализации.
- HSV: Hue — сдвиг, S/V — множители с нейтральным 1; S/V slider до 4, мягкая верхняя граница, жёсткий ноль.
- Варианты узора/алгоритма — одним enum-параметром, а не отдельными пресетами и не shader variants.
  Enum идёт через `material.SetFloat`, поэтому ветка по нему uniform: расхождения внутри волны нет,
  а развёрнутая цена ограничена суммой веток (~90 ALU) и дешевле усреднения блока по 16 сэмплам.
  Отдельные файлы дублировали бы ~80% кода, раздули меню каталога и сбрасывали настройку при переключении.
  Сами узоры лежат в `src/Shaders/Dither.cginc`; порядок списка общий для пресетов, `Hash` стоит последним.
  Перенос `Hash` меняет вид старых документов Posterize с включённым дизерингом (значение 1 теперь Bayer2) — принято.
- Тот же include переиспользуют проектные пресеты; имена узоров и `DitherThreshold` публичные, не переименовывать.
- `HalftonePattern` — единственный узор, достигающий порога ровно 1.0, поэтому шаг уровня обязательно
  ограничивать сверху (`min(..., steps)`), иначе белый пиксель даёт значение выше 1 и третий цвет в one-bit.
- Error diffusion (Floyd–Steinberg, Atkinson) в пресетах невозможен: `ApplyFX` однопроходный, без состояния соседей.
  Не эмулировать; при необходимости — отдельная C#/мультипас-фича для Drawing-слоёв.
- Пресет пикселизации: `Pixel Art/Pixelate`, узор считается по сетке блоков, иначе после пикселизации он не виден;
  матрицы Байера обрезаются по своему периоду, чтобы рисунок не плыл на больших холстах.

## Выделение, направляющие, UV

- Иконки в шапке Transform: Center Pivot сохраняет изображение на месте; Center on Canvas переносит пивот в центр Canvas вместе с изображением. Flip Horizontal/Vertical и Rotate Left/Right 90° используют оси Canvas и текущий пивот, не оси повёрнутого вида. При мультивыделении используется общая рамка и общий пивот; сброс общего пивота меняет только состояние рамки, не локальные пивоты слоёв.
- Shift+MMB вращает вид с любым инструментом; zoom и угол доступны численно. Shift-рисование учитывает поворот.
- Линейки сверху/слева и скроллбары справа/снизу имеют общую толщину 16 px. Линейки показывают пиксели от проекции верхнего левого угла Canvas вдоль осей текущего вида; шаг адаптируется к зуму, маркер следует указателю. Скроллбары перемещают только вид, учитывают повёрнутые bounds Canvas и не перекрывают инструменты. Прокрутка не ограничена границами, включая Fit без переполнения: рабочая область расширяется, а бегунок сжимается до минимального размера 24 px (не больше длины дорожки). На время жеста фиксируется только скорость перетаскивания, не диапазон или размер бегунка; отпускание не меняет положение вида.
- Стрелки на концах скроллбаров двигают вид на 24 экранных пикселя. Удержание повторяет шаг через 350 ms, затем каждые 50 ms; используется штатный UI Toolkit RepeatButton. Дорожка и стрелки имеют раздельные обработчики, поэтому нажатие стрелки не запускает drag/page scroll.
- Направляющие вытягиваются из левого/верхнего края; из пересечения линеек — пара горизонтальная+вертикальная, с общими commit/cancel и Undo/Redo. Создавать можно любым инструментом. Двигать существующие — Layer Select, Transform, Zoom и временными FX-инструментами. Рисование, Shape и выделение области их не перехватывают. Маркеры/рамка активного инструмента приоритетнее линии; Ctrl пропускает её и оставляет обычное действие инструмента.
- Направляющая хранится относительно холста; при создании на повёрнутом виде параллельна краю вытягивания.
- Кисть/карандаш притягиваются. Начало мазка на направляющей + Shift удерживает её вне обычного радиуса.
- Пересечения имеют повышенный приоритет при том же радиусе. Неоднозначные виды snapping к наклонным
  направляющим пропускать; края объектов не тянуть к произвольному углу.
- Сами направляющие не притягиваются друг к другу; могут к краям/центру холста и пересечениям,
  если в пересечении нет параллельной перемещаемой направляющей.
- Углы направляющих дают магнитные углы вращения вида для горизонтального и вертикального выравнивания.
  Параллельные текущему виду направляющие визуально отличаются от наклонных.
- Радиус snapping, цвета направляющих — user settings; видимость направляющих — footer.
- Layer Select учитывает альфу, default threshold 10%; повторный выбор группы ищет её дочерние слои.
- UV: показать острова без внутренних треугольных рёбер, выбирать область острова. Редактирование UV не нужно.
- Content-aware fill — процедурное заимствование существующей картинки, не генеративная модель.
  Distance задаёт ширину внутренней полосы от границы выделения; есть инверсия выделения.

## Генерация и документация для браузерного ИИ

- Не встраивать чат в WhimTex. Live-заглушка — резервирование/блокировка, не промежуточный кадр.
  Допустимо создать сразу с именем; пользователь может двигать/скрывать её пока агент работает.
- Строгая маска или примерная область, проба слоя или всей композиции выбираются по запросу.
  Не отрезать тени автоматически, если выделение задаёт лишь расположение объекта.
- Примеры JSON должны вставляться напрямую; URL — строка с прямым адресом, не Markdown-ссылка.
  Не предполагать поддержку Base64; проверять действующий контракт.
- Canvas size необязателен. В пустом документе применяется сразу, в непустом запрашивает подтверждение.
  Фильтрация canvas отдельна от фильтра слоя; отсутствие параметра сохраняет контрактный default.
- Навигация для ИИ: явная точка входа, заметные примеры, частые ошибки, полная спецификация.
  Скрытый комментарий README помогает читателям raw Markdown, но не гарантирует индексацию.
- Не рассчитывать на выполнение кода браузерным ИИ. Онлайн-валидатор обсуждался, но не был выбран
  обязательным способом самопроверки.
- Примеры вроде сердца предпочтительно собирать из нескольких осмысленных слоёв:
  форма, gradient+clipping, outline, нарисованный/примитивный блик и blur. Не заменять всё одним растром.

## Регрессии: куда смотреть при похожих симптомах

- После reload текстура материала могла выглядеть сплошным цветом, зависеть от камеры/preview;
  наблюдалось не только на композиторах. Проверять mipmaps, владение/освобождение RT,
  RenderTexture.active, GL.sRGBWrite; не объявлять причиной Live Update, PNG или meta без воспроизведения.
- Пипетка: временная Alt по всему экрану, курсор-пипетка вместо отдельной иконки рядом.
  Лупа раньше прыгала из-за координат/offset; на втором мониторе цвет клика расходился на пиксель.
  Проверять DPI/координаты и соответствие видимого sample фактически выбранному цвету.
- Мягкий alpha-край мог отодвигать Outline слишком наружу; важны threshold и определение границы SDF.
  Заливка центра и обводка могут иметь разные цвета.
- Gradient мог тормозить весь preview; не обвинять миниатюры без проверки основного рендера.
  Переключение режима градиента однажды сбрасывалось обратно: проверять round-trip UI → данные.
- Make Seamless: Mirror=0, ScreenedPoisson=2, OffsetBlend=3, PatchQuilting=4; новые слои выбирают OffsetBlend. Сохранённые 0/3/4 обрабатываются своими алгоритмами, остальные числовые значения — как ScreenedPoisson; API принимает четыре актуальных имени. Screened использует глобальный projected FFT-preconditioned CG с 16 итерациями и поканальным guard; подробности — в разделе алгоритмов ниже. Это не bounded solve: RGB может выйти за диапазон, alpha ограничена. Центр сохраняется приблизительно; складки за пределами стыка возможны. Оси длиной 2/3 проекция усредняет, длина 1 неизменна. Premultiplied linear RGBA, общий EffectRenderCache.
- Общая маска Channels R/G/B/A: processRed/Green/Blue/Alpha, default true. Выключенные каналы восстанавливаются из входа после алгоритма, в straight linear RGBA, до трансформов/FX/channelMapping/color range/blending. A выключена — исходная альфа без масштабирования выбранного RGB. Все четыре выключены — bypass; все включены — без дополнительного mask pass. Сериализация, Portable, API, Undo и кеш учитывают маску.
- Poisson Edges — общий парный селектор: AllEdges=0, TopAndBottom=1, LeftAndRight=2, None=3. Последнюю пару можно отключить; None пропускает только соответствующий проход, не независимые copy/mirror/quilting stages. Общие Undo/bindings и helper используются отдельным Poisson и коррекциями.
- Make Seamless на мягких текстурах мог оставлять тонкий шов; предложенную правку пользователь откатил.
- Mirror: mirrorContrastCompensation (default false), mirrorContrast 0–1 (default 1), mirrorSeamCorrection (field initializer false, factory нового слоя true), mirrorCorrectionRadius .005–.25 (default .05). Компенсация переиспользует HistogramSeamless с отражёнными донорами, симметричной выборкой и covariance отражённых пар; сохраняет fade/falloff Mirror. При выключении или силе 0 остаётся дешёвый shader. Коррекция — глобальный Screened с независимым mirrorPoissonEdges; Off отражения не отключает коррекцию. Миграции нет. Зеркальные мотивы сохраняются; компенсация приблизительна, коррекция может дать HDR/клиппинг.
  Не считать прежний алгоритмический вариант согласованным решением.
- ListView/DnD: притягивание списка к нижней границе, игнорирование drop на пустую нижнюю область.
- USS meta: ScriptedImporter version 1 вызывал предупреждение о минимальной версии 2.
  Не копировать старый meta-шаблон без проверки.

## Трансформы слоёв

- Обычные операции хранят TRS; скос/перспектива переключают слой на гомографию 3×3. Все данные double, GPU float.
- Матрица отображает нормализованные source UV в canvas UV; pivot хранится отдельно. Не декомпозировать и не пересобирать матрицу при выделении/сохранении. Reset возвращает TRS.
- Жест всегда считается от исходного снимка, не от предыдущего кадра. Numeric Rotation/Scale матричного слоя — локальные оси в pivot; редактирование сохраняет перспективу.
- Положение, размер и ориентация отпечатка кисти — в canvas space; запись компенсирует трансформ слоя.
- Иерархические group transforms реализованы в [TransformHierarchy](../src/WhimTexDocument.TransformHierarchy.cs): локальные значения, parent matrices/inverses/GPU rows, инвалидирование по значениям, parent identity/version и canvas size. Множественные жесты не считать автоматически тем же контрактом; перед расширением проверить текущую реализацию.

## Контекстные инструменты

- Базовые инструменты постоянные; последний выбранный базовый запоминается отдельно. Контекстные живут под разделителем панели и зависят от активного (последнего выбранного) слоя, даже при множественном выделении.
- Gradient Handles автоматически выбирается при смене активного слоя на поддерживаемый Gradient. Ручной выбор базового не перебивается до следующей смены активного слоя. Circular пока без манипуляторов.
- Включение UV только добавляет контекстный UV Island Select, не выбирая его. Это больше не вариант Area Select.
- Edit on Canvas создаёт один временный слот ниже всех контекстных. Имя и описание зависят от параметра, для FX иконка руки. Смена временной цели заменяет слот, не накапливает стек возврата.
- Выход из контекстного возвращает последний базовый. Выход из временного возвращает предыдущий инструмент, включая контекстный, если его контекст ещё существует; иначе базовый. Явный выбор другого инструмента имеет приоритет.
- Escape во время жеста отменяет только жест. Без жеста выходит из временного/контекстного; повторное нажатие его активной кнопки тоже выходит. Панорамирование и пипетка сохраняют своё поведение.
- Потеря контекста — смена/удаление цели, а не фокус Inspector, Color Picker или другого приложения. Выбор инструмента не входит в Undo и TIFF. При закрытии/перезагрузке восстанавливается базовый, затем учитывается текущий контекст.

## Восстанавливающая кисть

- Healing Brush — базовый инструмент для Drawing, не FX и не отдельный тип слоя.
  Клик по другому типу предлагает штатную конвертацию, не выполняя мазок.
- Мазок задаёт область ремонта; PatchMatch запускается после отпускания в фоне.
  Во время жеста маска рисуется в отдельный GPU-буфер, не в документ. Превью и
  финальная маска используют этот же буфер; Hardness задаёт профиль круглой кисти.
  Покрытие объединяется через Max, не накапливается от повторных проходов.
  Current Layer берёт пиксели до FX; Current & Below — видимый стек текущего и нижних
  слоёв в том же контейнере. Запись только в активный Drawing, возможен пустой ретуширующий слой.
- Canvas-space область поиска ограничена 1,048,576 пикселями; GPU readback локальный.
  Запись учитывает canvas transform и сохраняет исходные размеры Drawing. В первой
  версии нет повторов кисти, Flow/pressure и отдельного согласования освещения.
- Tiled повторяет маску в превью и переносит мазки через края и углы. Поиск использует
  локальную развёртку периодического холста с разрезом в незакрашенном промежутке;
  результат переносится обратно в исходный тайл. Переключение Tiled отменяет мазок.
- Выделение ограничивает запись, но не область поиска. Transparent Only проверяет
  альфу пробы. Вся область мазка, включая мягкую кромку, исключается из доноров.
- Один результат — один Undo. Escape/Cancel, смена инструмента/контекста, изменение
  источника и закрытие окна отменяют незавершённую работу. Не держать Undo-группу
  открытой на время фоновой задачи; не применять устаревший результат.
- Проверки: `healing-brush-smoke-v2`, `content-aware-fill-v2`; общий протокол —
  [RUNNING_TESTS.md](../Tests~/RUNNING_TESTS.md), алгоритмические cases — [HEALING_QUALITY.md](HEALING_QUALITY.md#проверки).
- Общий worker Healing/Content-Aware Fill учитывает независимые признаки фактуры на
  пирамиде. На последнем шаге лучший донор сохраняет резкие детали, а совместимые
  гладкие фрагменты избирательно смешиваются для уменьшения стыков. Гладкость
  определяется по исходным донорам, не по уже восстановленному изображению.
  Между уровнями передаются координаты доноров; цвет и признаки берутся из исходника
  нового разрешения, не из усреднённого грубого результата. Серую полосу это пока
  уменьшает лишь частично; экспериментальные изменения промежуточных весов не приняты.
  Обоснование, ограничения и сравнительные проверки: [HEALING_QUALITY.md](HEALING_QUALITY.md).
- Повторы источника ограничиваются мягко: учитывать покрытие исходных пикселей всеми
  найденными патчами, а не только частоту центров или смещений. Карту замораживать на
  проход; обычное перекрытие связного копирования не штрафовать. Альтернатива допускается
  лишь в пределах 15% сырой ошибки лучшего найденного за проход кандидата; точное
  совпадение не ухудшать. В voting/reconstruction хранить исходную ошибку без штрафа.
  Это эвристика разнообразия, не запрет повторов или гарантия отсутствия лоскутности.

## Noise: раздельный Scale, 3D и периодичность

- Scale X/Y (в 3D — XYZ) с цепочкой сохраняет пропорции при UI-редактировании. API принимает число, пару или тройку буквально: число задаёт активные оси, пара сохраняет Z, inspect возвращает XYZ. Runtime и файлы хранят оси явно; отсутствующие поля Compact получают фиксированные defaults, без наследования через scaleY=0.
- Scale Z по умолчанию 1, включая файлы без поля: прежний рендер сохраняется. Координата среза = Offset Z × Scale Z; при Offset Z=0 изменение только Scale Z не перемещает срез. 1D/2D сохраняют неактивный Z. Random All в 3D использует среднее XYZ и сохраняет связанные пропорции; в 1D/2D алгоритм XY прежний, Z сохраняется.
- OpenSimplex2/2S, Cellular, Perlin, ValueCubic, Value поддерживают 3D: Scale и Offset становятся XYZ,
  Z выбирает срез и сохраняется при переключении Dimensions. Это не автоматическая анимация.
- Periodic None/X/Y/XY работает в 2D/3D через оборачивание решётки до хеширования, не смешивание
  готовых цветов. Каждый octave/warp получает свой целочисленный период; Z не периодизируется.
  2D simplex использует ортогональный базис треугольной решётки, 3D — периоды кратные трём.
  Малые Scale квантуются. С 2026-10-01 2D simplex округляет только конечный период каждой
  октавы от исходного Scale, без предварительного округления базы: Scale <1 меняет частоты
  последующих октав. Минимум одна ячейка остаётся; старые 2D periodic simplex рисунки могут
  измениться и при Scale >1. White/Blue оставлены без новых режимов; 1D позднее получил отдельный `periodic1D` (см. раздел выше).
- CPU готовит double-базисы и разделяет целые/дробные координаты; GPU использует компенсированные
  произведения без double и без vendor intrinsics. Это сохраняет точность на больших Offset/частотах.
  Noise shader разделён на варианты по типу/размерности/периодичности для ограничения компиляции.
  FastNoiseLite hooks opt-in; другие пользователи include не меняются. 3D Noise разрешает обе
  итерации BCC-grid вместо прежнего unroll(1). Нового Unity internal reflection нет.
- Исторические 6480 GPU/reference сравнений и precision/UI/API проверки выполнены на DX12;
  это не новый PASS или проверка всех backends. Актуальные `noise-*-v2` scenarios и stress/diagnostic
  variants выбирать из каталога; производительность измерять отдельно.

## Make Seamless: алгоритмы и кеширование

Действующая реализация — [MakeSeamlessLayerBehaviour](../src/Layers/MakeSeamlessLayerBehaviour.cs),
[ScreenedSeamless](../src/ScreenedSeamless.cs), [PatchQuiltingSeamless](../src/PatchQuiltingSeamless.cs).
Factory defaults новых слоёв и field initializers для отсутствующих сохранённых полей различаются:
не считать числовое значение из старого эксперимента default нового слоя.

- Offset Blend: адаптация прототипа copy-blend 05; premultiplied linear RGBA по каналам, half-period copy, CDF/Gaussian LUT и covariance normalization. Стратифицированная выборка до 128×128, синхронный readback + CPU таблицы, full-resolution GPU blend. Пересчёт источника обновляет анализ; повторный вывод через EffectRenderCache. Распределение приблизительное; цвет и рисунок могут меняться. OffsetBlend — default новых слоёв; без миграции.
- Offset Blend: offsetTransitionStart -1–.95, UI Transition Start (%), начало quintic fade внутри edgeWidth. До начала — полная копия; 0 начинает переход на краю. Field initializer .325 сохраняет трактовку отсутствующих старых полей; factory нового слоя задаёт -.25 (см. defaults выше). Многомасштабное смешивание — внешний эксперимент, не режим продукта.
- Poisson: глобальный расчёт с независимыми poissonEdges, mirrorPoissonEdges, offsetPoissonEdges — AllEdges (default), TopAndBottom, LeftAndRight, None. Выбранные оси периодические, невыбранные — natural/clamped; None пропускает проход. Точный FFT-preconditioner через чётное продолжение невыбранной оси; два FFT RT удвоены по одной стороне, явная ошибка при превышении maxTextureSize. 16 PCG итераций с поканальным guard. Старый restricted solve и cubic seed удалены: фиксированная прямая по четырём крайним пикселям сохраняла резкий перепад даже после сходимости. Историческая проверка на шуме 725², направлениях и радиусах .005/.05/.25 совпала с double solver с max error <3.8e-7. Poisson игнорирует copy/mirror masks и их ширину, может менять центр и невыбранные края; это не локальный проход по полосе. UI/API/Undo/cache учитывают независимые enum, миграция старых флагов не выполняется.
- Method: Mirror, Offset Blend, Screened Poisson, Patch Quilting. Четыре флага left/right/bottom/top и edgeWidth .02–.5 (default .2) управляют только копированием Offset; histogramContrast 0–1 (default 1). offsetContrastCompensation, offsetSeamCorrection, offsetAutoRadius default true, offsetCorrectionRadius .005–.25 (default .05). Выключенная/нулевая компенсация пропускает гистограмму/Gaussian RT; Poisson Correction — глобальный проход независимо от копирующих граней, включая все выключенные. Auto radius = max(.005, edgeWidth/4), иначе ручной радиус. Параметры между методами не копируются. Mode 3 = OffsetBlend, старых API-алиасов и миграций нет. Общую силу подмешивания исходника не добавляли: она возвращает шов.
- Patch Quilting — локальная обработка краевых полос, не синтез всей текстуры. CPU bounded search: downsample 96/160/256, 8/24/48 кандидатов Draft/Normal/High; GPU full-resolution premultiplied blend. Cut — DP по цвету и продольным производным; вторая ось использует первую и общий guard-anchor (приближённый cyclic cut, не глобальный оптимум). quiltingWidth .02–.45, default .2; quiltingFeather 0–100%, default 50. quiltingEdges допускает парные оси и None. Linked использует общий premultiplied RGBA разрез; Independent — straight-data разрезы выбранных каналов. Seed int32, default 0; результат детерминирован при одинаковых source/size/settings. quiltingSeamCorrection default false, отдельные quiltingPoissonEdges и radius .005–.25, default .05. Без коррекции центр сохраняется с premul roundoff; hidden RGB при alpha=0 в Linked обнуляется. Физический B<=1 копируется напрямую; остальные tiny bands используют Feather по правилу ниже. Параметры методов не переносятся/не запекаются; общий EffectRenderCache, sliders capture-out. Уменьшенный просмотр может выбрать другой разрез: оценивать full resolution. High не гарантирует улучшения, линии склейки возможны.
- Patch Quilting matching — Burst IJobParallelFor, float4 NativeArray исходных ориентированных значений/производных; Independent сравнивает один компонент. GetPixelData/SetPixelData заменяют managed image arrays. FloatMode.Strict и double финальное сложение/деление сохраняют порядок почти равных кандидатов; budgets качества неизменны. FP32 pre-Poisson entry принадлежит общему LRU EffectRenderCache: downstream correction его не инвалидирует, source/size/scale/quilting settings — инвалидируют. Resolver использует NextContentLayer, пропуская Pending/null как рендер. Рабочая память описана следующим пунктом, не является кешем результата.
- Patch Quilting workspace — единый Burst batch уникальных (channel, rounded donor, side), зависимость от PrepareJob, один Complete на ось. Aliases восстанавливают исходные кандидаты, дубликаты и tie order до sort/seeded selection. Один idle owner Persistent NativeArray + readback/path Texture2D, максимум 64 МиБ удерживаемого storage, отдельно от EffectRenderCache. Expiry 30 s без поиска, cleanup reload/quit; nested rent изолирован, exceptions dispose после Complete, channels map очищается. Второй проход зависит от рендера первого; async/GPU-поиск не добавлены. Исторические A/B-серии в Git, не обещание frame budget.
- Patch Quilting Feather — доля доступного симметричного перехода вокруг каждого cut, независимо от Width. Для доли p: F_L=2*p*max(0,min(L,B-1-L)), F_R=2*p*max(0,min(R-B,2B-1-R)); L/R не используют общий minimum, /scaleMultiplier нет. При analysis b<4 cuts ставятся в середины половин полосы, Feather применяется; только физический B<=1 копируется напрямую. На нескольких output pixels разные проценты могут не семплироваться. По отдельному явному решению миграции пиксельного Feather нет: сохранённое 16 читается как 16%, прежний вид этой настройки не гарантируется. UI Feather (%), API/schema 0..100; это смешивание, не blur.

## Shape

- Фигуры: Rectangle, Ellipse, Polygon, Star, Line, Arc, Sector. Arc — тело дуги с независимыми Fill/Stroke, как Line; `arcThickness` (default 8) задаёт толщину тела в canvas pixels, Transform — эллипс средней линии. Нулевая толщина или Sweep 0 дают пустую фигуру; Sweep 360 — кольцо без окончаний. Start Angle 0 направлен вправо, Sweep 0..360 идёт против часовой стрелки. Sector заполняет сектор; при Sweep 360 это эллипс без углов.
- Stroke Position: Inside / Center / Outside относительно контура тела, в том числе Arc; ширина обводки в canvas pixels не меняет толщину тела. У Line тело задаётся Transform. Butt/Round/Square — окончания Line/Arc; Round/Square выступают за endpoints на половину толщины тела. У Arc Thickness показан в Layer Settings и шапке инструмента только для Arc; Fill/Stroke остаются общими для всех фигур.
- Corner descriptor `{style:Round|Bevel,amount:0..1}`. Rectangle: TL/TR/BR/BL, доля полной короткой стороны; независимый угол может занимать больше 50%, вплоть до 100%, вытесняя конфликтующих соседей. Polygon: по вершине; Star/Sector: отдельно Outer/Inner. У Sector Inner — центр, Outer — два стыка с дугой; Sweep 180 не имеет центрального угла. Round использует круговой fillet, Bevel — прямой срез; Sector строит скругления в нормализованной окружности и растягивает вместе с эллипсом. У Ellipse нет углов, у Line/Arc вместо углов окончания.
- Corners UI: схема фигуры из общего с рендером контура, пространственные поля величин и компактные Round/Bevel иконки вместо текста enum. У Polygon >8 вершин выбор угла на схеме (также Left/Right); у Star/Sector — Outer/Inner. Связь величин обозначается цепочкой, как прежде у Rectangle.
- Link Corner Amounts связывает только величины, не типы. При ненулевом исходном значении сохраняет пропорции, при редактировании нулевого прибавляет одинаковую величину. Независимый edit через UI/`SetCorner` отдаёт приоритет активному углу/группе, уменьшает реальные соседние значения, затем ограничивает активное. Уменьшение активного не восстанавливает соседей. Связанный edit, геометрические изменения и массивные API assignments ограничивают величины пропорционально по фактической длине занятого ребра. Все изменения одной UI операции входят в один document Undo.
- `ShapeContour` кеширует прямые сегменты и аналитические ограниченные дуги; distance и inside-test используют один контур. Feather — SDF-переход Inside/Outside/Centered без отдельной raster SDF и без скрытого уменьшения Feather. Широкий Feather естественно поглощает мелкие детали.
- Edge Mode Antialiased / Step. Step отключает Feather и геометрическое AA, вычисляет coverage 0/1 на canvas grid после Transform. Альфа цветов, Opacity, Mapping, FX, композит и последующая фильтрация остаются независимыми; binary alpha относится к исходному full-resolution Shape с непрозрачными цветами.
- Данные/API: `rectangleCorners`, `polygonCorners`, `outerCorner`, `innerCorner`, `strokePosition`, `lineCap`, `edgeMode`, `startAngle`, `sweepAngle`. `roundness` и `cornerRoundness` удалены без aliases/миграции. Обновлены Shape defaults и генераторы схем; неверное количество corner objects и amount вне 0..1 дают явный JSON diagnostic. Full JSON сохраняет неактивные настройки, оптимизированные режимы могут их исключить по общим правилам.
