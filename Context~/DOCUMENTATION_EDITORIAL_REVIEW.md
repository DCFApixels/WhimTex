# Редакторская правка документации

Дата: 2026-10-03. Аудитория — художник с базовым пониманием технической стороны, способный написать простой шейдер.
Это отчёт о правке и предложения для согласования, не очередь поручений агенту.

## Что изменено

- Вход в руководство разделён по задачам: композиция, рисование, процедурные эффекты, проверка и сохранение.
- В Layers сначала идут обычные действия со слоями; подробности Pattern и Shape — после них.
- В Noise сначала выбирается узор, затем размерность и бесшовность. Output выделен в сравнение режимов; правила Random All собраны отдельно.
- В Effects исправлено вложение Linear/Circular Blur, ранее оказавшееся под Sharpen. Источники Previous / Specific / All Below сопоставлены в одном месте.
- Outline и SDF разделены по результату: обводка, дистанционный переход, обработка края. Убрано повторное объяснение Inverted.
- Make Seamless начинается со сравнения методов. Общие грани/каналы отделены от параметров каждого метода и проверки результата.
- В Color выбор цвета предшествует HDR-фильтрации истории. Отдельно объяснены числовой ввод, реальная интенсивность и экспозиция просмотра. Работа с градиентом — до подробностей Rounded.
- Shader FX начинается с выбора между эффектом слоя и Processor, затем использования пресета. Синтаксис контролов вынесен на отдельную дополнительную страницу EN/RU/ZH. Различие компиляции и запекания Apply показано явно.
- Исправлено противоречие о неудачном Apply: ошибочный FX пропускается, а не продолжает отображать прежнюю скомпилированную версию.
- В Painting открытие панели и обычные настройки идут раньше HLSL. В Preview направляющие разбиты по действиям; минипревью сначала объясняет, как его открыть.
- Saving начинается с сохранения и выбора формата, а не исключений JSON. Открытие JSON, вставка слоёв и Save As сопоставлены отдельно.
- В технических справочниках подключение API и первый HLSL-пример подняты выше внутренних деталей. JSON разделён на правила записи, модель, assets/FX, валидацию и вызовы API. Колорпикер больше не вложен в хранение Drawing.
- README уточнён: Export используется не только для изображений, но и для JSON без Drawing-пикселей.

Существующие пути, permalink и тексты прежних заголовков сохранены. Новые подразделы добавлены синхронно в EN/RU/ZH. Реализация, API-контракт, схемы, семплы и Unity-ассеты не менялись.

Технические подробности не удалялись ради сокращения. Синтаксис оставлен в дополнительной странице/справочниках; полезные ограничения остаются рядом с результатом. Уникальные детали управления из списка ниже пока сохранены.
